# Fix: Tiling drag handle hover triggers when overlays are open

## Bug

When an overlay (help dialog, command palette, exit confirm) is open:
- Moving the mouse **through** the overlay's dialog area: fixed by render_area check
- Moving the mouse **outside** the overlay's dialog bounds (the dimmed background): **broken** — handles highlight because render_area doesn't cover the outer area

Root cause: spatial occlusion checks fail because overlay dimmed backdrops don't register hitboxes or define render_area coverage.

## Fix

### Fix 1: `hovered_tiling_handle()` — check `!self.overlays.is_empty()`

Replace the per-overlay `render_area()` iteration with: if *any* overlay exists in the SlotMap, suppress handle hover entirely. Using `!self.overlays.is_empty()` is universally correct — it catches all overlays (built-in and custom third-party), unlike the legacy `visible_overlay_count()` which only tallies specific system overlays.

```rust
// If any overlay is active, suppress handle hover (overlays are modal).
if !self.overlays.is_empty() {
    return None;
}
```

### Fix 2: `dispatch_mouse()` — add `!self.overlays.is_empty()` guard

Add to the Moved forwarding `obscured` check. When obscured, send synthetic off-screen event to clear layout state.

```rust
let obscured = match &owner {
    ComponentOwner::Layer(_) | ComponentOwner::Overlay(_) => true,
    ComponentOwner::Window(key) if self.is_window_floating(*key) => true,
    ComponentOwner::Chrome(target)
        if !matches!(target, ChromeTarget::SplitHandle(_)) => true,
    _ => false,
} || !self.overlays.is_empty();
```

### Fix 3: Remove per-overlay `render_area()` iteration

The global `!self.overlays.is_empty()` check makes the per-overlay `render_area()` loop redundant. Remove it.

### Fix 4: Replace `visible_overlay_count()` with `self.overlays.len()`

Delete the legacy `visible_overlay_count()` method — it violates OCP by only counting specific built-in overlays. Replace its two call sites:

- `src/lib.rs:65`: `let total = num_windows + wm.overlays().len();`
- `crates/term-wm-core/src/runner.rs:699`: `system_handle.set_keep_awake(!app.wm().overlays().is_empty());`
