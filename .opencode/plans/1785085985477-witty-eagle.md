# Fix: Arrow Keys Blocked in Embedded Man Pages / git log

## Root Cause

Two independent problems:

1. **Keyboard arrow keys intercepted**: `ScrollViewComponent` in `ScrollKeyMode::Full` intercepts bare Up/Down (bound to `ScrollUp`/`ScrollDown`) for native scrollbar. Arrow keys must **always** be forwarded to the PTY child.

2. **No passive state tracker for PTY byte stream**: Mouse scroll routing relies on ad-hoc `direct_mode` flag and `alternate_screen()` calls through vt100 parser. These lack a unified deterministic state machine for alternate screen, mouse tracking, and custom margins.

## Design

### Input Routing Table

| Input | Routing |
|-------|---------|
| Keyboard arrow keys (Up/Down/Left/Right) | Always → PTY child process (never intercepted) |
| Keyboard PageUp/PageDown/Home/End | ScrollViewComponent (native scrollbar) |
| Keyboard Shift+Up/Down | Native scrollback navigation (modifier-based) |
| Mouse scroll wheel | Query `Pane::requires_app_routing()` → PTY or native scrollbar |

### PtyStateTracker — Lock-Free Atomic State Machine

Contains ONLY atomic fields. Wrapped in `Arc` and shared between reader thread and main thread.

**`update_mouse_tracking`** uses CAS to avoid clobbering different active modes:
```rust
pub(crate) fn update_mouse_tracking(&self, target_mode: u8, is_set: bool) {
    if is_set {
        self.mouse_tracking_mode.store(target_mode, Ordering::Release);
    } else {
        // Only clear if the mode being reset matches the currently active one.
        let _ = self.mouse_tracking_mode.compare_exchange(
            target_mode,
            0,
            Ordering::AcqRel,
            Ordering::Relaxed,
        );
    }
}
```

```rust
pub struct PtyStateTracker {
    is_alt_screen_active: AtomicBool,
    mouse_tracking_mode: AtomicU8,  // 0=None, 1=X11Normal, 2=CellMotion, 3=AllMotion
    is_sgr_mouse_active: AtomicBool,
    is_alt_scroll_mode_active: AtomicBool,
    has_custom_margins: AtomicBool,
    terminal_height: AtomicU16,
}

impl PtyStateTracker {
    pub fn new(terminal_height: u16) -> Self;
    pub fn requires_app_routing(&self) -> bool;  // reads atomics (Ordering::Acquire)
    pub fn resize(&self, height: u16);           // writes terminal_height (Ordering::Release)

    // Package-internal setters for PtyPerformAdapter (reader thread):
    pub(crate) fn set_alt_screen(&self, active: bool);
    pub(crate) fn set_sgr_mouse(&self, active: bool);
    pub(crate) fn set_alt_scroll_mode(&self, active: bool);
    pub(crate) fn set_custom_margins(&self, active: bool);

    /// Conditional mouse mode update: set unconditionally, but
    /// clear only via CAS (don't clobber a different active mode).
    pub(crate) fn update_mouse_tracking(&self, target_mode: u8, is_set: bool);

    /// Reset all state to defaults (RIS / DECSTR recovery).
    pub(crate) fn reset_all(&self);
}
```

### PtyPerformAdapter — Reader-Thread-Local vte::Perform

A private struct owned exclusively by the reader thread. Holds `Arc<PtyStateTracker>`. Implements `vte::Perform`.

```rust
struct PtyPerformAdapter {
    tracker: Arc<PtyStateTracker>,
}

impl vte::Perform for PtyPerformAdapter {
    fn esc_dispatch(&mut self, intermediates: &[u8], ignore: bool, byte: u8) {
        if ignore { return; }
        // RIS (Reset to Initial State): \e c
        if intermediates.is_empty() && byte == b'c' {
            self.tracker.reset_all();
        }
    }

    fn csi_dispatch(&mut self, params: &vte::Params, intermediates: &[u8], ignore: bool, action: char) {
        if ignore { return; }

        // DECSTR (Soft Terminal Reset): CSI ! p
        if action == 'p' && intermediates == &[b'!'] {
            self.tracker.reset_all();
            return;
        }

        let is_dec_private = intermediates.first() == Some(&b'?');
        match action {
            'h' | 'l' if is_dec_private => {
                let is_set = action == 'h';
                for param_group in params.iter() {
                    for &param in param_group {
                        match param {
                            47 | 1047 | 1049 => self.tracker.set_alt_screen(is_set),
                            1000 => self.tracker.update_mouse_tracking(1, is_set),
                            1002 => self.tracker.update_mouse_tracking(2, is_set),
                            1003 => self.tracker.update_mouse_tracking(3, is_set),
                            1006 => self.tracker.set_sgr_mouse(is_set),
                            1007 => self.tracker.set_alt_scroll_mode(is_set),
                            _ => {}
                        }
                    }
                }
            }
            // DECSTBM: evaluate margins bidirectionally (set or clear).
            // Normalize explicit 0 params to defaults (0 top → 1, 0 bottom → terminal_height).
            'r' => {
                let top_param = params.iter().next()
                    .and_then(|g| g.first().copied())
                    .unwrap_or(0);
                let bottom_param = params.iter().nth(1)
                    .and_then(|g| g.first().copied())
                    .unwrap_or(0);
                let height = self.tracker.terminal_height.load(Ordering::Acquire);
                let top = if top_param == 0 { 1 } else { top_param };
                let bottom = if bottom_param == 0 { height } else { bottom_param };
                let has_margins = top > 1 || bottom < height;
                self.tracker.set_custom_margins(has_margins);
            }
            _ => {}
        }
    }

    fn print(&mut self, _c: char) {}
    fn execute(&mut self, _byte: u8) {}
    fn hook(&mut self, _params: &vte::Params, _intermediates: &[u8], _ignore: bool, _action: char) {}
    fn put(&mut self, _byte: u8) {}
    fn unhook(&mut self) {}
    fn osc_dispatch(&mut self, _params: &[&[u8]], _bell_terminated: bool) {}
}
```

## Concurrency Model

```
Reader Thread                                Main Thread
─────────────                                ───────────
local vte::Parser parser;                    mouse scroll event
local PtyPerformAdapter adapter;               → comp.handle_events()
                                                 → pane.requires_app_routing()
loop:                                              (load atomics, Ordering::Acquire)
  reader.read(&mut buf)                            → return bool
  → parser.advance_bytes(&mut adapter, &buf[..n])
    (adapter stores atomics on Arc<PtyStateTracker>)
  → shared_parser.lock().process(&buf[..n])
```

- **Parser + adapter persist across loop iterations** (instantiated before the loop, not inside it)
- **Tracker fields are atomics only** — `Send + Sync`
- **Main thread reads atomics** — no locks, no mutable borrow
- **No channel, no heap allocation, no batch dropping**

### Amendment 2: Missing DECCKM Tracking (Root Cause of Arrow Key Failure)

**Bug**: `less` activates Application Cursor Keys mode (DECCKM, DECSET 1, `\e[?1h`) on startup, which changes arrow sequences to SS3 format (`\eOA`). Our `input_encoding.rs` always emits normal CSI sequences (`\e[A`) regardless. `less` silently drops `\e[A` because it expects `\eOA`.

**Fix** — track DECCKM state + conditionally encode arrows:

#### A. `PtyStateTracker` — Add DECCKM field

```rust
is_application_cursor_keys_active: AtomicBool,

pub fn is_application_cursor_keys_active(&self) -> bool {
    self.is_application_cursor_keys_active.load(Ordering::Acquire)
}

pub(crate) fn set_application_cursor_keys(&self, active: bool) {
    self.is_application_cursor_keys_active.store(active, Ordering::Release);
}
```

In `reset_all()`: clear this field.
In `PtyPerformAdapter::csi_dispatch`, `'h' | 'l' if is_dec_private` arm: add `1 => self.tracker.set_application_cursor_keys(is_set)`.

#### B. `input_encoding.rs` — Conditional arrow encoding

Add `application_cursor_keys: bool` param to `key_to_bytes()`. Only unmodified arrows use SS3; modified arrows always use standard CSI (including xterm modifier parameters) regardless of DECCKM:
```rust
(KeyCode::Up, m) if application_cursor_keys && m == KeyModifiers::NONE => b"\x1bOA".to_vec(),
(KeyCode::Down, m) if application_cursor_keys && m == KeyModifiers::NONE => b"\x1bOB".to_vec(),
(KeyCode::Right, m) if application_cursor_keys && m == KeyModifiers::NONE => b"\x1bOC".to_vec(),
(KeyCode::Left, m) if application_cursor_keys && m == KeyModifiers::NONE => b"\x1bOD".to_vec(),
```

Modified arrows (Shift/Ctrl/Alt + arrow) fall through to the normal CSI match arms below, which currently use `_` for modifiers — these will need the same `&& !application_cursor_keys` guard (negated) to prevent the old `_` wildcard from catching them before SS3. Alternatively, restructure to check `application_cursor_keys && m == KeyModifiers::NONE` first, then let the existing `(KeyCode::Up, _)` catch everything else.

Update all callers of `key_to_bytes()` to pass the state.

#### C. `events.rs` — Add param to `to_pty_bytes()`

```rust
pub fn to_pty_bytes(&self, application_cursor_keys: bool) -> Vec<u8> {
    ...
    key_to_bytes(&pty_key, application_cursor_keys)
}
```

Update all callers.

#### D. `Pane` trait — Add accessor

```rust
fn is_application_cursor_keys_active(&self) -> bool { false }
```

`impl Pane for Pty`: delegates to `self.tracker`.

#### E. `TerminalComponent::handle_events` — Wire it

```rust
let app_cursor = self.pane.borrow().is_application_cursor_keys_active();
let bytes = key.to_pty_bytes(app_cursor);
```

### Amendment 3: Unify `direct_mode` with `requires_app_routing()` at the Window Boundary

**Problem**: `ScrollViewComponent::on_key` intercepts PageUp/PageDown/Home/End for native scrollbar even when the app is in alternate screen (`less`, `vim`) or has mouse tracking. Users must manually toggle `direct_mode` to bypass — a hidden mechanism.

In `component_context_for`, auto-set `direct_mode = manual_direct_mode || tracker.requires_app_routing()`. ### Amendment 4: Trinary Override + Eliminate Split-Brain

**Problems**:
1. `manual_dm || auto_dm` (OR) can never produce `false` when `auto_dm` is `true` — manual override is powerless.
2. `terminal.rs` directly queries `pane.requires_app_routing()` (lines 125, 539, 596–597), bypassing the unified `ctx.direct_mode()`. Scrollbar state desynchronizes from input routing.

**Fix**: Trinary override on `Window` + unified `ctx.direct_mode()` everywhere.

#### A. Trinary override on `Window` (`entry.rs`)

Change from `direct_mode: bool` to `direct_mode_override: Option<bool>`:
- `None` = automatic (defer to tracker)
- `Some(true)` = force ON
- `Some(false)` = force OFF

Toggle cycles: `None → Some(false) → Some(true) → None`

Keep `set_direct_mode(bool)` as a convenience that wraps `direct_mode_override = Some(value)`.
Update `toggle_direct_mode` to cycle the trinary state.

#### B. Unified resolution in `component_context_for`

```rust
let manual_override: Option<bool> = self.windows.get(key).and_then(|w| w.direct_mode_override());
let auto_dm = self.windows.get(key)
    .map(|w| w.requires_direct_input())
    .unwrap_or(false);
let resolved = manual_override.unwrap_or(auto_dm);
ctx.with_direct_mode(resolved)
```

When user sets override to `Some(false)`, `resolved = false` regardless of `auto_dm`.
When override is `None`, `resolved = auto_dm` (automatic tracking).

#### C. Purge raw pane queries from `terminal.rs`
