# Collapse WmConfig::standalone() into WmConfig::default()

## Goal
Eliminate the redundant `WmConfig::standalone()` preset. `standalone()` and
`default()` return identical configs (`default()` just calls `standalone()`), and
`AppBuilder::new()` already starts from `WmConfig::default()`. Deleting
`standalone()` leaves exactly two clearly-distinct names:
- `WmConfig::default()` — the config value (all features enabled)
- `AppBuilder::new()` — the builder that starts from `default()` (tweak via `.config(...)`)

Also delete `KeyBindings::standalone()` (keybindings.rs:112) — its only caller is
`WmConfig::standalone()`, and it is itself `== KeyBindings::default()`.

## Changes

### 1. `crates/term-wm-core/src/wm_config.rs`
- Move the body of `WmConfig::standalone()` (lines 122–142) into
  `impl Default for WmConfig { fn default() -> Self { ... } }`.
- Delete `pub fn standalone()`.
- Replace `KeyBindings::standalone()` with `KeyBindings::default()` in the moved body.
- Update struct doc (lines 62–63): "The `standalone` preset …" → describe
  `Default` as the full-featured config.

### 2. `crates/term-wm-core/src/keybindings.rs`
