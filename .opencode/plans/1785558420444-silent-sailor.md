# Plan: Clipboard backend orchestration refactor (Option 4)

Status: **Approved** per the AMEND code-review verdict — implements the
"Explicit Static Orchestration with Encapsulated Helpers" directive.

## Goal

Restore readability to `crates/term-wm-pty-engine/src/clipboard.rs`. The
three backends (arboard, temp-file store, OSC 52) are currently woven into
nested if/then blocks inside `Clipboard::set()`/`get()`. Keep `Clipboard` as
a static orchestrator, but extract each backend operation into a private,
named helper so `set()`/`get()` read as short, explicit pipelines — and drop
the false-fallible `Result` from `set()`.

## Design (from review)

- **Reject** trait registries / `Box<dyn ClipboardBackend>` / priority-ordered
  iteration (breaks write-only OSC 52 + mandatory "OSC 52 last" ordering).
- **Reject** wrapping fields into exposed sub-structs (`cb.system`, etc.).
- Keep `Clipboard` as the direct orchestrator owning its current fields;
  dispatch stays static and compile-time verified.
- Extract each backend operation into a **private module-level helper**.
- `set()` becomes infallible: `pub fn set(&mut self, text: &str)`.
- `get()` stays `pub fn get(&mut self) -> Result<String, ClipboardError>`;
  `ClipboardError` remains for `get()` and `set_via_osc52_with_writer`.
- No new `pub` fields. Existing private fields (`arboard`, `temp_store_enabled`,
  `temp_path`, `osc52_limit`) and the `#[cfg(test)] pub osc52_output` capture
  stay as-is.

## Files changed

- `crates/term-wm-pty-engine/src/clipboard.rs`
- `crates/term-wm-pty-engine/src/pty.rs` (call site)
- `crates/term-session-client/src/lib.rs` (call site)

## `clipboard.rs`

### 1. Private module-level helpers

- `fn write_temp_store(path: &Path, enabled: bool, text: &str)` — headless
  temp-file write + tracing (moved out of `set()`).
- `fn write_system_clipboard(clipboard: &mut Option<arboard::Clipboard>, text: &str)`
  — arboard write with `StderrSuppressGuard` + tracing (moved out of `set()`).
- `fn read_temp_store(path: &Path, enabled: bool) -> Option<String>` — temp-file
  read with consume-on-read (`remove_file`) + tracing (moved out of `get()`).
- `fn read_system_clipboard(clipboard: &mut Option<arboard::Clipboard>) -> Result<Option<String>, ClipboardError>`
  — arboard read; `Ok(None)` when no system backend (headless).
- `fn truncate_for_osc52(text: &str, limit: usize) -> &str` — char-boundary
  truncation via `floor_char_boundary` (extracts the escape-sequence-adjacent
  slicing).

### 2. `set()`

```rust
pub fn set(&mut self, text: &str) {
    write_temp_store(&self.temp_path, self.temp_store_enabled, text);
    write_system_clipboard(&mut self.arboard, text);
    let osc52_text = truncate_for_osc52(text, self.osc52_limit);
    #[cfg(not(test))]
    if let Err(e) = set_via_osc52_with_writer(osc52_text, &mut std::io::stdout().lock()) {
        tracing::debug!("clipboard: set OSC 52 to stdout failed ({e})");
    }
    #[cfg(test)]
    {
        let mut buf = Vec::new();
        let _ = set_via_osc52_with_writer(osc52_text, &mut buf);
        self.osc52_output = buf;
    }
}
```

Ordering preserved: temp store → arboard → OSC 52 **last** (host terminal owns
the clipboard). No trailing `Ok(())`.

### 3. `get()`

Rewrite with `read_system_clipboard` + `read_temp_store`, preserving the exact
current semantics:

```rust
pub fn get(&mut self) -> Result<String, ClipboardError> {
    match read_system_clipboard(&mut self.arboard) {
        Ok(Some(text)) => return Ok(text),
        Ok(None) if !self.temp_store_enabled => {
            tracing::debug!("clipboard: get no backends available");
            return Err(ClipboardError::NotAvailable);
        }
        Ok(None) => {}
        Err(e) if !self.temp_store_enabled => {
            tracing::debug!("clipboard: get via arboard failed; temp store inactive");
            return Err(e);
        }
        Err(_) => {}
    }
    read_temp_store(&self.temp_path, self.temp_store_enabled)
        .ok_or(ClipboardError::NotAvailable)
}
```

### 4. Docs

Update the `set()` doc comment to reflect the infallible signature; keep the
OSC 52-last and backend-ordering rationale.

## Behavior preservation

- Write order: temp store → arboard → OSC 52 last. Read order: arboard →
  temp store (consume-on-read).
- Temp store active only when arboard is unavailable (headless/SSH).
- OSC 52 truncation at a UTF-8 char boundary; test capture via `osc52_output`.
- `get()` error semantics unchanged (`Ok`/`NotAvailable`/propagated arboard
  error) — `temp_store_not_written_when_clipboard_present` and the roundtrip
  tests continue to pass unchanged.

# Amendment: Close flagged test gaps

The Option 4 refactor is complete and merged; the review flagged these entities
as untested: `ClipboardError`, `Clipboard::new`, `Osc52Extractor` (`new`/`push`),
and `parser_read_loop` (its OSC 52 relay path). These were dismissed as
"pre-existing mapping gaps" — that dismissal was wrong. Fix by adding direct
tests; the `parser_read_loop` OSC 52 relay needs a small test seam so the relay
can be exercised without touching the real system clipboard or temp store.

## `clipboard.rs`

### 1. Test-only seam for a headless `Clipboard`

Add a `#[cfg(test)]` constructor so sibling modules (pty tests) can build a
deterministic headless handle without widening field visibility or touching the
real clipboard:

```rust
#[cfg(test)]
pub(crate) fn headless_with_temp_path(path: PathBuf) -> Self {
    Self {
        arboard: None,
        temp_store_enabled: true,
        temp_path: path,
        osc52_limit: DEFAULT_MAX_OSC52_BYTES,
        osc52_output: Vec::new(),
    }
}
```

(No `pub` fields are added; `arboard`/`temp_store_enabled` stay private — this
constructor is the seam, consistent with the Option 4 encapsulation directive.)

### 2. New tests

- `clipboard_error_display_messages` — asserts `Display` for all constructible
  variants (`NotAvailable`, `Io(io::Error)`, `Backend(arboard::Error::ContentNotAvailable)`)
  and the `From<io::Error>` / `From<arboard::Error>` conversions.
- `clipboard_new_uses_default_path_and_default_limit` — `Clipboard::new()`
  resolves `temp_path == default_temp_path()` and
  `osc52_limit == DEFAULT_MAX_OSC52_BYTES` (construction only, no I/O).
- `extractor_new_starts_inactive` — `Osc52Extractor::new()` is not active.
- `extractor_push_empty_data_no_activation` — `push(b"", &[])` returns `None`
  and never activates.
- `extractor_clear_resets_in_progress` — partial push activates; `clear()`
  deactivates; a subsequent full sequence still extracts.

## `pty.rs`
