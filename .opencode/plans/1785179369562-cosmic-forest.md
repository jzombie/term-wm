# Plan: Make window header buttons bold + invert hover colors

## Changes

**File:** `crates/term-wm-console/src/draw_plan_renderer.rs`

### Change 1 — Make non-hovered header buttons bold
- Line 1241: add `.add_modifier(Modifier::BOLD)` to non-hovered button style

### Change 2 — Swap fg ↔ bg on hover (invert)
- Currently hovered buttons use `contrast_fg` (white `theme.menu_selected_fg`) as foreground
- Change to use `header_bg.to_ratatui()` as foreground on hover, so fg/bg swap cleanly:
  - Non-hovered: `bg=header_bg, fg=stoplight_fg`
  - Hovered: `bg=stoplight_fg, fg=header_bg`

This simplifies to a single `let hover_bg = match btn.action { ... };` since the fg is always `header_bg` on hover.
