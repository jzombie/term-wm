# Plan: Make window header buttons bold + invert hover colors

## Root cause

`render_cursor_overlay` (line 1913) applies `Modifier::REVERSED` to the cell under
the cursor AFTER `render_window` runs. This means any manual fg↔bg swap in
`render_window` gets undone by REVERSED, making hovered buttons look identical
to non-hovered.

## Fix

Eliminate the `if is_hovered { ... } else { ... }` branch entirely. Use the same
style for all buttons:

```rust
Style::default()
    .bg(header_bg.to_ratatui())
    .fg(stoplight_fg)
    .add_modifier(Modifier::BOLD)
```

The cursor overlay's `Modifier::REVERSED` will naturally swap fg↔bg on hover,
producing the exact inverted look: `bg=stoplight_fg, fg=header_bg, bold`.

## File changed

branching in the button rendering loop (lines 1223-1239).
