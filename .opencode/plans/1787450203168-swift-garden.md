# Show the IPC Channel in the Stop Gateway Daemon Confirmation Dialog

## Context

The Command Palette entry "Stop Gateway Daemon" opens a confirmation dialog
(`TermWmAction::OpenStopGatewayConfirm`). The user asked that the dialog also
show which IPC channel (the resolved gateway channel) the shutdown will target,
matching what the CLI exposes in its `--help` footer
(`gateway_help_line()`: "Persistence gateway: ...").

Flow today:
- Palette item: crates/term-wm-core/src/window/window_manager/command_palette.rs:580
  emits `OpenStopGatewayConfirm`.
- Handler: src/main.rs:989 → `open_stop_gateway_confirm()` at
  src/term_wm_app.rs:1287 builds the body:
  warning line + "Active workspaces · Total windows · Running tasks".
- IPC endpoint source: `gateway_channel_name()` in
  crates/term-session-muxio-service-definitions/src/channel.rs:112, re-exported
  as `term_session::gateway_channel_name` (crates/term-session/src/lib.rs:9).
  Display form example: `gateway/default/administrator/gateway`.

User decisions: show it as a dialog body line only (not the toast); label it
`Channel:`.

## Changes

### 1. src/term_wm_app.rs

- Near the existing `GATEWAY_STOP_*` consts (~line 46-57) add:
  ```rust
  #[cfg(feature = "session-persistence")]
  const GATEWAY_STOP_CHANNEL_LABEL: &str = "Channel";
  ```
- In `open_stop_gateway_confirm()` resolve the channel once and insert a
  second body line between the warning and the counts line:
  ```rust
  let channel = term_session::gateway_channel_name().to_string();
  let body = format!(
      "{GATEWAY_STOP_WARNING}\n{GATEWAY_STOP_CHANNEL_LABEL}: {channel}\nActive workspaces: {workspace_label} · Total windows: {windows} · Running tasks: {tasks}"
  );
  ```
  Resulting body:
  ```
  Stopping the gateway daemon will terminate every workspace session.
  Channel: gateway/default/administrator/gateway
  Active workspaces: 2 · Total windows: 3 · Running tasks: 1
  ```
- Extract the body construction into a small pure helper (private fn in the
  same impl/module) taking `(channel: &str, workspace_label: &str, windows: &str, tasks: &str) -> String`
  so it is unit-testable without rendering infrastructure. Keep comments
  accurate (update the doc comment of `open_stop_gateway_confirm` to mention
  the channel line). No em/en dashes anywhere (AGENTS.md).
