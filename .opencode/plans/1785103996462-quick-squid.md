# Plan: Make `AppRootComponent` extensible via generic parameter

## Problem

`AppRootComponent` is a closed enum — adding custom components requires modifying library source.

## Solution

Generic `<C = NoopComponent>` parameter on `AppRootComponent`, propagated to `TermWmApp`. Core components stay in the `Core(CoreWmComponent)` variant — zero dynamic dispatch, contiguous memory.

## Changes

### 1. `src/components.rs` — Generic enum + macro delegation

```rust
pub enum AppRootComponent<C = NoopComponent> {
    Core(CoreWmComponent),
    Custom(C),
}
```

**Must use macro, not manual impl.** Two options:

**Option A (preferred):** Extend `impl_component_delegate!` to accept optional generic params. Change signature from:
```rust
impl_component_delegate!(AppRootComponent { Core, Custom });
```
to:
```rust
impl_component_delegate!(AppRootComponent<C: Component<TermWmAction>> { Core, Custom });
```
The macro generates:
```rust
impl<C: Component<TermWmAction>> Component<TermWmAction> for AppRootComponent<C> {
    // match self { Self::Core(c) => c.method(...), Self::Custom(c) => c.method(...) }
    // for every trait method
}
```

**Option B:** Write a dedicated `impl_generic_component_delegate!` macro that takes the generic param separately.

Either way, centralizes the delegation and prevents divergence when `Component` trait changes.

### 2. `src/term_wm_app.rs` — Split impl blocks

**Keep constructors on `impl TermWmApp<NoopComponent>`** so existing code type-infers without annotations:

```rust
// Default constructors — C = NoopComponent, no annotation needed
impl TermWmApp<NoopComponent> {
    pub fn new(app_ctx: AppContext) -> Self { ... }
    pub fn bare(app_ctx: AppContext) -> Self { ... }
    pub fn embedded(app_ctx: AppContext) -> Self { ... }
    pub fn from_wm(wm: ..., tx: ...) -> Self { ... }
}
```

**Core logic on the generic block:**

```rust
impl<C: Component<TermWmAction>> TermWmApp<C> {
    pub fn spawn_terminal_window(...) -> io::Result<WindowKey> { ... }
    pub fn init_system_windows(&mut self) { ... }
    pub fn open_window(&mut self, component: AppRootComponent<C>) -> WindowKey { ... }
    pub fn run(self) -> io::Result<()> { ... }
    // etc.
}
```

**Generic constructor for custom component users:**

```rust
impl<C: Component<TermWmAction>> TermWmApp<C> {
    /// Create with explicit custom component type.
    /// Prefer `TermWmApp::new()` when C = NoopComponent.
    pub fn with_custom(app_ctx: AppContext) -> Self {
        let mut app = Self::bare(app_ctx);
        #[cfg(feature = "sys-ui")] {
            app.init_system_windows();
        }
        app
    }
}
```

Wait — `init_system_windows` is in the generic block, so `with_custom` can call it. But `bare()` needs to construct the `WindowManager`. Since `bare` is in `impl TermWmApp<NoopComponent>`, it can't be called from `impl<C>`. 

**Fix:** Move `WindowManager` construction into a non-method associated function that's generic:

```rust
impl<C: Component<TermWmAction>> TermWmApp<C> {
    fn build_wm(app_ctx: AppContext) -> WindowManager<AppRootComponent<C>, LayerComponent, OverlayComponent> {
        AppBuilder::<LayerComponent>::bare()
            .app_ctx(Arc::new(app_ctx))
            .build()
            .expect("standalone build")
    }
}
```

Then both `TermWmApp::<NoopComponent>::bare()` and `TermWmApp::<C>::with_custom()` call `Self::build_wm(ctx)`.

### 3. Macro modification (`crates/term-wm-core/src/macros.rs`)

Extend `impl_component_delegate!` to accept an optional generic parameter clause:

```
Current syntax:
    impl_component_delegate!(AppRootComponent { Core, SvgImage });

New syntax:
    impl_component_delegate!(AppRootComponent<C: Component<TermWmAction>> { Core, Custom });
    // Still works without generics:
    impl_component_delegate!(CoreWmComponent { Terminal, DebugLog, ... });
```

The macro detects whether there's a `<...>` after the enum name and, if so, wraps the generated `impl` block with the generic params.

### 4. `examples/dual_image.rs` — Update

```rust
// Before:
let mut app = TermWmApp::new(AppContext::new("example", "0.0.0"));
let left_key = app.open_window(AppRootComponent::SvgImage(left));

// After:
let mut app: TermWmApp<SvgImageComponent> = TermWmApp::with_custom(AppContext::new("example", "0.0.0"));
let left_key = app.open_window(AppRootComponent::Custom(left));
```
