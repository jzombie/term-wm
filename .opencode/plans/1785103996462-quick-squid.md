# Plan: Make `AppRootComponent` extensible via generic parameter

## Problem

`AppRootComponent` is a closed enum — adding custom components requires modifying library source.

## Solution

Generic `<C = NoopComponent>` parameter on `AppRootComponent`, propagated to `TermWmApp`. Core components stay in `Core(CoreWmComponent)` — zero dynamic dispatch, contiguous memory. A `impl TermWmApp<NoopComponent>` facade preserves backward-compatible type inference for `TermWmApp::new(ctx)`.

## Changes

### 1. `crates/term-wm-core/src/macros.rs` — New macro arm

Decouple param identifier from trait bound so the expansion generates valid Rust:

```rust
macro_rules! impl_component_delegate {
    // Generic variant (new)
    ($enum_name:ident, param: $param:ident, bound: $bound:path, variants: { $($variant:ident),* $(,)? }) => {
        impl<$param: $bound> $crate::components::Component<$crate::actions::TermWmAction>
            for $enum_name<$param>
        {
            // match self { Self::$variant(c) => c.method(...),* }
            // identical body to the original arm
        }
    };
    // Concrete variant (original, unchanged)
    ($enum_name:ident { $($variant:ident),* $(,)? }) => {
        impl $crate::components::Component<$crate::actions::TermWmAction> for $enum_name {
            // identical body
        }
    };
}
```

Usage:
```rust
impl_component_delegate!(AppRootComponent, param: C, bound: Component<TermWmAction>, variants: { Core, Custom });
```

### 2. `src/components.rs` — Generic enum + macro

```rust
pub enum AppRootComponent<C = NoopComponent> {
    Core(CoreWmComponent),
    Custom(C),
}

impl_component_delegate!(AppRootComponent, param: C, bound: Component<TermWmAction>, variants: { Core, Custom });
```

Remove the `use term_wm_ui_components::svg_image::SvgImageComponent;` import (no longer needed as a direct variant).

### 3. `src/term_wm_app.rs` — Generic block + facade

**Generic block** — single source of truth for all construction and runtime logic:

```rust
impl<C: Component<TermWmAction>> TermWmApp<C> {
    // ---- Core constructors ----
    #[cfg(feature = "sys-ui")]
    fn new_inner(app_ctx: AppContext) -> Self { /* same body as current TermWmApp::new */ }
    fn bare_inner(app_ctx: AppContext) -> Self { /* same body as current TermWmApp::bare */ }
    fn embedded_inner(app_ctx: AppContext) -> Self { /* same body */ }
    pub fn from_wm(wm: ..., tx: ...) -> Self { /* same body */ }

    // ---- Runtime methods (same as today) ----
    pub fn spawn_terminal_window(...) -> io::Result<WindowKey> { ... }
    pub fn init_system_windows(&mut self) { ... }
    pub fn open_window(&mut self, component: AppRootComponent<C>) -> WindowKey { ... }
    pub fn run(self) -> io::Result<()> { ... }
    pub fn render_app(&mut self, ...) { ... }
    // ... etc
}
```

**Facade block** — zero domain logic, pure forwarders for type inference:

```rust
impl TermWmApp<NoopComponent> {
    pub fn new(app_ctx: AppContext) -> Self { Self::new_inner(app_ctx) }
    pub fn bare(app_ctx: AppContext) -> Self { Self::bare_inner(app_ctx) }
    pub fn embedded(app_ctx: AppContext) -> Self { Self::embedded_inner(app_ctx) }
}
```

The `WindowManagerHost` impl uses the generic type:

```rust
impl<C: Component<TermWmAction>> WindowManagerHost<AppRootComponent<C>, LayerComponent, OverlayComponent>
    for TermWmApp<C>
{ ... }
```

**Match patterns in `spawn_terminal_window`:** `component_for_key_mut` still returns `&mut AppRootComponent<C>`. The `Core(CoreWmComponent::Terminal(scroll_view))` pattern works unchanged. The `_other` catch-all also covers `Custom(...)` variants.

### 4. `examples/dual_image.rs`

```rust
// Before:
fn main() -> io::Result<()> {
    let mut app = TermWmApp::new(AppContext::new("example", "0.0.0"));
    let mut left = SvgImageComponent::new();
    left.set_keep_aspect(true);
    left.set_colorize(true);
    left.load_from_path(&paths[0])?;
    let left_key = app.open_window(AppRootComponent::SvgImage(left));

// After:
fn main() -> io::Result<()> {
    let mut app: TermWmApp<SvgImageComponent> = TermWmApp::new(AppContext::new("example", "0.0.0"));
    let mut left = SvgImageComponent::new();
    left.set_keep_aspect(true);
    left.set_colorize(true);
    left.load_from_path(&paths[0])?;
    let left_key = app.open_window(AppRootComponent::Custom(left));
```
