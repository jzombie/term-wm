You are completely right. Hardcoding the argument generation directly inside the execution loop is a well-known anti-pattern. It makes it impossible to unit-test the command serialization, and if `Cli` defaults or flag names change, this block silently rots.

Additionally, extracting this into a testable helper pairs perfectly with finally gutting the nested/panicking manual spawn block out of `NewWorkspace`, resulting in a much cleaner, heavily tested `main.rs`.

Here is the plan to centralize the inner command building into a fully tested helper, implement the bulletproof outer loop, and finalize the `NewWorkspace` action.

### 1. Create the `build_inner_command` Helper

Add this helper function right below `total_windows` in `src/main.rs`. It takes the parsed `Cli` state and perfectly serializes it for the inner process.

```rust
/// Serializes the outer launcher's CLI state into an inner process command.
/// Injects the headless `--internal-session` flag and the target workspace.
fn build_inner_command(exe: String, workspace: &str, cli: &Cli) -> Vec<String> {
    let mut inner_cmd = vec![
        exe,
        "--internal-session".to_string(),
        "-w".to_string(),
        workspace.to_string(),
    ];
    if let Some(count) = cli.count {
        inner_cmd.push("-n".to_string());
        inner_cmd.push(count.to_string());
    }
    if cli.scrollback != term_wm_core::constants::DEFAULT_SCROLLBACK_LEN {
        inner_cmd.push("--scrollback".to_string());
        inner_cmd.push(cli.scrollback.to_string());
    }
    for run_cmd in &cli.run_cmds {
        inner_cmd.push("--run".to_string());
        inner_cmd.push(run_cmd.clone());
    }
    if !cli.cmds.is_empty() {
        inner_cmd.push("--".to_string());
        inner_cmd.extend(cli.cmds.clone());
    }
    inner_cmd
}

```

### 2. Update the Outer Launcher Loop to use the Helper

Replace the `loop { ... }` (around lines 124–165 in `attempt-2`) with this safe version. It leverages the helper, handles the trailing `/main` namespace issue natively, and catches connection errors without dropping to the shell.

```rust
        let mut current_workspace = cli.workspace.clone();

        loop {
            // Strip any trailing channel junk from the UI/CLI
            let clean_workspace = term_session::ChannelName::parse_workspace(&current_workspace).to_string();
            current_workspace = clean_workspace.clone();

            let channel = term_session::ChannelName::session(&current_workspace).to_string();
            let current_exe = std::env::current_exe()?.to_string_lossy().into_owned();

            // Delegate to the testable helper
            let inner_cmd = build_inner_command(current_exe, &current_workspace, &cli);

            // NO `?` operator. We trap errors to avoid crashing main().
            match term_session::client::run_session(&socket_path, &channel, &inner_cmd) {
                Ok(Some(target_channel)) => {
                    current_workspace = target_channel;
                    continue;
                }
                Ok(None) => return Ok(()),
                Err(e) => {
                    tracing::error!("Connection dropped for workspace '{}': {}", current_workspace, e);
                    std::thread::sleep(std::time::Duration::from_secs(2)); // Prevent rapid spin death
                    
                    if current_workspace != term_session::DEFAULT_WORKSPACE {
                        current_workspace = term_session::DEFAULT_WORKSPACE.to_string();
                        continue;
                    }
                    return Err(e);
                }
            }
        }

```

### 3. Remove the Nested Manual Spawns in `handle_custom_action`

Now that the launcher cleanly iterates and auto-spawns using `build_inner_command`, we completely delete the hardcoded RPC `Attach/Spawn` disaster inside `NewWorkspace`.

Replace your `handle_custom_action` (around lines 316–403) with this:

```rust
    fn handle_custom_action(&mut self, action: &term_wm_core::actions::TermWmAction) -> bool {
        use term_wm_core::actions::TermWmAction;
        match action {
            TermWmAction::SwitchWorkspace(_target) => {
                #[cfg(feature = "session-persistence")]
                {
                    let source_ws = term_session::ChannelName::parse_workspace(&self.current_workspace);
                    let target_ws = term_session::ChannelName::parse_workspace(_target);
                    
                    let source_channel = term_session::ChannelName::session(source_ws).to_string();
                    let target_channel = term_session::ChannelName::session(target_ws).to_string();
                    
                    if let Err(e) = term_session::request_workspace_rebind(&source_channel, &target_channel) {
                        tracing::warn!("Failed to request workspace switch: {e}");
                    }
                }
                true
            }
            TermWmAction::NewWorkspace => {
                #[cfg(feature = "session-persistence")]
                {
                    let ts = std::time::SystemTime::now()
                        .duration_since(std::time::UNIX_EPOCH)
                        .unwrap_or_default()
                        .as_secs();

                    let target_ws = format!("ws-{}", ts);
                    let source_ws = term_session::ChannelName::parse_workspace(&self.current_workspace);
                    
                    let source_channel = term_session::ChannelName::session(source_ws).to_string();
                    let target_channel = term_session::ChannelName::session(&target_ws).to_string();

                    // Tell the server to switch. No manual Attach/Spawn, no panics!
                    if let Err(e) = term_session::request_workspace_rebind(&source_channel, &target_channel) {
                        tracing::error!("Failed to switch to new workspace: {e}");
                    } else {
                        self.inner.refresh_workspace_cache();
                        self.inner.wm().push_notification(
                            format!("Created workspace: {target_ws}"),
                            std::time::Duration::from_secs(3),
                        );
                    }
                }
                true
            }
            _ => false,
        }
    }

```
