# Plan: Native Muxio Workspace Switching

## Context

The workspace switching mechanism was previously implemented via raw Unix sockets and temp files, bypassing the Muxio transport. The service definitions were reverted (commit `0b94c471`) but stale references remain in `session_server.rs` and `main.rs`, causing compile failures. This plan re-implements workspace switching as proper Muxio RPCs, using a facade in `term-session` so `term-wm` never touches Muxio directly.

## Architecture

```
Inner TUI process                    Server                         Outer viewer (launcher)
       │                              │                                  │
       │── RebindWorkspace ──────────>│                                  │
       │   (term-session facade)      │── OnWorkspaceRebind ───────────>│
       │                              │   (push to viewer conn)         │
       │  [continues running]         │                           run_session returns
       │                              │                           Ok(Some("target"))
       │                              │                                  │
       │                              │                           launcher loop
       │                              │                           reconnects to
       │                              │                           target/main
```

## Changes

### 1. Service definitions — `crates/term-session-muxio-service-definitions/src/methods.rs`

Add two RPC methods after `OnPtyResized` (line 516):

- **`RebindWorkspace`** — client→server RPC. Input: `RebindWorkspaceRequest { source_channel, target }`. Wire ID: `session.rebind_workspace`.
- **`OnWorkspaceRebind`** — server→client push. Input: `OnWorkspaceRebindRequest { target }`. Wire ID: `session.on_workspace_rebind`.

Both use the standard `RpcMethodPrebuffered` boilerplate (bitcode encode/decode).

**`crates/term-session-muxio-service-definitions/src/lib.rs`** — add `RebindWorkspace`, `RebindWorkspaceRequest`, `OnWorkspaceRebind`, `OnWorkspaceRebindRequest` to the `pub use methods::{...}` block.

### 2. Server — `crates/term-session-server/src/session_server.rs`

**Imports (lines 13–19):** Replace stale `RequestWorkspaceSwitch`, `WorkspaceRebind` with `RebindWorkspace`, `OnWorkspaceRebind`, `OnWorkspaceRebindRequest`.

**Handler (lines 1301–1342):** Replace the `RequestWorkspaceSwitch` handler with `RebindWorkspace`:
- Decode `RebindWorkspaceRequest`
- Find all connections attached to `source_channel`
- For each, spawn a task pushing `OnWorkspaceRebind` with the target

### 3. Client — `crates/term-session-client/src/lib.rs`

**Return type:** Change `run_session` from `io::Result<()>` to `io::Result<Option<String>>`.

**New imports (line 21–24):** Add `OnWorkspaceRebind`, `OnWorkspaceRebindRequest` to the `use term_session_muxio_service_definitions::{...}` block.

**Handler registration (after `OnPtyResized` registration, ~line 323):** Register `OnWorkspaceRebind::METHOD_ID` on the client endpoint. The handler decodes the request and stores the target in an `Arc<Mutex<Option<String>>>`.

**Event loop check (before `pane.has_exited()` at line 716):**
```rust

    return Ok(Some(target));

```

**Exit on session exit (line 717):** Change `return Ok(())` to `return Ok(None)`.

### 4. Facade — `crates/term-session/src/lib.rs`

Add `request_workspace_rebind` next to `list_channels` and `kill_client`:

```rust
/// Request the gateway to rebind all viewers attached to `source_channel`
/// over to the `target` workspace.
pub fn request_workspace_rebind(source_channel: &str, target: &str) -> io::Result<()> {
    with_gateway(|client| async move {
        use term_session_muxio_service_definitions::{RebindWorkspace, RebindWorkspaceRequest};
        use muxio_tokio_rpc_ipc_client::RpcCallPrebuffered;

        RebindWorkspace::call(
            &*client,
            RebindWorkspaceRequest {
                source_channel: source_channel.to_string(),
                target: target.to_string(),
            },
        )
        .await
    })?
    .map_err(|e| io::Error::other(format!("rebind workspace: {e}")))
}
```

### 5. Launcher — `src/main.rs`

**Remove import (line 23):** Delete `use term_session::ControlEvent;`

**Launcher loop (lines 124–171):** Replace `run_session_with_control` + `ControlEvent` match with:
```rust
match term_session::client::run_session(&socket_path, &channel, &inner_cmd)? {
    Some(target_workspace) => {
        current_workspace = target_workspace;
        continue;
    }
    None => return Ok(()),
}
```

**`SwitchWorkspace` handler (lines 320–331):** Replace `set_current_workspace` mutation with the facade call:
```rust
TermWmAction::SwitchWorkspace(target) => {
    #[cfg(feature = "session-persistence")]
    {
        let source_channel = format!("{}/main", self.current_workspace);
        if let Err(e) = term_session::request_workspace_rebind(&source_channel, target) {
            tracing::warn!("Failed to request workspace switch: {e}");
        }
    }
    true
}
```

No `set_current_workspace` call — the inner process is permanently bound to its channel.

**`App::new_with` (lines 256–263):** Add `set_current_workspace` propagation after `from_wm`:
```rust
let inner = TermWmApp::from_wm(wm, pty_wakeup_tx.clone());
#[cfg(feature = "session-persistence")]
inner.set_current_workspace(workspace.clone());
```
