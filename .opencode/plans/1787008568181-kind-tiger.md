# Plan: Centralize Channel/Workspace Constants and Add Tests

## Context

Hardcoded `"{}/main"`, `.split('/')`, `.strip_suffix("/main")`, and `"default"` appear 20+ times across `main.rs`, `term_wm_app.rs`, and `channel.rs`. The canonical `ChannelName` parser exists but is bypassed. This causes the multi-slash crash and makes the code fragile.

## Changes

### 1. Add constants and helpers to `crates/term-session-muxio-service-definitions/src/channel.rs`

```rust
/// Default workspace name (namespace when no `/` is present).
pub const DEFAULT_WORKSPACE: &str = "default";

/// Default session channel name within a workspace.
pub const SESSION_CHANNEL_NAME: &str = "main";
```

Add helper methods to `ChannelName`:

```rust
impl ChannelName {
    /// Construct a session channel for the given workspace.
    pub fn session(workspace: &str) -> Self {
        Self {
            namespace: workspace.to_string(),
            name: SESSION_CHANNEL_NAME.to_string(),
        }
    }

    /// Extract the workspace (namespace) from a session channel.
    pub fn workspace(&self) -> &str {
        &self.namespace
    }
}
```

Export `DEFAULT_WORKSPACE` and `SESSION_CHANNEL_NAME` from `lib.rs`.

### 2. Update `crates/term-session/src/lib.rs`

Add constants:

```rust
pub const DEFAULT_WORKSPACE: &str = term_session_muxio_service_definitions::DEFAULT_WORKSPACE;
pub const SESSION_CHANNEL_NAME: &str = term_session_muxio_service_definitions::SESSION_CHANNEL_NAME;
```

Replace `DEFAULT_CHANNEL` usage with `ChannelName::session(DEFAULT_WORKSPACE).to_string()`.

### 3. Update `src/main.rs`

Replace all `format!("{}/main", ...)` with `ChannelName::session(&workspace).to_string()`.

Replace all `.strip_suffix("/main")` with `ChannelName::parse(&target).map(|c| c.namespace)` or similar.

Replace `split('/').next().unwrap_or("default")` with `ChannelName::parse(&cli.workspace).map(|c| c.namespace).unwrap_or(DEFAULT_WORKSPACE)`.

Specifically:

- **Line 97** (`cli.workspace.split('/').next()...`): Use `ChannelName::parse`
- **Line 120** (`format!("{}/main", workspace)`): Use `ChannelName::session(&workspace)`
- **Line 131** (`.strip_suffix("/main")`): Use `ChannelName::parse` to extract workspace
- **Line 134** (`format!("{}/main", current_workspace)`): Use `ChannelName::session`
- **Line 327** (`format!("{}/main", self.current_workspace)`): Use `ChannelName::session`
- **Line 328** (`.strip_suffix("/main")` on target): Use `ChannelName::parse` on target
- **Line 343** (`format!("ws-{}", ts)`): Extract `WORKSPACE_PREFIX` constant
- **Line 344** (`format!("{}/main", self.current_workspace)`): Use `ChannelName::session`

### 4. Update `src/term_wm_app.rs`

- **Line 268** (`current_workspace: "default".to_string()`): Use `DEFAULT_WORKSPACE`
- **Line 290** (`ch.name.split('/').next()...`): Use `ChannelName::parse(&ch.name).map(|c| c.namespace)`

### 5. `crates/term-wm-core/src/window/window_manager/mod.rs`

Line 940 uses `"default"` as a fallback workspace name. Since `term-wm-core` doesn't depend on the session crate, define a local `DEFAULT_WORKSPACE` constant here (or accept workspace as a parameter). This is the only place in the WM core that needs it.

### 6. Add tests

In `channel.rs`, add tests for:
- `ChannelName::session("ws-123")` produces `"ws-123/main"`
- `ChannelName::session("default")` produces `"default/main"`
- `ChannelName::parse("ws-123/main")` → namespace=`"ws-123"`, name=`"main"`
- `ChannelName::parse("ws-123/main/main")` → error (3 segments)
- `ChannelName::parse("default")` → namespace=`"default"`, name=`"default"`
- `ChannelName::workspace()` returns namespace

In `main.rs` (or a new test module), add tests for:
- Workspace normalization: `"ws-123/main"` → `"ws-123"`
- Channel construction: `"ws-123"` → `"ws-123/main"`
