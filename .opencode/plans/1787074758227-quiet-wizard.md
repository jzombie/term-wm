# Environment-scoped persistence gateway (`TERM_WM_ENV`)

## Goal
Separate the term-wm persistence gateway endpoint by **environment** so development
builds never attach to / tear down production sessions, while keeping the shared
`term-wm` family namespace (so `term-wm` and `term-session` keep interoperating on
the same gateway) and exposing a getter that BOTH binaries' `--help` menus display.

Confirmed with the user:
- **Per-env only** — namespace stays the shared family; only the environment
  segment is added: `term-wm/<env>/<user>/gateway`. term-wm ↔ term-session
  interop is preserved.
- **Env detection** = build profile default (`cfg!(debug_assertions)` → `dev`,
  release → `prod`) **plus** a `TERM_WM_ENV=dev|prod|test` override. `TERM_WM_GATEWAY`
  remains the wholesale top-priority override.
- **No hardcoded `"term-wm"` literals** in code/tests — a single
  `GATEWAY_NAMESPACE` const in `term-wm-config` is the only place the literal lives.

## Verified facts
- clap 4.6.6 (registry source checked): `Command::after_help(String)` works
  (resettable `StyledStr`); long help falls back to `after_help` when
  `after_long_help` unset → one call covers both `-h` and `--help`.
  `Parser::parse()` internally = `command().get_matches()` +
  `FromArgMatches::from_arg_matches_mut(&mut matches)`; the derive still
  implements `Parser`, so existing `Cli::parse_from([...])` tests keep working.
  `render_long_help()` / `write_long_help()` are NOT deprecated in this pin.
- `gateway_channel_name()` result is only ever `.to_string()`-ed and passed to
  `RpcIpcClient::new` / `probe_ipc_endpoint` — never re-parsed, so the 3-segment
  name `term-wm/dev/<user>/gateway` is safe.
- `crates/term-session-muxio-service-definitions` does NOT yet depend on
  `term-wm-config`; `term-wm-config` IS a workspace member + root dep.
- `term-wm-config/src/runtime.rs` won't compile its tests (uses
  `RuntimeConfig::default()`; no `Default` impl) — in-flight blocker; must be
  fixed before `cargo test -p term-wm-config` can run.
- `daemon_tests.rs` and session test helpers inject unique `TERM_WM_GATEWAY` →
  unaffected by the default-gateway change.

### 1. `crates/term-wm-config/src/env.rs` — namespace const + env resolver
Add after `NO_SESSION_PERSISTENCE_ENV_VAR` (env.rs:12):

```rust
use std::fmt;

/// Default gateway namespace (the only place the family literal lives).
pub const GATEWAY_NAMESPACE: &str = "term-wm";

/// Active environment override (`dev`/`prod`/`test`, case-insensitive).
pub const ENVIRONMENT_ENV_VAR: &str = "TERM_WM_ENV";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Environment { Dev, Prod, Test }

impl Environment {
    /// Canonical lowercase identifier used in channel names.
    pub fn as_str(&self) -> &'static str {
        match self { Environment::Dev => "dev", Environment::Prod => "prod", Environment::Test => "test" }
    }
}
impl fmt::Display for Environment {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result { f.write_str(self.as_str()) }
}

/// Compile-time default: dev in debug builds, prod in release.
pub fn default_environment() -> Environment {
    if cfg!(debug_assertions) { Environment::Dev } else { Environment::Prod }
}

/// Parse a user value (case-insensitive, trimmed). Unknown/empty → None.
pub fn parse_environment(raw: &str) -> Option<Environment> {
    match raw.trim().to_ascii_lowercase().as_str() {
        "dev" => Some(Environment::Dev),
        "prod" => Some(Environment::Prod),
        "test" => Some(Environment::Test),
        _ => None,
    }
}

/// `TERM_WM_ENV` when set and valid, else [`default_environment`].
pub fn active_environment() -> Environment {
    std::env::var(ENVIRONMENT_ENV_VAR)
        .ok()
        .and_then(|raw| parse_environment(&raw))
        .unwrap_or_else(default_environment)
}
```

## Migration note (document, do not code)
An existing daemon bound to the legacy `term-wm/<user>/gateway` (no env segment)
is unreachable by the new binaries (the `TERM_WM_GATEWAY` override is `ns/name`
single-slash and cannot express the old 3-segment key). Stop it manually:
`kill $(pgrep -f "term-session --daemon")` / `taskkill /IM term-session.exe /F`
(existing recovery path in `crates/term-session/README.md`). Deliberately NO
legacy-name fallback probing — it would reintroduce cross-build coupling.
