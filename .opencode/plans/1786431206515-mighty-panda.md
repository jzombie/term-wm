## A2. `StderrSuppressGuard` thread safety (SEV-2.1)

The guard now lives in `term-sys-io`, but the design is unchanged from the earlier plan:
`dup2` on `STDERR_FILENO` is process-global; `arboard` calls can race with `tracing` logging
or parallel tests. Serialize with a process-global mutex held for the guard's lifetime:

```rust
/// Serialises process-global stderr redirection across threads.
static STDERR_MUTEX: std::sync::Mutex<()> = std::sync::Mutex::new(());

#[cfg(unix)]
pub struct StderrSuppressGuard {
    saved_fd: libc::c_int,
    _lock: std::sync::MutexGuard<'static, ()>,   // field order: Drop restores fd first, then releases lock
}
```

- `new()` acquires the lock **first** (poison-recover via `.unwrap_or_else(|e| e.into_inner())`),
  then performs the existing open/dup/dup2 dance. On early `None` return (open failure) the lock
  drops naturally.
- `Drop` restores the original fd (existing body); the `_lock` field drops after `Drop::drop`,
  releasing the mutex post-restore.
- Apply the same lock field to the `#[cfg(windows)]` impl. The fallback impl
  (`#[cfg(not(any(unix, windows)))])` performs no redirection → no lock needed.
- The moved test runs single-threaded and is unaffected.

## A3. Standalone binary `src/bin/term-copy.rs` — flagless, backend cascade

**Amendment (user):** the binary is renamed `term-copy` ("term-clipboard doesn't say 'hey, this
copies'"), and the `--osc52` flag is **removed** — the CLI is fully flagless. `set()` fans out
to every available backend automatically (A5), so it works locally and over SSH with no flags.

```rust
use std::io::Read;
use std::path::PathBuf;
use std::process::ExitCode;

use clap::Parser;
use term_clipboard::Clipboard;

/// Copy text to the clipboard, cross-platform.
#[derive(Parser, Debug)]
#[command(
    name = env!("CARGO_BIN_NAME"),
    version = env!("CARGO_PKG_VERSION"),
    about = env!("CARGO_PKG_DESCRIPTION"),
    long_about = concat!(
        env!("CARGO_PKG_NAME"), " ", env!("CARGO_PKG_VERSION"), ": ",
        env!("CARGO_PKG_DESCRIPTION"),
        "\n\nReads UTF-8 text from FILE (or stdin when omitted) and copies it to the ",
        "clipboard.  Writes to every available backend in order: the system clipboard, ",
        "the shared in-memory buffer, and OSC 52 to the host terminal — so it works ",
        "locally and over SSH with no flags.  Only UTF-8 text is supported; binary ",
        "input is an error (exit code 1)."
    ),
)]
struct Cli {
    /// Text to copy, read as UTF-8.  When omitted, reads from stdin.
    file: Option<PathBuf>,
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let text = match read_input(cli.file) {
        Ok(text) => text,
        Err(msg) => {
            eprintln!("term-copy: {msg}");
            return ExitCode::FAILURE;
        }
    };
    let mut cb = Clipboard::new();
    cb.set(&text);
    ExitCode::SUCCESS
}
```

- `Cli::parse()`: single optional `[FILE]` positional (or stdin when absent); `-h`/`--help` and
  `--version` handled automatically. `name = env!("CARGO_BIN_NAME")` renders the **binary**
  name `term-copy` (Cargo sets `CARGO_BIN_NAME` when compiling a bin target), not the package
  name; `about`/`version` come from cargo vars like the other binaries.
- `set()` is infallible (fan-out logs per-backend failures), so success always exits `0`.
- **Exit codes:** clap parse errors (extra positional, unknown flag) exit **`2`**;
  `--help`/`--version` exit `0`; runtime errors below exit **`1`**.
- No `--osc52` and no `set_via_osc52_with_writer` in the binary — OSC 52 is just one backend
  in the cascade (A5). Over SSH the arboard backend fails harmlessly and the OSC 52 backend
  emits to stdout automatically.

Read path (unchanged shape, takes `Option<PathBuf>`):
- File: `File::open(path)` **first** (validates readability; missing/unreadable → clean
  `error: cannot read <path>: <io>` to stderr, exit `1`), then `read_to_string`.
- Stdin: `std::io::read_to_string(std::io::stdin().lock())`.
- Either source producing **non-UTF-8** → `error: input is not valid UTF-8`, exit `1`.

Non-UTF-8 file *contents* are out of scope (document in `long_about`); non-UTF-8
*filenames* are fine (`PathBuf` + `to_string_lossy` in error messages).

## A5. Backend registry system (replaces the imperative pipeline)

**Amendment (user):** the hardcoded imperative pipeline inside `Clipboard` (`set()` =
`if let`-chain writing the shared buffer, calling `write_system_clipboard`, then conditionally
emitting OSC 52) is replaced by a **pluggable backend registry** — a public trait + concrete
backends + a `Clipboard` that composes them. This is what lets the `term-copy` CLI be flagless:
`set()` simply fans out to every registered backend.

### Trait

```rust
/// A pluggable clipboard backend.  `Clipboard` composes backends and fans
/// `set()` out to all of them in registration order; `get()` returns the
/// first backend that can supply text.
pub trait ClipboardBackend: Send {
    /// Best-effort write.  `Err` is logged by the caller; the fan-out continues.
    fn set(&mut self, text: &str) -> Result<(), ClipboardError>;
    /// Read the clipboard.  `Ok(None)` when this backend cannot supply text
    /// (e.g. OSC 52 is write-only); `Err` on backend failure.
    fn get(&mut self) -> Result<Option<String>, ClipboardError>;
    /// Stable identifier for logging / diagnostics.
    fn name(&self) -> &'static str;
}
```

### Concrete backends

- **`ArboardBackend { clipboard: Option<arboard::Clipboard> }`** — `new()` probes
  `arboard::Clipboard::new().ok()` (None headless/SSH). `set` wraps `cb.set_text` in
  `term_sys_io::StderrSuppressGuard`; `get` returns `cb.get_text()`. Absorbs the logic of the
  deleted `write_system_clipboard` / `read_system_clipboard` helpers.
- **`InMemoryBackend { shared: Arc<RwLock<Option<String>>> }`** — Tier-1 copy→paste round-trip.
  `set` writes the buffer (poison-tolerant `if let Ok`); `get` reads with poison recovery.
- **`Osc52Backend { enabled: bool, limit: usize }`** — write-only. `set` truncates via
  `truncate_for_osc52` then writes via `set_via_osc52_with_writer` to `stdout().lock()`
  (captured to `#[cfg(test)] output: Vec<u8>` in tests); `get` returns `Ok(None)`.

### `Clipboard` composition

```rust
pub struct Clipboard { backends: Vec<Box<dyn ClipboardBackend>> }

impl Clipboard {
    pub fn new() -> Self { Self::with_config(ClipboardConfig::default()) }

    pub fn with_config(config: ClipboardConfig) -> Self {
        Self::with_backends(default_backends(config))
    }

    /// Headless seam used by pty-engine tests: in-memory + OSC 52, no arboard.
    pub fn with_shared_buffer(buffer: Arc<RwLock<Option<String>>>) -> Self {
        Self::with_backends(vec![
            Box::new(InMemoryBackend::new(buffer)),
            Box::new(Osc52Backend::new(ClipboardConfig::default())),
        ])
    }

    /// Compose a clipboard from a custom backend list (public — the "actual
    /// backend system" entry point).
    pub fn with_backends(backends: Vec<Box<dyn ClipboardBackend>>) -> Self {
        Self { backends }
    }

    pub fn set(&mut self, text: &str) {
        for backend in &mut self.backends {
            if let Err(e) = backend.set(text) {
                tracing::debug!("clipboard: backend {} set failed ({e})", backend.name());
            }
        }
    }

    pub fn get(&mut self) -> Result<String, ClipboardError> {
        for backend in &mut self.backends {
            match backend.get() {
                Ok(Some(text)) => return Ok(text),
                Ok(None) => {}
                Err(e) => tracing::debug!("clipboard: backend {} get failed ({e})", backend.name()),
            }
        }
        Err(ClipboardError::NotAvailable)
    }
}

/// Default order: arboard, in-memory, OSC 52 last (host terminal becomes the
/// final X11 owner).  `set()` fans out in this order (in-memory is always
/// written — the loop never aborts on a backend error); `get()` resolves
/// arboard first (authoritative), then in-memory, and OSC 52 never yields.
fn default_backends(config: ClipboardConfig) -> Vec<Box<dyn ClipboardBackend>> {
    vec![
        Box::new(ArboardBackend::new()),
        Box::new(InMemoryBackend::new(default_shared_buffer())),
        Box::new(Osc52Backend::new(config)),
    ]
}
```

### Semantics preserved (behavior-compatible)

- `set()` infallible fan-out to all backends; per-backend failures logged, never fatal.
- `get()` = arboard (authoritative, real system clipboard) → in-memory fallback; `Err::NotAvailable`

- OSC 52 emitted **last** so the host terminal becomes the final owner (unchanged ordering intent).
- Public surface unchanged for all external consumers (`new`, `set`, `get`, `with_shared_buffer`,

```rust
    line
};
result.push_str(&line);

// SEV-1.1: `viewport_row` (line 933) is the viewport-relative index; the
// bounds check is defensive — `row_wrapped` is OOB-safe (returns false).
if absolute_row < vt100_end_row
    && viewport_row < viewport_rows
    && !wrapped
{
    result.push('\n');
}
```

Notes:
- `row_wrapped` is queried per-row **after** the existing `set_scrollback()` pagination, so it
  is correct for both viewport and scrollback selections.
- SEV-1.2 trim is defensive: the fork's `Row::write_contents` already strips trailing empty
  cells, so in the current `contents_between` path it is normally a no-op. It guards against
  grid padding leaking via any raw-row path and against internal gap spaces at a wrap seam.
  Tradeoff: a wrapped row whose *actual* content ends in spaces would lose them (matches the
  "join with nothing" behavior of mainstream terminals).
- Join-with-nothing is unconditional (no config flag). Genuine `\r\n` rows keep their `\n`
  because those rows are `wrapped == false`.
