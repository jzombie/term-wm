# Plan: Clear screen immediately before term-wm exit (issue #262)

## Goal
When term-wm exits, clear the screen (erase the alt-screen UI content) immediately
before leaving alternate screen mode, so the terminal returns cleanly to the shell.

## Where the change goes
`ConsoleRenderTarget::exit()` — the single production teardown path. It is invoked
from `src/main.rs:81`, `src/term_wm_app.rs:505`, and via the `Drop` impl
(`console_render_target.rs:209-213`), so the fix covers the normal exit path and
panic/error exits. (`repair()` overrides `exit` behavior and is unaffected.)

File: `crates/term-wm-console/src/console_render_target.rs`

## Implementation
In `RenderTarget::exit()` (lines 150-183), add `Clear(ClearType::All)` to the
always-written `execute!` block so it is emitted immediately before
`LeaveAlternateScreen`:

```rust
// write_ansi() — always write so tests verify the byte stream.
execute!(
    self.terminal.backend_mut(),
    DisableBracketedPaste,
    Clear(ClearType::All),
    LeaveAlternateScreen,
)?;
```

- `Clear` / `ClearType` are already imported (line 4) and used in `repair()`
  (line 204) — no new imports or crossterm features needed.
- Emits `\x1b[2J` (erase display) before `\x1b[?1049l` (leave alt screen).
- Cross-platform: `Clear` is a standard crossterm command that works on
  Windows (ANSI or winapi path) as well as macOS/Linux.
- Deliberately does NOT add `ClearType::Purge` (`\x1b[3J`, clears primary-screen
  scrollback): that would erase the user's pre-term-wm shell scrollback history.
  The issue only asks to clear the screen before leaving alt-screen mode.

## Test
Add a test in the existing `#[cfg(test)] mod tests` at the bottom of the same
file, mirroring `exit_writes_bracketed_paste_disable` (uses `new_capturing()`,
`enter()` first, `writer.clear()`, then asserts on `exit()`'s byte stream):

```rust
#[test]
fn exit_writes_clear_screen_before_leave_alternate_screen() {
    let (mut rt, writer) = ConsoleRenderTarget::new_capturing();
    rt.enter().expect("enter must succeed");
    writer.clear();
    rt.exit().expect("exit must succeed");
    let bytes = writer.bytes();
    let clear = bytes
        .windows(b"\x1b[2J".len())
        .position(|w| w == b"\x1b[2J")
        .expect("exit() must write clear screen \\x1b[2J");
    let leave = bytes
        .windows(b"\x1b[?1049l".len())
        .position(|w| w == b"\x1b[?1049l")
        .expect("exit() must write leave alternate screen \\x1b[?1049l");
    assert!(
        clear < leave,
        "clear screen must be emitted before LeaveAlternateScreen. \
         Captured bytes: {:?}",
        String::from_utf8_lossy(&bytes)
    );
}
```
