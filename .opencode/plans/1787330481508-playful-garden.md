# Plan: `car-driver` — Open-World Braille TUI Driving Simulator

## Summary
New **standalone** crate `crates/car-driver` (lib + bin). Zero coupling to term-wm crates: own crossterm terminal setup, own game loop, own keybindings. Infinite procedural terrain (hills/mountains), winding highways with guardrails/signs baked into the world, AI traffic, chase cam, HUD + minimap — all rendered as Unicode braille dots (each cell = 2×4 pixel grid, glyphs `U+2800 + bits`) so it looks like grainy video. Arcade-simple controls. Target ~30–60 fps in release.

Only change to an existing file: add `"crates/car-driver"` to `[workspace] members` in root `Cargo.toml` (explicit list, no glob — verified).

## Key Algorithms

### Noise / terrain (world/noise.rs, chunk.rs)
- Integer hash → [0,1): xorshift-multiply mix of `(x*PRIME1) ^ (y*PRIME2) ^ seed`; value noise = bilinear-smoothstep of corner hashes; fBm 4–5 octaves (lacunarity 2, gain 0.5); ridged = `1-|2n-1|`.
- Height: `continent = fbm(p/CONTINENT_SCALE)` (plains↔mountain regions), `mountains = ridged(p/RIDGE_SCALE)^1.5`, `hills = fbm(p/HILL_SCALE)`; `h = continent*MOUNTAIN_AMP*mountains + hills*HILL_AMP*(0.4+0.6*(1-continent))`. Sea plane at `SEA_LEVEL` (water/sand bands). Materials from height+slope+dither: grass / dirt / rock / snow above `SNOW_LINE`.

### Roads (world/roads.rs, baked in chunk.rs)
- Two highways: A ≈ E-W with centerline `x_c(z)`, B ≈ N-S with `z_c(x)`; each = sum of 2 sines + warped noise (deterministic, chunk-independent).
- Per chunk: build centerline polylines (samples every `CHUNK_SIZE/8`), exact point-segment distance `d` per cell.
- Elevation: evaluate the *low-frequency part only* of the height fn on the centerline (cheap, C¹, no per-octave jitter) → `road_elev`; blend `h = lerp(terrain_h, road_elev, smoothstep(SHOULDER+BLEND, ROAD_HALF, d))` → natural cuts/embankments.
- Materials: asphalt `|d|<ROAD_HALF`; dashed center paint (`frac(s/9)<0.5`, `|d|<0.15`); solid edge lines; shoulders; guardrail = thin bright steel band at `ROAD_HALF+0.2..+0.45` only where adjacent terrain drops > `RAIL_DROP_THRESH` (renders as a continuous light line); reflector posts every `POST_SPACING`.
- Curvature κ(s) via finite 2nd derivative → curve-warning sign spawn points (sprites, deduped by min spacing).
- Intersections (A×B crossings): flat priority crossing v1 (documented simplification).

### Renderer (render/*)
1. **Sky**: gradient rows via 4×4 ordered-Bayer dither of dot density; sun disk; 2 cloud bands.
2. **Terrain** (classic voxel-space / Comanche): per screen pixel-column, march ray `NEAR→FAR` with adaptive step `dt = STEP_BASE + t/STEP_GROWTH_DIV`; bilinear height sample; on penetration compute hit height, project to row, `fill_span` from current column top (`ybuf[col]`) upward; update `ybuf`; stop when `ybuf` above horizon or `t>FAR`. Shade: finite-diff normal ⊗ fixed `SUN_DIR` lambert; fog `lerp(color, sky_horizon, 1-exp(-t/FOG_DIST))`; palette quantize + Bayer dithering inside cells for smooth gradients.
3. **Sprites**: project world pos → (col, row_base, depth); scale = `FOCAL_Y/depth`; nearest-neighbor blit of small const dot-mask arrays (car body/cabin/wheels/taillights; signs); skip pixels where `row < ybuf[col]` (ridge occlusion); sort far→near. Player rear-view sprite last: taillights bright-red (brighter on brake), bob `sin(phase)·speed·k`, ±1px top-row lean on steer.
4. **HUD**: plain ratatui cells (not braille) for crispness: speed number+bar, D/R gear, offroad warning, dim hint line; P/Esc pause panel lists controls.
5. **Minimap**: braille, heading-up: per minimap-pixel rotate offset by −yaw, read cached chunk material (roads pop visually), traffic blips projected, player arrow center.

### Physics (sim/car.rs, dt = 1/60 accumulator)
`speed += (throttle·ACCEL − drag·v² − roll·v − brake·BRAKE)·dt`; offroad adds `OFFROAD_DRAG` + caps speed; `heading += steer_smoothed · STEER_RATE · g(v) · dt · sign(v)` where `g(v) = clamp(v/12,0,1)·(1−0.55·v/MAX_SPEED)` (tight low, stable high); reverse steers inverted; Space = handbrake; soft circle collision vs traffic (pushback + mutual damping); clamps `[-MAX_REVERSE, MAX_SPEED]`.

### Traffic (sim/traffic.rs)
State `{hw, s(arc-len), lane(±1.75/±5.25m), dir, v}`; IDM-lite: scan same lane/dir leader ≤ `GAP_SCAN`, match `min(cruise, leader_v·gap_factor)`; accel limit; recycle beyond `RECYCLE_BEHIND/AHEAD` of player's projected s → respawn 250–650 m ahead random lane (constant density forever). Braking flag drives taillight brightness.

### Input (app.rs, own keybindings — zero WM coupling)
Arrows/WASD drive, Space handbrake, C cam distance cycle, M minimap, H HUD, P/Esc pause, Q or Ctrl-C quit.
Enable `KeyboardEnhancementFlags::REPORT_ALL_KEYS_AS_ESCAPE_CODES | REPORT_EVENT_TYPES` when `supports_keyboard_enhancement()` → true Press/Repeat/**Release**; held = down-until-release. Fallback (unsupported terminals): held = last Press/Repeat within `FALLBACK_HELD_TIMEOUT_MS` (160). Single const keymap table.

## Performance Budget
240×140 px viewport → 240 cols × ~220 avg steps ≈ **~50 k height samples/frame** (~2 M flops) → 60 fps release comfortably; ~15 fps debug (recommend `cargo run --release`). Steady-state zero heap allocs (persistent Vecs swapped/reused; ratatui diffing handles IO). Initial 7×7 chunk burst amortized ≤2/frame after first synchronous ring. Vertical projection uses `ASPECT_CORRECTION_Y` const because braille-pixel aspect varies with font metrics.

## Tests (repo pattern: headless `Buffer::empty(area)` renders)
- braille packing golden chars (single px → `U+2801` etc., spans, clear)
- noise determinism/range/continuity; fixed-seed world
- road distance-field continuity across chunk borders (ε)
- physics clamps, reverse-steer sign, offroad slowdown
- traffic same-lane min-gap invariant over N steps; recycle keeps count constant
- render smoke: fixed seed+pose → non-empty buffer, byte-identical across two runs
- sim determinism: 300 ticks → bit-equal positions
- too-small-terminal path renders message not panic

## Milestones (each runnable)
1. **M1**: skeleton + loop + braille fb + sky + terrain flyover (orbiting cam, no car) → hills/mountains visible.
2. **M2**: player car physics + controls (kitty + fallback) + speed HUD; drive anywhere off-road.
3. **M3**: roads baked (paint/shoulders/guardrails/signs) + offroad penalty; follow a highway.
4. **M4**: traffic AI + billboards + collisions + minimap.
5. **M5**: fog/dither polish, pause overlay, perf pass, clippy/tests green.

## Risks
Font aspect variance (const tunable) · slow debug builds (document --release) · weak braille-font terminals (out of scope v1, noted in help) · Windows key repeat differences (heartbeat fallback path covers) · flat intersections simplify realism (documented v1 tradeoff).
