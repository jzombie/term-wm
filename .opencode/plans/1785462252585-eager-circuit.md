# Plan: Fix term-session IPC connectivity — cut the over-engineering

## Diagnosis

`./target/debug/term-session` fails with
`ConnectionRefused: "Server exited prematurely during startup with status: exit status: 1"`.

- muxio's client (`RpcIpcClient::new`) and server (`serve`) both route the socket through
  interprocess `GenericNamespaced`, which decides socket location per platform (macOS
  `/tmp/<name>` or `/run/user/<uid>/…`, Linux abstract namespace, Windows `\\.\pipe\`).
  The library already handles location — term-wm doesn't need to.
- term-wm's `probe_ipc_endpoint` instead does a raw `UnixStream::connect(resolved_path)`
  on the un-namespaced path → always `ENOENT` → auto-spawn always fires.
- When a server is already running it holds a flock on `main.sock.lock`; a newly spawned
  `--server` fails the lock (`AddrInUse`) → exits 1 → the client reports the error above.
- `ChannelResolver::resolve`'s 100-byte check doesn't match interprocess's real macOS
  budget (83), so longer channels (`default/workspace`, `workspace/dev`) fail to bind.

Everything past `ChannelName` + a probe is unnecessary. Cut it.

## Design (lean)

- Socket name = **`channel.to_string()`** (e.g. `default/main`), handed straight to the
  library. Short, always inside every platform budget, stable.
- **Delete the lock machinery** (`acquire_sidecar_lock`, `.sock.lock` files, stale-socket
  cleanup). The socket bind is the single-server mutex: a losing racer exits, the client
  re-probes and attaches to the winner. This removes the exact failure mode that bit us.
- **Delete `ChannelResolver`** (`resolve`, `default_channels_dir`, length-budget check)
  and `base_dir` everywhere. They only controlled the lock-file location, never the socket.
- `probe_ipc_endpoint` uses the same namespace mapping as the library:
  ```rust
  pub fn probe_ipc_endpoint(channel: &ChannelName) -> bool {
      use interprocess::local_socket::{GenericNamespaced, LocalSocketStream, ToNsName};
      let Ok(n) = channel.to_string().to_ns_name::<GenericNamespaced>() else { return false };
      LocalSocketStream::connect(n).is_ok()
  }
  ```
  (blocking `connect`; live → Ok, stale/missing → ECONNREFUSED/ENOENT). One impl for all
  platforms — replaces the unix `UnixStream` and windows Winsock AF_UNIX versions.
- Auto-spawn surfaces the spawned server's stderr (pipe it) and re-probes once on premature
  exit (spawn-race), so a real failure shows its message instead of the generic one.

## Changes

1. **`crates/term-session-muxio-service-definitions/Cargo.toml`**
   - Remove: `dirs`, `libc`, `windows-sys` (only used by the resolver/lock/probe being cut).
   - Add: `interprocess = "2.4.2"` (already in Cargo.lock via muxio).

2. **`crates/term-session-muxio-service-definitions/src/channel.rs`**
   - Keep `ChannelName` (`parse`, `Display`).
   - Delete `ChannelResolver`, `resolve`, `default_channels_dir`, `acquire_sidecar_lock`,
     the `>= 100` check, and the cfg-split probes.
   - Add `probe_ipc_endpoint(channel: &ChannelName) -> bool` (above).
   - Unit tests: probe returns `false` when nothing is bound on that channel; `ChannelName`
     round-trip unchanged.

3. **`crates/term-session-muxio-service-definitions/src/lib.rs`**
   - Re-export `ChannelName` + `probe_ipc_endpoint` only.

4. **`crates/term-session-server/src/session_server.rs`**
   - `SessionServerConfig`: remove `base_dir`.
   - `run_server`: `server.serve(&config.channel.to_string())` (drop the resolver path).

5. **`crates/term-session-client/src/auto_spawn.rs`**
   - `ServerSpawnConfig`: remove `base_dir`.
   - `spawn_detached_server`: `stderr(Stdio::piped())` instead of null.
   - `connect_or_spawn_server` → returns `io::Result<String>` (the channel name):
     probe `channel` → if alive return it; else spawn `current_exe() --server --channel …`
     and poll; on premature exit read the piped stderr, include it in the error, and
     re-probe once (a racer may have won) before failing; on timeout, error.

6. **`crates/term-session-client/src/main.rs`**
   - Remove the `--base-dir` flag.
   - `run_server_mode`: delete the lock + stale-socket block; just init tracing, build
     `SessionServerConfig`, `rt.block_on(run_server(...))`.
   - Client mode: pass the returned channel-name string to `run_session`.

7. **`tests/common/session.rs` + `tests/integration_session.rs`**
   - `test_channel()` → drop TempDir/base_dir; give each test its own channel name
     (e.g. `test/input_roundtrip`), since sockets are no longer isolated by tempdir.
   - `spawn_session(…)` takes a channel name; connect string = `channel.to_string()`.
   - Direct-`run_server` tests (`session_reconnect`, multi-client, start/stop): config
     without `base_dir`, connect via `channel.to_string()`.

## Immediate unblock (stale state)
- `pkill -f 'term-session --server'` (leftover daemon holding `main.sock.lock`).
- Remove stale files: `$HOME/Library/Application Support/term-wm/channels/…/*.sock.lock`
  and the orphaned `/tmp/…/channels/…/*.sock`. `/tmp` cleans up the rest.
