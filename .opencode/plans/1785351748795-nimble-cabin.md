# Plan: Integration tests for smallest-client geometry constraint

## Goal

Add integration tests in `tests/integration_session.rs` that verify the server constrains the PTY to the smallest connected client, and expands when the smallest client disconnects.

## Test Infrastructure

Existing helpers in `tests/common/session.rs`:
- `TEST_COLS = 80`, `TEST_ROWS = 24`
- `connect_client_with_retry(socket_path) -> Arc<RpcIpcClient>` — retries for 3s
- `generate_socket_path() -> (TempDir, String)` — temp socket path
- `SessionServerConfig`, `run_server` — start the server

`Spawn::call` returns `(id: u64, cols: u16, rows: u16)` — the constrained geometry.
`ResizePty::call` returns `(cols: u16, rows: u16)` — the constrained geometry.

## New Tests

### 1. Three clients, PTY constrained to smallest

```rust
#[tokio::test]
#[serial]
async fn session_multi_client_pty_constrained_to_smallest() {
    let mock = get_mock_bin();
    let (tempdir, socket_path) = generate_socket_path();
    let config = SessionServerConfig {
        socket_path, cmd: vec![mock, "echo".into()],
        cols: 120, rows: 40,
    };
    tokio::spawn(async move { run_server(config).await });
    tokio::time::sleep(Duration::from_millis(100)).await;

    let c1 = connect_client_with_retry(&config.socket_path).await;
    let c2 = connect_client_with_retry(&config.socket_path).await;
    let c3 = connect_client_with_retry(&config.socket_path).await;

    // Capture dynamic pane IDs
    let (pid1, _, _) = Spawn::call(&*c1, (None, 120, 40)).await.unwrap();
    let (pid2, _, _) = Spawn::call(&*c2, (None, 80, 24)).await.unwrap();
    let (pid3, _, _) = Spawn::call(&*c3, (None, 100, 30)).await.unwrap();

    // All clients now see 80x24 (c2 is smallest)
    assert_geometry(&*c1, pid1, 120, 40, 80, 24).await;
    assert_geometry(&*c2, pid2, 80, 24, 80, 24).await;
    assert_geometry(&*c3, pid3, 100, 30, 80, 24).await;

    drop(tempdir);
}
```

### 2. Disconnect smallest, PTY expands

```rust
#[tokio::test]
#[serial]
async fn session_multi_client_disconnect_expands_pty() {
    let mock = get_mock_bin();
    let (tempdir, socket_path) = generate_socket_path();
    let config = SessionServerConfig {
        socket_path, cmd: vec![mock, "echo".into()],
        cols: 120, rows: 40,
    };
    tokio::spawn(async move { run_server(config).await });
    tokio::time::sleep(Duration::from_millis(100)).await;

    let c1 = connect_client_with_retry(&config.socket_path).await;
    let c2 = connect_client_with_retry(&config.socket_path).await;
    let c3 = connect_client_with_retry(&config.socket_path).await;

    let (pid1, _, _) = Spawn::call(&*c1, (None, 120, 40)).await.unwrap();
    let (pid2, _, _) = Spawn::call(&*c2, (None, 80, 24)).await.unwrap();
    let (pid3, _, _) = Spawn::call(&*c3, (None, 100, 30)).await.unwrap();

    // Verify constrained to 80x24
    assert_geometry(&*c1, pid1, 120, 40, 80, 24).await;

    // Drop c2 (smallest) → PTY expands to 100x30 (c3's size)
    drop(c2);
    assert_geometry(&*c1, pid1, 120, 40, 100, 30).await;

    // Drop c3 → only c1 remains, PTY expands to 120x40
    drop(c3);
    assert_geometry(&*c1, pid1, 120, 40, 120, 40).await;

    drop(tempdir);
}
```

### Helper: retry-based geometry assertion

Replaces hardcoded sleeps with a polling loop:

```rust
async fn assert_geometry(
    client: &RpcIpcClient, pane_id: u64,
    req_cols: u16, req_rows: u16,
    expected_cols: u16, expected_rows: u16,
) {
    let start = std::time::Instant::now();
    while start.elapsed() < Duration::from_secs(3) {
        if let Ok((cols, rows)) = ResizePty::call(client, (pane_id, req_cols, req_rows)).await {
            if (cols, rows) == (expected_cols, expected_rows) {
                return;
            }
        }
        tokio::time::sleep(Duration::from_millis(10)).await;
    }
    panic!("Timed out waiting for geometry ({expected_cols}x{expected_rows})");
}
```

### 4. `render_frame` unit test

Create a mock `vt100::Parser` with known content, call `render_frame`, and verify the output contains expected ANSI sequences. Tests in `lib.rs` under `#[cfg(test)]`:

```rust
#[test]
fn render_frame_outputs_correct_cup_and_sgr() {
    let mut parser = vt100::Parser::new(4, 8, 0);
    parser.process(b"\x1b[31mhello\x1b[0m");
    let screen = parser.screen();
    let mut buf = Vec::new();
    render_frame(&mut buf, screen, 4, 8).unwrap();
    let output = String::from_utf8_lossy(&buf);
    // Should contain CUP to each row
    assert!(output.contains("\x1b[1;1H"));
    assert!(output.contains("\x1b[2;1H"));
    // Should contain "hello" in the output
    assert!(output.contains("hello"));
    // Should contain the red SGR
    assert!(output.contains("\x1b[31m") || output.contains("\x1b[38;5;1m"));
}
```
