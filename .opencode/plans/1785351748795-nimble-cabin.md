# Plan: SUBSCRIBE_EVENTS — streaming RPC for geometry events

## Design

### 1. Define `SessionEvent` + `SubscribeEvents` (streaming RPC method)

**`crates/term-session-muxio-service-definitions/src/methods.rs`:**
```rust
#[derive(Debug, Clone, Encode, Decode)]
pub enum SessionEvent {
    PtyResized { cols: u16, rows: u16 },
    SessionExited { status: i32 },
}

pub struct SubscribeEvents;

impl RpcMethodStream for SubscribeEvents {
    const METHOD_ID: u64 = rpc_method_id!("session.subscribe_events");
    type Input = ();
    type Item = SessionEvent;

    fn encode_request(_input: Self::Input) -> Result<Vec<u8>, std::io::Error> { Ok(Vec::new()) }
    fn decode_request(_bytes: &[u8]) -> Result<Self::Input, std::io::Error> { Ok(()) }
    fn encode_item(item: &Self::Item) -> Result<Vec<u8>, std::io::Error> {
        bitcode::encode(item).map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))
    }
    fn decode_item(bytes: &[u8]) -> Result<Self::Item, std::io::Error> {
        bitcode::decode(bytes).map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e))
    }
}
```

Re-export `SubscribeEvents`, `SessionEvent`, and `RpcMethodStream`.

### 2. Server: event subscriber registry + broadcast

**`crates/term-session-server/src/session_server.rs`:**
- Add `EventSubscriber { conn_id, respond }` struct
- Add `event_subscribers: Vec<EventSubscriber>` to `ServerState`
- Register `register_stream` handler for `SubscribeEvents::METHOD_ID`:
  - On connection, push immediate `SessionEvent::PtyResized { session.cols, session.rows }`
  - Store responder in `event_subscribers`
- In `recalculate_pty_size()`: after resize, broadcast `SessionEvent::PtyResized { min_cols, min_rows }` to `event_subscribers`, pruning disconnected responders via `retain`
- In `ClientDisconnected`: filter `event_subscribers` by conn_id

### 3. Client: event listener task + crossbeam channel + main loop handler

**`crates/term-session-client/src/lib.rs`:**
- Subscribe to events: `SubscribeEvents::subscribe(&*client)` returns a reader
- Spawn background task: read from event reader, decode `SessionEvent::PtyResized`, send `(cols, rows)` to `event_tx` (crossbeam channel)
- In main loop: non-blocking `try_recv` from `event_rx`; resize parser with `set_size(rows, cols)` only — no `\x1bc`:
```rust
while let Ok((cols, rows)) = event_rx.try_recv() {
    let parser = pane.shared_parser();
    let mut parser = parser.lock().unwrap();
    parser.screen_mut().set_size(rows, cols);
}
```
- Raw byte passthrough on `SUBSCRIBE_OUTPUT` unchanged
