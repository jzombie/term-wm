# Plan: OnPtyResized — server calls prebuffered RPC on client

## Architecture

**Client registers a prebuffered RPC handler on its endpoint. Server calls it when geometry changes.** No streaming, no polling.

## Design

### 1. Define `OnPtyResized` prebuffered RPC method

**`methods.rs`:**
```rust
#[derive(Encode, Decode)]
struct OnPtyResizedRequest { pub cols: u16, pub rows: u16 }

pub struct OnPtyResized;

impl RpcMethodPrebuffered for OnPtyResized {
    const METHOD_ID: u64 = rpc_method_id!("session.on_pty_resized");
    type Input = (u16, u16);
    type Output = ();
    fn encode_request(i: Self::Input) -> Result<Vec<u8>, io::Error> {
        Ok(bitcode::encode(&OnPtyResizedRequest { cols: i.0, rows: i.1 }))
    }
    fn decode_request(b: &[u8]) -> Result<Self::Input, io::Error> {
        let r = bitcode::decode::<OnPtyResizedRequest>(b)?;
        Ok((r.cols, r.rows))
    }
    fn encode_response(_: Self::Output) -> Result<Vec<u8>, io::Error> { Ok(Vec::new()) }
    fn decode_response(_: &[u8]) -> Result<Self::Output, io::Error> { Ok(()) }
}
```

### 2. Server: store client caller handles

**`session_server.rs` `ClientEntry`:**
```rust
struct ClientEntry {
    conn_id: usize,
    caller: Arc<dyn RpcServiceCallerInterface + Send + Sync>,
    cols: u16,
    rows: u16,
}
```

In `ClientConnected` event: store `handle` (implements `RpcServiceCallerInterface`) in `ClientEntry.caller`.

In `recalculate_pty_size()`: resize PTY normally. DO NOT dispatch RPCs inside this method (would hold lock across network I/O).

Add `notify_clients()` method for post-lock dispatch:
```rust
/// Broadcast geometry to all clients via detached async tasks.
/// Call AFTER releasing the ServerState lock.
fn notify_clients(clients: &[ClientEntry], cols: u16, rows: u16) {
    for client in clients {
        let caller = Arc::clone(&client.caller);
        tokio::spawn(async move {
            let _ = OnPtyResized::call(&*caller, (cols, rows)).await;
        });
    }
}
```

In each handler that calls `recalculate_pty_size()` (ResizePty, Spawn, ClientDisconnected):
```rust
guard.recalculate_pty_size();
let (min_cols, min_rows) = (guard.session.as_ref().map(|s| (s.cols, s.rows)).unwrap_or((80, 24)));
let clients = guard.clients.clone(); // Vec<ClientEntry>
drop(guard);
ServerState::notify_clients(&clients, min_cols, min_rows);
```

Note: `ClientEntry` must derive Clone.

### 3. Client: register handler

**`lib.rs`**: Register handler BEFORE calling Spawn to prevent race condition (server might call OnPtyResized immediately on connection):
```rust
// Register handler BEFORE Spawn to avoid race
client.get_endpoint().register_prebuffered(OnPtyResized::METHOD_ID, move |payload, _ctx| {
    let pane = Arc::clone(&pane);
    async move {
        let (cols, rows) = OnPtyResized::decode_request(&payload)?;
        let parser = pane.shared_parser();
        let mut parser = parser.lock().unwrap();
        parser.screen_mut().set_size(rows, cols);
        OnPtyResized::encode_response(())
    }
}).await?;
```
