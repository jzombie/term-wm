# Plan: PtyResized Frame + TerminalComponent Centered Rendering + Framed Server Output

## Problems solved

1. **Parser desync**: Server constrains PTY to smallest-client geometry, but client's local `vt100::Parser` isn't resized until the user triggers `ResizePty`. Add out-of-band `PtyResized` frame.
2. **Dead space**: Larger clients see content top-left anchored. Use `TerminalComponent` + centered `Rect`.
3. **Raw ANSI rendering**: No layout abstraction, can't center. Replace with Ratatui + `TerminalComponent`.
4. **Stream fragmentation**: TCP/UDS doesn't preserve message boundaries. Need accumulator buffer for frame decoding.
5. **Server output unframed**: Raw PTY bytes sent without `SessionPushFrame` envelope. Client expects framed data after introducing `PtyResized`.

## Design

### Part 1 — Protocol: `PtyResized` frame

Add `PtyResized { id: u64, cols: u16, rows: u16 }` to `SessionPushFrame`.

**`crates/term-session-muxio-service-definitions/src/push_frame.rs`:**
- Add `TAG_PTY_RESIZED = 0x04`
- Add `PtyResized` variant
- Encode: `[tag(1), id(8le), cols(2le), rows(2le)]` = 13 bytes
- Decode: read from bytes[1..13]

### Part 2 — Server: frame all output, broadcast PtyResized

**`crates/term-session-server/src/session_server.rs`:**

Wrap every `sub.respond.respond(data, false)` call in `SessionPushFrame::RawOutput { id, data }.encode()`:
- Output polling loop (raw PTY bytes to subscribers)
- Subscribe handler initial/early buffer push

In `recalculate_pty_size()`, after `session.pty.resize(size)`:
- Encode and broadcast `SessionPushFrame::PtyResized { id: session.id, cols: min_cols, rows: min_rows }` to all subscribers

### Part 3 — Client: stream buffering + frame decode

**`crates/term-session-client/src/lib.rs` (subscribe handler):**

Replace raw-byte forwarding with an accumulator buffer. On decode error, drain 1 byte to avoid infinite deadlock:

```rust
let mut acc = Vec::new();
while let Some(chunk) = reader.recv().await {
    match chunk {
        Ok(data) => {
            acc.extend_from_slice(&data);
            loop {
                match SessionPushFrame::decode(&acc) {
                    Ok((frame, consumed)) => {
                        acc.drain(..consumed);
                        match frame {
                            SessionPushFrame::RawOutput { data, .. } => {
                                let _ = push_tx.try_send(data);
                            }
                            SessionPushFrame::PtyResized { cols, rows, .. } => {
                                let _ = resize_tx.try_send((cols, rows));
                            }
                            _ => {}
                        }
                    }
                    Err(ref e) if e.kind() == io::ErrorKind::UnexpectedEof => {
                        break; // need more bytes
                    }
                    Err(_) => {
                        acc.drain(..1); // drop corrupt byte, attempt recovery
                        continue;
                    }
                }
            }
        }
        Err(_) => break,
    }
}
```

Add a `resize_rx: crossbeam_channel::Receiver<(u16, u16)>` channel. In the main loop, non-blocking-recv from `resize_rx` and call `pane.resize(cols, rows)` to resize the local parser.

Track `live_cols`/`live_rows` locally in the main loop, initialized from `crossterm::terminal::size()`, updated from `PtyResized` events. These are used for centering math.

### Part 4 — Client: TerminalComponent centered rendering

**`crates/term-session-client/Cargo.toml`:**
Add deps: `ratatui`, `term-wm-ui-components`, `term-wm-core`, `term-wm-console`, `term-wm-render`, `term-wm-layout-engine`

**`crates/term-session-client/src/lib.rs` (render loop):**

Replace the raw ANSI diff loop with Ratatui `Terminal::draw()`. Inside the closure:

```rust
let mut terminal = Terminal::new(CrosstermBackend::new(stdout))?;
let mut term_component = TerminalComponent::from_pane(Box::new(pane));

// Main loop
loop {
    // ... event handling (same select! block) ...

    terminal.draw(|f| {
        let area = f.area();

        // Compute centered rect using locally-tracked dimensions
        let render_w = live_cols.min(area.width);
        let render_h = live_rows.min(area.height);
        let offset_x = (area.width - render_w) / 2;
        let offset_y = (area.height - render_h) / 2;

        let centered_rect = LayoutRect {
            x: (area.x + offset_x) as i32,
            y: (area.y + offset_y) as i32,
            width: render_w,
            height: render_h,
        };

        // Clear dead space
        f.render_widget(Clear, area);

        // Render TerminalComponent at centered position
        let mut backend = RatatuiBackend::new_simple(f.buffer_mut(), area);
        let ctx = ComponentContext::new(true);
        let mut registry = HitboxRegistry::new();
        term_component.render(&mut backend, centered_rect, &ctx, &mut registry);
    })?;

    // Check exit
    if term_component.pane().has_exited() {
        break;
    }
}
```
