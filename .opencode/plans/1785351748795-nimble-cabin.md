# Plan: Fix `\x1b[K` → bounded spaces with cursor restore + UTF-8 col tracking

## Fixes

### 1. Replace `\x1b[K` with spaces, restore cursor with CHA

`\x1b[K` is non-advancing — cursor stays at pre-clear column. Writing spaces moves cursor right. After spaces, emit `\x1b[{col+1}G` to restore cursor:

```rust
b'K' => {
    let param = param_str.parse::<u16>().unwrap_or(0);
    match param {
        1 => {
            // Erase from BOL to cursor — not emitted by our vt100, pass through
            out.extend_from_slice(&diff[start..i]);
        }
        2 => {
            // Erase entire line: cursor to BOL, write parser_cols spaces, restore
            write!(out, "\x1b[1G").unwrap();
            for _ in 0..parser_cols { out.push(b' '); }
            write!(out, "\x1b[{}G", col + 1).unwrap();
        }
        _ => {
            // Erase from cursor to EOL: write spaces, restore
            let spaces = parser_cols.saturating_sub(col) as usize;
            for _ in 0..spaces { out.push(b' '); }
            write!(out, "\x1b[{}G", col + 1).unwrap();
        }
    }
}
```

### 2. UTF-8 column tracking

Iterate chars (not bytes) so multi-byte sequences increment col once:

```rust
if let Ok(s) = std::str::from_utf8(&diff[i..]) {
    if let Some(ch) = s.chars().next() {
        let len = ch.len_utf8();
        if ch == '\n' { col = 0; }
        else if ch != '\r' { col = col.saturating_add(1).min(parser_cols); }
        out.extend_from_slice(&diff[i..i + len]);
        i += len;
        continue;
    }
}
out.push(diff[i]); i += 1;
```
