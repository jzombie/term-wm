# Fix: OnPtyResized clear + Spawn insert-before-recalculate

## Bug 1: `OnPtyResized` doesn't clear screen or reset prev_content

When parser shrinks (120x40 → 80x20), `prev_content` stays at 120x40. `contents_diff()` across mismatched grids produces corrupted ANSI. Physical rows 21-40 retain stale text.

**Fix in `lib.rs` OnPtyResized handler:**

```rust
let (cols, rows) = OnPtyResized::decode_request(&payload)?;
let mut parser = parser.lock().unwrap();
parser.screen_mut().set_size(rows, cols);

// Clear physical screen to wipe stranded dead-space cells
let mut out = std::io::stdout();
let _ = out.write_all(b"\x1b[2J\x1b[H");
let _ = out.flush();
// prev_content reset happens naturally on next render iteration
// (prev_content.is_none() triggers full contents_formatted render)
```

But the handler doesn't have access to `prev_content` (it's in `run_session`). The handler just resizes the parser. The main loop's render section checks `prev_content.is_none()` and does a full `contents_formatted()` render.

Currently, `prev_content` is only set to `None` in the `Event::Resize` handler. I need to also reset it when `OnPtyResized` fires.

Fix: use an `AtomicBool` flag or a shared `Cell<bool>` to signal the main loop to reset prev_content. Or simpler: the `OnPtyResized` handler can share a `Arc<AtomicBool>` with the main loop.

**Simpler approach:** After `parser.screen_mut().set_size(rows, cols)`, set a flag that the main loop checks before rendering. If the flag is set, reset `prev_content = None` and clear the flag.

**`lib.rs`**:
- Add `Arc<AtomicBool>` flag `resize_pending` shared between handler and main loop
- In handler: set flag + clear screen
- In main loop: check flag, reset prev_content, clear flag

## Bug 2: Spawn handler inserts client AFTER recalculate (or not at all)

`ServerState.clients` needs to be `HashMap<usize, ClientEntry>` so insertion is idempotent.

**`session_server.rs`**:
- Change `clients: Vec<ClientEntry>` to `clients: HashMap<usize, ClientEntry>`
- `ClientConnected`: `clients.insert(conn_id, ClientEntry { caller: handle.0.clone(), cols: u16::MAX, rows: u16::MAX })`
- `ClientDisconnected`: `clients.remove(&conn_id)`
- `Spawn` handler: `clients.entry(ctx.conn_id).or_insert_with(|| ClientEntry { conn_id, caller, cols, rows })` then update cols/rows, then `recalculate_pty_size()`, then `notify_clients()` after dropping lock
- `ResizePty` handler: `clients.get_mut(&ctx.conn_id)`
- `recalculate_pty_size`: `self.clients.values()`
- `notify_clients`: iterate `self.clients.values()`
