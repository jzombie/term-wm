# Fix: Row-by-row rendering replaces rewrite_diff

## Problem

`rewrite_diff()` tracks cursor column by parsing ANSI byte streams. Unhandled sequences (relative movement `\x1b[A`, `\t`, `\x08`, ConPTY injection) cause `col` to drift. When `\x1b[K` is encountered, the wrong number of spaces is emitted → line wrap → diagonal cascade explosion.

## Fix

Replace `contents_diff()` + `rewrite_diff()` with `render_frame()` — iterate the vt100 `Screen` cell matrix directly, emitting explicit CUP positioning for each row. No `\x1b[K` anywhere, no column state tracking, no cascade possible.

## Implementation

### 1. Remove `rewrite_diff` and its dependencies

Delete the `rewrite_diff` function. Remove `line-ending` and `unicode-width` from `Cargo.toml` (no longer needed).

### 2. Add `render_frame`, `CellStyle`, `apply_sgr`

**`lib.rs`** — Replace `rewrite_diff` with:

```rust
#[derive(Default, PartialEq, Clone, Copy)]
struct CellStyle {
    fg: vt100::Color, bg: vt100::Color,
    bold: bool, italic: bool, underline: bool, inverse: bool,
}

fn apply_sgr(out: &mut dyn Write, style: &CellStyle) -> io::Result<()> {
    write!(out, "\x1b[0m")?;
    if style.bold { write!(out, "\x1b[1m")?; }
    if style.italic { write!(out, "\x1b[3m")?; }
    if style.underline { write!(out, "\x1b[4m")?; }
    if style.inverse { write!(out, "\x1b[7m")?; }
    match style.fg {
        vt100::Color::Idx(i) => write!(out, "\x1b[38;5;{}m", i)?,
        vt100::Color::Rgb(r, g, b) => write!(out, "\x1b[38;2;{};{};{}m", r, g, b)?,
        _ => {}
    }
    match style.bg {
        vt100::Color::Idx(i) => write!(out, "\x1b[48;5;{}m", i)?,
        vt100::Color::Rgb(r, g, b) => write!(out, "\x1b[48;2;{};{};{}m", r, g, b)?,
        _ => {}
    }
    Ok(())
}

pub fn render_frame(out: &mut dyn Write, screen: &Screen, rows: u16, cols: u16) -> io::Result<()> {
    let mut active_style = CellStyle::default();
    out.write_all(b"\x1b[0m")?;
    for row in 0..rows {
        write!(out, "\x1b[{};1H", row + 1)?;
        for col in 0..cols {
            if let Some(cell) = screen.cell(row, col) {
                let style = CellStyle { fg: cell.fgcolor(), bg: cell.bgcolor(), bold: cell.bold(), italic: cell.italic(), underline: cell.underline(), inverse: cell.inverse() };
                if style != active_style { apply_sgr(out, &style)?; active_style = style; }
                let c = cell.contents();
                if c.is_empty() { out.write_all(b" ")?; } else { out.write_all(c.as_bytes())?; }
            } else { out.write_all(b" ")?; }
        }
    }
    out.write_all(b"\x1b[0m")?;
    let (cur_row, cur_col) = screen.cursor_position();
    write!(out, "\x1b[{};{}H", cur_row + 1, cur_col + 1)?;
    if screen.hide_cursor() { out.write_all(b"\x1b[?25l")?; } else { out.write_all(b"\x1b[?25h")?; }
    out.flush()
}
```

### 3. Update render loop

Remove `prev_content`, `prev_parser`, diff computation, `contents_diff()`, `rewrite_diff()` call. Replace with:

```rust
if resize_pending.swap(false, Ordering::Relaxed) {
    let _ = out.write_all(b"\x1b[0m\x1b[2J\x1b[H");
    let _ = out.flush();
}
if has_new_data {
    let parser = pane.shared_parser();
    let mut parser = parser.lock().unwrap();
    let screen = parser.screen();
    let (rows, cols) = screen.size();
    render_frame(&mut out, screen, rows, cols)?;
}
```

- `line_ending::PeekableLineEndingExt` (deleted)
