# Fix: Row-by-row rendering with buffered output, wide-char support

## Problem

`rewrite_diff()` column tracking drifts on unhandled control sequences, causing `\x1b[K` to emit wrong space count → line wrap → cascade explosion.

## Fix

Replace `contents_diff()` + `rewrite_diff()` with `render_frame()` — iterate vt100 `Screen` cell matrix directly, accumulating into a `Vec<u8>` buffer. No `\x1b[K`, no column tracking, no cascade.

### Key design decisions from analysis:

1. **Buffered I/O** — Accumulate all escape sequences into `Vec<u8>` before single `out.write_all(&buf)` + flush
2. **Wide char skipping** — Use `unicode_width::UnicodeWidthStr::width()` to skip continuation cells (CJK/Emoji)
3. **`\x1b[0m` is fine** — Reset-then-set is standard practice; the `\x1b[0m + \x1b[1;3;38;5;...m` pattern is how real terminals work. Keep it for correctness
4. **Row-level diffing** — Use `contents_diff()` to identify dirty rows, only render those rows explicitly (retains `prev_parser` diff cache for efficiency)

### Implementation

```rust
#[derive(Default, PartialEq, Clone, Copy)]
struct CelStyle {
    fg: vt100::Color,
    bg: vt100::Color,
    bold: bool,
    dim: bool,
    italic: bool,
    underline: bool,
    inverse: bool,
}

impl CelStyle {
    fn from_cell(cell: &vt100::Cell) -> Self {
        Self {
            fg: cell.fgcolor(),
            bg: cell.bgcolor(),
            bold: cell.bold(),
            dim: cell.dim(),
            italic: cell.italic(),
            underline: cell.underline(),
            inverse: cell.inverse(),
        }
    }
}

fn apply_sgr(out: &mut dyn Write, style: &CelStyle) -> io::Result<()> {
    write!(out, "\x1b[0m")?;
    if style.bold { write!(out, "\x1b[1m")?; }
    if style.dim { write!(out, "\x1b[2m")?; }
    if style.italic { write!(out, "\x1b[3m")?; }
    if style.underline { write!(out, "\x1b[4m")?; }
    if style.inverse { write!(out, "\x1b[7m")?; }
    match style.fg {
        vt100::Color::Idx(i) => write!(out, "\x1b[38;5;{}m", i)?,
        vt100::Color::Rgb(r, g, b) => write!(out, "\x1b[38;2;{};{};{}m", r, g, b)?,
        _ => {}
    }
    match style.bg {
        vt100::Color::Idx(i) => write!(out, "\x1b[48;5;{}m", i)?,
        vt100::Color::Rgb(r, g, b) => write!(out, "\x1b[48;2;{};{};{}m", r, g, b)?,
        _ => {}
    }
    Ok(())
}

pub fn render_frame(out: &mut dyn Write, screen: &Screen, rows: u16, cols: u16) -> io::Result<()> {
    let mut buf = Vec::with_capacity((rows as usize) * (cols as usize) * 3);
    let mut active_style = CelStyle::default();

    buf.extend_from_slice(b"\x1b[0m");

    for row in 0..rows {
        write!(buf, "\x1b[{};1H", row + 1)?;
        let mut col: u16 = 0;
        while col < cols {
            let cell_opt = screen.cell(row, col);
            let style = cell_opt.map(|c| CelStyle::from_cell(&c)).unwrap_or_default();
            
            if style != active_style {
                apply_sgr(&mut buf, &style)?;
                active_style = style;
            }

            if let Some(cell) = cell_opt {
                let c = cell.contents();
                if !c.is_empty() {
                    buf.extend_from_slice(c.as_bytes());
                    let w = unicode_width::UnicodeWidthStr::width(c).max(1) as u16;
                    col += w;
                    continue;
                }
            }

            buf.push(b' ');
            col += 1;
        }
    }

    buf.extend_from_slice(b"\x1b[0m");
    let (cur_row, cur_col) = screen.cursor_position();
    write!(buf, "\x1b[{};{}H", cur_row + 1, cur_col + 1)?;
    if screen.hide_cursor() { buf.extend_from_slice(b"\x1b[?25l"); }
    else { buf.extend_from_slice(b"\x1b[?25h"); }

    out.write_all(&buf)?;
    out.flush()
}
```

### Dependencies

- `unicode-width` — KEEP (needed for wide char detection)
- `line-ending` — REMOVE (no longer used by rewrite_diff)

### Render loop changes

Remove `prev_content`, `prev_parser`, `contents_diff()`. For efficiency, call `render_frame` only on `has_new_data` (as before). The unbuffered full-frame render is fast enough for 80×20 grids.

### Files to modify

| File | Changes |
|------|---------|
| `Cargo.toml` (client) | Remove `line-ending`, keep `unicode-width` |
| `lib.rs` (client) | Remove `rewrite_diff`, `PeekableLineEndingExt`. Add `render_frame`, `CellStyle`, `apply_sgr`. Update render loop. Remove `prev_content`/`prev_parser`. |
