# Plan: Fix term-resize-indicator Rendering & SetSize Debounce

## Problems

### SEV-1: Synchronous `SetSize` feedback loop
In `on_resize()` (lib.rs:97-108), every `Event::Resize` synchronously fires `SetSize` back to the locked size. In a multiplexed PTY (tmux/tmate) with multiple clients:
- Client A drags window → SIGWINCH → PTY resizes → Client B gets SIGWINCH → Client B fires SetSize → PTY resizes → Client A gets SIGWINCH → infinite thrash
- Even single-client: SetSize inside the event loop fights the OS window manager during drag at hundreds of Hz

### SEV-1: VT100 DECAWM auto-wrap scroll
When writing to the last column of the terminal, DECAWM places the cursor into a "pending wrap" state. Subsequent cursor repositioning commands from Ratatui's buffer flush emit CRLF, causing an unrecoverable hardware scroll. This tears the viewport regardless of any user-space cell skipping.

### Rendering bugs in `draw_overlay()`
1. **u16 overflow in text label** (line 232): `text_x + i as u16` wraps when `text_x` > 65535 - label_len
2. **Asymmetrical centering** (lines 157-158): `full.width/2 - w/2` vs the more correct `(full.width - w)/2`. Off by 1 when full.width even and w odd.

## Design

### 1. Debounce `SetSize` (lib.rs)

New field in `App`:
```rust
struct App {
    mode: Mode,
    live_size: Size,
    pending_snap: Option<Instant>,
}
```

`on_resize` in locked mode: set `live_size` to the new size immediately (so the visual overlay tracks the actual terminal), arm a 250ms debounce timer in `pending_snap`. Do NOT call `SetSize` synchronously.

`run_loop` before each `terminal.draw()`: check `pending_snap` — if the timer has expired, fire `SetSize` and reset `live_size` to locked size, clear `pending_snap`.

### 2. Disable DECAWM at protocol level (lib.rs)

Add `DisableLineWrap` to the `crossterm::execute!` call that enters the alternate screen. Add `EnableLineWrap` to the call that leaves it.

Change:
```rust
use crossterm::terminal::{self, EnterAlternateScreen, LeaveAlternateScreen, SetSize, DisableLineWrap, EnableLineWrap};

crossterm::execute!(stdout, EnterAlternateScreen, DisableLineWrap)?;
// ...
let _ = crossterm::execute!(terminal.backend_mut(), LeaveAlternateScreen, EnableLineWrap);
```

This commands the terminal emulator to discard overruns instead of wrapping/CRLF-scrolling. The bottom-right cell exclusion hack is removed — the box draws symmetrically with no missing corner.

### 3. Fix centering algebra (lib.rs lines 157-158)

Change from:
```rust
let bx = full.left() as i32 + full.width as i32 / 2 - w as i32 / 2;
let by = full.top() as i32 + full.height as i32 / 2 - h as i32 / 2;
```
To:
```rust
let bx = full.left() as i32 + (full.width as i32 - w as i32) / 2;
let by = full.top() as i32 + (full.height as i32 - h as i32) / 2;
```

### 4. Fix u16 overflow in text label (lib.rs line 232)

Change from:
```rust
let cx = text_x + i as u16;
```
To:
```rust
let cx = text_x.saturating_add(i as u16);
```
