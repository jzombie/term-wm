# Plan: Smallest-Client Geometry + PtyResized Frame + Centered Rendering

## Problem

After constraining the PTY to smallest-client geometry, the server resizes the PTY without the client knowing → local `vt100::Parser` desyncs. Larger clients also see dead space top-left anchored.

## Design

### Part 1 — `PtyResized` frame in SessionPushFrame protocol

Add a `PtyResized { id: u64, cols: u16, rows: u16 }` variant to `SessionPushFrame`. 13 bytes: tag + 8-byte ID + 2-byte cols + 2-byte rows.

**Files:**
- `crates/term-session-muxio-service-definitions/src/push_frame.rs` — variant + encode + decode
- `crates/term-session-muxio-service-definitions/src/lib.rs` — re-export (already done)

### Part 2 — Server: broadcast PtyResized from `recalculate_pty_size()`

After resizing the PTY in `recalculate_pty_size()`, encode a `SessionPushFrame::PtyResized` and push it to all subscribers.

**File:** `crates/term-session-server/src/session_server.rs`

### Part 3 — Client: intercept PtyResized, resize local parser

The subscribe handler (lib.rs:192-223) currently forwards raw bytes directly to `push_tx`. Change it to:
1. Decode each chunk as `SessionPushFrame`  (since server will now send framed data)
2. `RawOutput { data }` → forward to `push_tx` as before
3. `PtyResized { cols, rows }` → resize the local parser via `pane.resize()`

**File:** `crates/term-session-client/src/lib.rs`

### Part 4 — Client: centered rendering

The raw ANSI output from `vt100::Screen::contents_diff()` uses absolute CUP sequences. Center by:
1. Compute `offset_x = (term_cols - parser_cols) / 2`, `offset_y = (term_rows - parser_rows) / 2`
2. Before writing the diff, clear the full terminal
3. At the start of each frame's diff, insert a CUP to `(1+offset_y, 1+offset_x)` and parse/subsequent CUP sequences in the diff to add offsets

**File:** `crates/term-session-client/src/lib.rs`

### Part 5 — Server constraint (already implemented)

`ClientEntry` geometry, `recalculate_pty_size()`, `ResizePty`/`Spawn` updates, connect/disconnect handlers — these are already done from the previous round.
