# Plan: Rewrite `\x1b[K` as bounded spaces via `rewrite_diff`

## Problem

`\x1b[K` in `contents_diff()` clears to physical end-of-line. Fix: replace with bounded space padding + cursor restore. Use `line-ending` crate for line break detection and `unicode-width` for column tracking.

## Implementation

### 1. Add dependencies

**`Cargo.toml`**: Add `line-ending` and `unicode-width`.

### 2. Add `rewrite_diff` function

**`lib.rs`**: Implements the ANSI rewriter using `PeekableLineEndingExt` and `UnicodeWidthChar`:

- Parses CSI sequences (`ESC[`), tracks cursor column
- Replaces `\x1b[K` (erase to EOL) with `(parser_cols - col)` spaces + cursor restore via CHA
- Replaces `\x1b[2K` (erase entire line) with `parser_cols` spaces + cursor restore
- Detects line endings via `consume_line_ending()`, resets col to 0
- Tracks column via `UnicodeWidthChar::width()` for accurate UTF-8 display width
- Passes through non-CSI ESC sequences unchanged

### 3. Apply to render loop

**`lib.rs` render section**: Replace `out.write_all(&diff)` with:

```rust
let clean = rewrite_diff(&diff, cols);
if !clean.is_empty() {
    out.write_all(&clean)?;
}
```

After render, sync cursor position + visibility:
```rust
let (cur_row, cur_col) = screen.cursor_position();
write!(out, "\x1b[{};{}H", cur_row + 1, cur_col + 1)?;
if screen.hide_cursor() { out.write_all(b"\x1b[?25l")?; }
else { out.write_all(b"\x1b[?25h")?; }
out.flush()?;
```
