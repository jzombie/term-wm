# Plan: Proper muxio RPC — remove custom framing entirely

## Principle

- **Only `SUBSCRIBE_OUTPUT`** uses streaming → raw PTY bytes, no `SessionPushFrame` wrapping
- **Everything else** is a prebuffered RPC with typed request/response

## Changes

### 1. Remove `SessionPushFrame` entirely

Delete `push_frame.rs`. Remove `pub mod push_frame` from lib.rs. Remove `pub use push_frame::SessionPushFrame`. It was dead code before these changes and is the root of the anti-pattern.

### 2. `ResizePty` response: `()` → `(u16, u16)`

Response carries the actual constrained geometry:

```rust
type Output = (u16, u16);

fn encode_response(output: Self::Output) -> Result<Vec<u8>, io::Error> {
    Ok(bitcode::encode(&(output.0, output.1)))
}
fn decode_response(bytes: &[u8]) -> Result<Self::Output, io::Error> {
    let r = bitcode::decode::<(u16, u16)>(bytes)?;
    Ok(r)
}
```

### 3. `Spawn` response: `u64` → `(u64, u16, u16)`

Response carries session_id + actual cols + actual rows:

```rust
type Output = (u64, u16, u16);

fn encode_response(output: Self::Output) -> Result<Vec<u8>, io::Error> {
    Ok(bitcode::encode(&(output.0, output.1, output.2)))
}
fn decode_response(bytes: &[u8]) -> Result<Self::Output, io::Error> {
    let r = bitcode::decode::<(u64, u16, u16)>(bytes)?;
    Ok(r)
}
```

### 4. Server: return actual sizes from handlers

**`ResizePty` handler** (`session_server.rs`):
- Update client's geometry + `recalculate_pty_size()`
- Return `(guard.session.cols, guard.session.rows)` in response

**`Spawn` handler** (`session_server.rs`):
- Reuse path: `recalculate_pty_size()` then return `(session.id, session.cols, session.rows)`
- Cold path: `set_session()` + `recalculate_pty_size()` then return `(id, session.cols, session.rows)`

### 5. Server: send raw PTY bytes on SUBSCRIBE_OUTPUT

Revert all `SessionPushFrame::RawOutput` wrapping. Just `sub.respond.respond(raw, false)` with raw bytes.

- Output polling loop: `sub.respond.respond(raw.clone(), false)`
- Subscribe handler snapshot: `respond.respond(data, false)`
- Subscribe handler early data: `respond.respond(data, false)`
- `clear_session()`: `sub.respond.respond(raw.clone(), false)`

### 6. Client: `RemotePane::resize()` uses actual size from RPC

```rust
fn resize(&mut self, size: PtySize) -> PtyResult<()> {
    if let Some(ref caller) = self.server {
        let (_, actual_cols, actual_rows) = ResizePty::call(caller, (self.id, size.cols, size.rows))?;
        let parser = self.parser.lock().unwrap();
        parser.screen_mut().set_size(actual_rows, actual_cols);
    } else {
        let parser = self.parser.lock().unwrap();
        parser.screen_mut().set_size(size.rows, size.cols);
    }
    Ok(())
}
```

### 7. Client: subscribe handler = raw passthrough

```rust
rt.spawn(async move {
    let mut osc52 = Osc52Extractor::new();
    let mut prev_tail: [u8; 8] = [0; 8];
    while let Some(chunk) = reader.recv().await {
        if let Ok(mut data) = chunk {
            if let Some(text) = osc52.push(&data, &prev_tail) {
                let _ = clip_tx.try_send(text);
            }
            let n = data.len();
            if n >= 8 { prev_tail.copy_from_slice(&data[n - 8..n]); }
            else if n > 0 { prev_tail.rotate_left(n); prev_tail[8 - n..].copy_from_slice(&data[..n]); }
            while let Err(TrySendError::Full(pending)) = push_tx.try_send(data) {
                data = pending;
                tokio::time::sleep(Duration::from_millis(1)).await;
            }
        } else { break; }
    }
});
```

No accumulator, no `SessionPushFrame::decode`, no `PtyResized` dispatch, no `resize_tx`.

### 8. Client: `live_cols`/`live_rows` updates

Update from `Spawn` response:
```rust
let (id, actual_cols, actual_rows) = rt.block_on(Spawn::call(&*client, (None, term_cols, term_rows)))?;
live_cols = actual_cols;
live_rows = actual_rows;
```

After `Event::Resize` → `pane.resize()`: the local parser is already resized to actual size inside `RemotePane::resize()`. Read parser size:
```rust
let parser = pane.shared_parser();
let parser = parser.lock().unwrap();
live_cols = parser.screen().size().1;
live_rows = parser.screen().size().0;
```
