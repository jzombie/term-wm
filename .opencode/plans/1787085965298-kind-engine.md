## Phase 2 — Baseline report + Makefile

Mirror the CI coverage job (`.github/workflows/rust-tests.yml:95-200`):

```bash
cargo llvm-cov clean --workspace
cargo llvm-cov --workspace --all-features --lcov --output-path lcov.info
cargo llvm-cov --workspace --all-features --summary-only   # record as baseline
```

Add a root `Makefile` (repo has none today) with targets that wrap these exact commands so the workflow is reproducible. The Makefile must be **environment-agnostic** (works on macOS/Linux/Windows shells — use POSIX `sh`, `TMPDIR`/`mktemp`-style paths, never hardcoded absolute or platform-specific paths):
- `make coverage` — clean + full run + `--summary-only`
- `make coverage-baseline` — writes `coverage-baseline.txt` (summary + total line %)
- `make coverage-main` — runs the same against a throwaway `git worktree` of `main` created in a **relative repo-local dir** (e.g. `.build/main-worktree`, git-ignored), with an explicit teardown rule (`git worktree remove --force .build/main-worktree`) so a cancelled/partial run never leaves an orphaned worktree. No absolute paths.
- `.PHONY` entries, no artifacts (`lcov.info`, `*.profraw`) committed; add `.build/` to `.gitignore`.

Measure `main` via that worktree so the current branch is untouched. Record both summaries (total line %). CI runs on Ubuntu; local macOS numbers differ in absolute value but are a valid relative comparison.
