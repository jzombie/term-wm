## Verification Gates

1. **Punctuation gate:** `grep -nP "[\x{2013}\x{2014}]" Cargo.toml README.md docs/DEVELOPMENT.md docs/launch/*.md` — zero matches allowed
2. **Doc gate:** `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps --document-private-items` — must pass after any README edit
3. **Link verification:** All rustdoc links must resolve (enforced by doc gate)
4. **Feature claims:** Social copy must match README wording exactly
5. **docs.rs compatibility:** HTML must render correctly when embedded via `include_str!`
