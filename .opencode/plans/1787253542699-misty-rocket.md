# Add `TrailingEdgeDebouncer` Utility and Replace Ad-Hoc Timestamp Patterns

## Problem

Ad-hoc `Option<Instant>` timestamp comparisons are scattered across `TermWmApp` and `Pty`, duplicating timing logic and violating clean abstraction boundaries. Each site manually tracks `last_trigger: Option<Instant>`, computes `duration_since`, and compares against a threshold. A generic trailing-edge debouncer eliminates this boilerplate and provides consistent, testable timing semantics.

## Existing Debounce Primitives

**Directory:** `crates/term-wm-core/src/utils/debounce/`

| Primitive | Pattern | Limitation |
|-----------|---------|------------|
| `DelayedReleaseBool` | Instant-on, delayed-release boolean | Boolean-only; wrong semantics for trailing-edge action execution |
| `KeyedTaskDebouncer` | Leading-edge, keyed, scheduler-backed | Requires `TaskScheduler` + `TaskHandle`; too heavy for synchronous loops |

**Missing:** A lightweight, synchronous trailing-edge debouncer that coalesces triggers and fires once after a quiet period.

## Implementation Plan

### Phase 1: Add `TrailingEdgeDebouncer` Utility

**File:** `crates/term-wm-core/src/utils/debounce/trailing_edge_debouncer.rs`

```rust
use std::time::{Duration, Instant};

/// A synchronous, trailing-edge debouncer for event-driven polling loops.
/// Coalesces rapid triggers into a single execution after a quiet period.
pub struct TrailingEdgeDebouncer {
    delay: Duration,
    last_trigger: Option<Instant>,
    pending: bool,
}

impl TrailingEdgeDebouncer {
    pub fn new(delay: Duration) -> Self {
        Self {
            delay,
            last_trigger: None,
            pending: false,
        }
    }

    /// Record an event. Restarts the quiet-period timer.
    pub fn trigger(&mut self) {
        self.last_trigger = Some(Instant::now());
        self.pending = true;
    }

    /// Record an event with an explicit timestamp (for deterministic testing).
    pub fn trigger_at(&mut self, now: Instant) {
        self.last_trigger = Some(now);
        self.pending = true;
    }

    /// Check if the quiet period has elapsed. Returns `true` exactly once
    /// per quiet-period completion.
    pub fn poll(&mut self) -> bool {
        self.poll_at(Instant::now())
    }

    /// Check with explicit timestamp (for deterministic testing).
    pub fn poll_at(&mut self, now: Instant) -> bool {
        if !self.pending {
            return false;
        }
        if let Some(last) = self.last_trigger {
            if now.duration_since(last) >= self.delay {
                self.pending = false;
                self.last_trigger = None;
                return true;
            }
        }
        false
    }

    /// Cancel any pending execution.
    pub fn reset(&mut self) {
        self.pending = false;
        self.last_trigger = None;
    }

    pub fn is_pending(&self) -> bool {
        self.pending
    }
}
```

**Re-export** from `crates/term-wm-core/src/utils/debounce/mod.rs` and `crates/term-wm-core/src/utils/mod.rs`.

**Unit tests** covering:
- Single trigger → fires after delay
- Rapid burst → fires only once after quiet period
- Reset cancels pending
- `poll_at` with explicit timestamps for determinism
