# Optimize term-wm Idle CPU (macOS)

## Problem

Profiling with `samply` shows **12% CPU usage during idle** on macOS (1 core pegged at 100% on an 8-core machine). Linux shows lower idle CPU. The profile captures ~25.8 seconds of idle time, and one background thread (`Thread <13365839>`) has a weight of **25,441ms** — confirming a busy-spin.

## Root Causes (Ordered by Impact)

### 1. `BackgroundConsoleReader` Busy-Spin (CRITICAL — 100% of 1 core)

**File:** `crates/term-wm-console/src/background_console_reader.rs:97-122`

On macOS, `crossterm::event::poll()` frequently returns `Ok(false)` **immediately** (0µs) without blocking for the 100ms timeout. The empty `Ok(false)` arm means the thread executes millions of `poll()` calls per second, consuming 100% of a CPU core while idle.

**Proof from profile:** Thread `<13365839>` has weight 25,441ms in a ~25.8s profile — a single thread running at ~98.6% CPU for the entire duration.

### 2. O(rows × cols × row) Row Lookup in Rendering

**File:** `crates/term-wm-ui-components/src/terminal.rs:685-686`

`screen.cell(row, col)` inside the column loop re-evaluates `visible_rows().nth(row)` for every column. This is O(row) per call due to the iterator chain, making total render complexity O(rows × cols × row).

### 3. Per-Cell Bounds Checks in Render Loop

`buffer.cell_mut()` does two bounds checks per cell. Inherent to the ratatui API.

### 4. Render Screen Hotspot Breakdown

| CPU (µs) | % | Function |
|-----------|------|----------|
| 26,828 + 24,860 | 2.0% | `Rect::contains` — bounds check per cell |
| 23,236 | 0.9% | `resolve_color` — called 2x per cell |
| 13,653 + 10,741 | 1.0% | `unicode_segmentation` — grapheme cluster iteration |

| 11,927 | 0.5% | `Cell::symbol` / `Cell::eq` — cell comparison |

| 11,285 | 0.4% | `encode_utf8` — UTF-8 encoding per cell |
| 9,800 | 0.4% | `Cell::set_style` — style application |

### 5. Link Overlay Doubles Iteration

Lines 648-678 iterate ALL cells for link detection before the main render loop.

### 6. Session Server 100ms Polling

Every active channel wakes 10×/second to check for exited sessions.

### 7. Debug Alignment Checks

`core::ptr::is_aligned_to` at 0.5%. Debug assertions that vanish in release builds.

## Implementation Plan

### Phase 1: Fix BackgroundConsoleReader Busy-Spin (CRITICAL)

**File:** `crates/term-wm-console/src/background_console_reader.rs:97-122`

```rust
fn input_loop(tx: Sender<Event>, shutdown: Arc<AtomicBool>) {
    loop {
        if shutdown.load(Ordering::Acquire) {
            break;
        }
        match crossterm::event::poll(CROSSTERM_POLL_INTERVAL) {
            Ok(true) => {
                match crossterm::event::read() {
                    Ok(evt) => {
                        let Some(core_evt) = term_wm_crossterm_adapter::try_translate_event(evt)
                        else {
                            continue;
                        };
                        if tx.send(core_evt).is_err() {
                            break;
                        }
                    }
                    Err(_) => break,
                }
            }
            Ok(false) => {
                thread::sleep(CROSSTERM_POLL_INTERVAL);
            }
            Err(_) => break,
        }
    }
}
```

**Why not blocking `event::read()`:** `BackgroundConsoleReader::drop` relies on `shutdown.store(true)` to terminate the loop. A thread blocked inside `event::read()` cannot evaluate the atomic flag until an external TTY event occurs, leaking the thread and causing process teardown hangs.

**Impact:** Eliminates 100% CPU spin on 1 core.

### Phase 2: Expose `visible_row` on `term_wm_vt100::Screen`

**Dependency setup:** `term-wm-vt100` is a crates.io dependency. A local fork exists at `../term-wm-vt100` and can be activated via `.cargo/config.toml`:

```toml
[patch.crates-io]
term-wm-vt100 = { path = "../term-wm-vt100" }
```

**File:** `term-wm-vt100/src/screen.rs`

Add a public `visible_row` method to `Screen` so caller crates can access rows without touching the private `grid` field:

```rust
impl Screen {
    pub fn visible_row(&self, row: u16) -> Option<&crate::row::Row> {
        self.grid().visible_row(row)
    }
}
```

**Impact:** Enables Phase 3 without private field access errors.

### Phase 3: Hoist Row Lookup Outside Column Loop

**File:** `crates/term-wm-ui-components/src/terminal.rs:685-753`

Call `screen.visible_row(row)` once per row before entering the column loop:

```rust
let parser_arc = pane.shared_parser();
let parser = parser_arc.lock().unwrap_or_else(|err| err.into_inner());
let screen = parser.screen();

for row in start_row..start_row + visible.height {
    let cell_y = area.y.saturating_add(row);
    let viewport_row = row.saturating_sub(start_row) as usize;
    let Some(vt_row) = screen.visible_row(row) else { continue; };

    for col in start_col..start_col + visible.width {
        let cell_x = area.x.saturating_add(col);
        let viewport_col = col.saturating_sub(start_col) as usize;

        if let Some(cell) = vt_row.get(col) {
            let mut symbol = cell.contents().chars().next().unwrap_or(' ');
            let (fg, bg) = resolve_colors_with_defaults(cell, default_fg, default_bg);
            let mut style = Style::default();
            if let Some(fg) = fg { style = style.fg(fg); }
            if let Some(bg) = bg { style = style.bg(bg); }
            if cell.bold() { style = style.add_modifier(Modifier::BOLD); }
            if cell.dim() { style = style.add_modifier(Modifier::DIM); }
            if cell.italic() { style = style.add_modifier(Modifier::ITALIC); }
            if cell.underline() { style = style.add_modifier(Modifier::UNDERLINED); }
            if cell.inverse() { style = style.add_modifier(Modifier::REVERSED); }
            if cell.is_wide_continuation() { symbol = ' '; }

            let theme = ctx.config().theme;
            if self.link_overlay.borrow().is_link_cell(viewport_row, viewport_col) {
                style = decorate_link_style(style, &theme);
            }

            if let Some(range) = selection_range {
                let abs_row = selection_row_base.saturating_add(row as usize);
                let abs_col = col as usize;
                if range.contains(LogicalPosition::new(abs_row, abs_col)) {
                    style = style
                        .bg(color_to_ratatui(theme.selection_bg))
                        .fg(color_to_ratatui(theme.selection_fg));
                }
            }

            if let Some(buf_cell) = buffer.cell_mut((cell_x, cell_y)) {
                let mut buf = [0u8; 4];
                if bg.is_none() {
                    buf_cell.reset();
                }
                let sym = symbol.encode_utf8(&mut buf);
                buf_cell.set_symbol(sym).set_style(style);
            }
        } else if let Some(buf_cell) = buffer.cell_mut((cell_x, cell_y)) {
            buf_cell.reset();
            buf_cell.set_symbol(" ");
        }
    }
}
```

**Impact:** Eliminates O(rows × cols × row) → O(rows × cols). For a 100×200 terminal, removes ~2M iterator steps per frame.

### Phase 4: Precompute Style Lookup Table

**File:** `crates/term-wm-ui-components/src/terminal.rs:680-753`

Precompute a default style for plain text cells to avoid 7+ conditional checks per cell:

```rust
let default_style = {
    let mut s = Style::default();
    if let Some(fg) = fg { s = s.fg(fg); }
    if let Some(bg) = bg { s = s.bg(bg); }
    s
};
```

**Impact:** ~10-15% reduction in style-building overhead.
