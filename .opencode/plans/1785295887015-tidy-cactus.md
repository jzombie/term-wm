# Plan: SUPER Key Forwards Through Palette via Data-Driven Keybinding

## Objective
When the command palette is open, pressing SUPER (the OpenCommandPalette keybinding) forwards the key bytes to the focused window instead of closing the palette. This is implemented as a palette-layer keybinding, making it entirely data-driven.

## How It Works
- `OpenCommandPalette` has combo `Ctrl+A` in the Global layer → opens palette when closed
- `SendSuperKeyToWindow` gets the same combo `Ctrl+A` in the CommandPalette layer → forwards key bytes when palette is open
- The runner pre-barrier no longer closes the palette; instead it lets the event fall through to the palette barrier, where the CommandPalette-layer keybinding dispatches `SendSuperKeyToWindow`

- Rename `SendSuperKeyToWindow(WindowKey)` → `SendSuperKeyToWindow(WindowKey)` stays for the command palette menu item
- Add new payload-free variant `SendSuperKeyToFocusedWindow` for the keybinding
- Both map to `Category::Windows`
- `SendSuperKeyToFocusedWindow.layer()` → `ActionLayer::CommandPalette`

### 2. `crates/term-wm-core/src/runner.rs`
- **Dispatch_action**: Handle `SendSuperKeyToFocusedWindow` — uses the `target` WindowKey already provided by the queue loop:
  ```rust
  TermWmAction::SendSuperKeyToFocusedWindow => {
      if let Some(combo) = app.wm().keybindings().first_combo(TermWmAction::OpenCommandPalette) {
          let bytes = KeyEvent::new(combo.code, combo.mods, KeyKind::Press).to_pty_bytes(false);
          if !bytes.is_empty() {
              queue.push_back((target, TermWmAction::KeyToBytes(bytes)));
          }
      }
  }
  ```
  Note: `to_pty_bytes()` returns `Vec<u8>` (not `Option`), so `!bytes.is_empty()` is the correct guard.
- **Pre-barrier (line 467-484)**: Change the close-palette path — when palette is visible, skip the early return so the event falls through to the palette barrier:
  ```rust
  if app.wm().command_palette_visible() {
      // Don't close — fall through to palette barrier
      // where CommandPalette-layer keybinding handles it
  } else {
      app.open_command_palette();
      update_selection_snapshot(app);
      return flush_state_changes(...);
  }
  ```
- **Palette barrier (after line 548)**: After `handle_command_palette_event` returns `None`, check for CommandPalette-layer keybindings. On match: dispatch the forward action, close the palette, return.
  ```rust
  } else if let Event::Key(key) = &evt {
      if app.wm().keybindings().action_for_key_in_layer(key, ActionLayer::CommandPalette).is_some() {
          let focused_key = app.wm().focused_window();
          let mut actions = std::collections::VecDeque::new();
          actions.push_back((focused_key, TermWmAction::SendSuperKeyToFocusedWindow));
          drain_action_queue(app, &mut actions);
          app.wm().close_command_palette();
          update_selection_snapshot(app);
          return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
      }
  }
  ```
  Note: We construct the action directly (known) to avoid the lifetime ambiguity the reviewer flagged. The key point: dispatch SUPER bytes, THEN close palette.
- Add `use crate::actions::ActionLayer;` import if not present

```rust
#[test]
fn send_super_key_matches_open_command_palette() {
    use crate::events::KeyEvent;
    let kb = KeyBindings::default();
    let global_combo = kb.first_combo(TermWmAction::OpenCommandPalette)
        .expect("OpenCommandPalette must have a default keybinding");
    let test_key = KeyEvent::new(global_combo.code, global_combo.mods, crate::events::KeyKind::Press);
    let found = kb.action_for_key_in_layer(&test_key, ActionLayer::CommandPalette);
    assert_eq!(found, Some(TermWmAction::SendSuperKeyToFocusedWindow));
}
```
