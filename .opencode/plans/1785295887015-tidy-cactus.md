# Plan: Dynamic Window Titles in Command Palette + Send SUPER Shortcut

## Goal
1. Replace hardcoded "Close Window" / "Minimize Window" / "Maximize Window" / "Restore Window" in the command palette with the actual window title (e.g., "Close htop").
2. Add a new item above "Close <title>" with icon "S" labeled "Send <super_key> to <title>" that sends the OpenCommandPalette key combo bytes to the focused terminal.

## Super Key Meaning
"SUPER" refers to the keyboard shortcut bound to `OpenCommandPalette` (default: `Ctrl+A`). Its display string is obtained dynamically via `self.keybindings().combos_for(TermWmAction::OpenCommandPalette)` — no hardcoding.

## Files to Modify

### 1. `crates/term-wm-core/src/actions.rs`
- Add `SendCommandPaletteKeyToWindow(WindowKey)` variant to `TermWmAction`
- Add to `layer()` → `ActionLayer::Global`
- Add to `category()` → `Category::Windows`
- Add `Display` impl string → "Send command palette key to window"

### 2. `crates/term-wm-core/src/runner.rs`
- Handle `SendCommandPaletteKeyToWindow(key)` in `dispatch_action`:
  - Get first `KeyCombo` for `OpenCommandPalette` from `app.wm().keybindings().first_combo()`
  - Construct `KeyEvent::new(combo.code, combo.mods, KeyKind::Press)` and call `.to_pty_bytes(false)`
  - Queue `TermWmAction::KeyToBytes(bytes)` for the window

### 3. `crates/term-wm-core/src/window/window_manager/mod.rs`
- Modify `wm_menu_items()` (line 2669):
  - Stop using `window_management_buttons()` for menu items — inline the items with dynamic titles
  - Get focused window title via `self.window_title(focused)`
  - Get super key display via `self.keybindings().combos_for(TermWmAction::OpenCommandPalette).first()`
  - Add "Send <super_key> to <title>" with icon "S" above "Close <title>"
  - Replace "Close Window"/"Minimize Window"/"Maximize Window"/"Restore Window" labels with "Close <title>"/etc.

### 4. `crates/term-wm-core/src/window/window_manager/focus.rs`
- Add `| TermWmAction::SendCommandPaletteKeyToWindow(_)` to the filter match in the palette rebuild on focus change (around line 84-89)

### 5. `src/term_wm_app.rs`
- Add `| TermWmAction::SendCommandPaletteKeyToWindow(_)` to the filter match in `open_command_palette()` (around line 493-498)
