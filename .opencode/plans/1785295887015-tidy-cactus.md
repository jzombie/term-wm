# Plan: Centralize Title Truncation + Unicode-Safe Ellipsis

## Objective
Replace inline `.chars().take(N)` hacks and the "all-or-nothing" chrome header rendering with a single, unicode-width-aware `truncate_with_ellipsis` function.

## Key Design Decisions
- **New function**, not a boolean flag — avoids control coupling.
- **`unicode-width` crate** for cellular-width measurement.
- **Single ellipsis `…` (U+2026)**, consumes exactly 1 cell.
- **Guard `max_width == 0`** to prevent spatial boundary violations.

## Files to Modify

### 1. `Cargo.toml` (workspace root)
- Add `unicode-width = "0.2"` to `[workspace.dependencies]`

### 2. `crates/term-wm-core/Cargo.toml`
- Add `unicode-width = { workspace = true }` to `[dependencies]`

### 3. `crates/term-wm-core/src/utils/mod.rs`
- Add: `use unicode_width::{UnicodeWidthChar, UnicodeWidthStr};`
- Add `truncate_with_ellipsis(value: &str, max_width: usize) -> String`:
  - `if max_width == 0 { return String::new(); }`
  - `if value.width() <= max_width { return value.to_string(); }`
  - Reserve 1 cell for `…`, iterate chars via `c.width().unwrap_or(0)`, break when running sum exceeds target, append `…`
- Add `#[cfg(test)] mod tests { ... }` block at bottom with:
  - `empty_string_returns_empty` — `truncate_with_ellipsis("", 10) == ""`
  - `zero_max_width_returns_empty` — `truncate_with_ellipsis("hello", 0) == ""`
  - `fits_exactly_returns_unchanged` — `truncate_with_ellipsis("hello", 5) == "hello"`
  - `truncates_with_ellipsis` — `truncate_with_ellipsis("hello world", 8) == "hello w…"`
  - `single_char_target` — `truncate_with_ellipsis("ab", 1) == "…"` (ellipsis fits in 1 cell)
  - `cjk_fits_one_char_plus_ellipsis` — `truncate_with_ellipsis("日本語", 3)` returns `"日…"` (1st CJK char is 2 cells, plus 1-cell ellipsis fits in 3)
  - `cjk_rejected_when_no_room` — `truncate_with_ellipsis("日本語", 2)` returns `"…"` (no CJK char fits, only the 1-cell ellipsis)
  - `cjk_mixed_truncation` — `truncate_with_ellipsis("ab日本語", 6)` returns `"ab日…"` (4 cells used, 1 for ellipsis, total 5 ≤ 6)

### 4. `crates/term-wm-core/src/window/window_manager/mod.rs`
- Replace inline `.chars().take(22)` truncation with `crate::utils::truncate_with_ellipsis(&raw_title, 25)`

### 5. `crates/term-wm-console/src/draw_plan_renderer.rs`
- Replace the `if title_len <= header_width { ... }` center-render block (lines 1194-1207) with:
  - Import `use term_wm_core::utils::truncate_with_ellipsis;` and `use unicode_width::{UnicodeWidthChar, UnicodeWidthStr};`
  - `let display_title = truncate_with_ellipsis(title, header_width as usize);`
  - Compute centering using cellular width: `let start_x = header_left + (header_width.saturating_sub(display_title.width() as u16)) / 2;`
  - Render using a mutable `current_x` accumulator advancing by each character's cellular width:
    ```rust
    let mut cx = start_x;
    for c in display_title.chars() {
        let cw = c.width().unwrap_or(0) as u16;
        if cw == 0 { continue; }
        let rel_x = cx as usize - buffer.area.x as usize;
        buffer.content[rel_y * buf_w + rel_x].set_symbol(&c.to_string());
        buffer.content[rel_y * buf_w + rel_x].set_style(header_style);
        cx += cw;
    }
    ```

### 6. No changes to:
- `wm_top_panel.rs` / `wm_bottom_panel.rs` — they use `truncate_to_width` (no ellipsis), which is correct for their compact labels.
