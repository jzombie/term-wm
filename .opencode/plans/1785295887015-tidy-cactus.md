# Plan: Dynamic Window Titles in Command Palette + Send SUPER Shortcut

## Goal
1. Replace hardcoded "Close Window" / "Minimize Window" / "Maximize Window" / "Restore Window" in the command palette with the actual window title (e.g., "Close htop").
2. Add a new item above "Close <title>" with icon "S" labeled "Send <super_key> to <title>" that sends the OpenCommandPalette key combo bytes to the focused terminal.

## Super Key Meaning
"SUPER" refers to the keyboard shortcut bound to `OpenCommandPalette` (default: `Ctrl+A`). Its display string is obtained dynamically via `self.keybindings().combos_for(TermWmAction::OpenCommandPalette)` — no hardcoding.

## Safety Constraints
- **Title truncation**: Window titles from PTY processes (OSC 0/2) are untrusted and unbounded. Clamp to 25 chars with `…` ellipsis before interpolation.
- **Keybinding fallback**: If `OpenCommandPalette` has no bound key, use "Super" as fallback string. Never unwrap unsafely.
- **PTY routing**: `KeyToBytes(bytes)` is correct — `dispatch_action` catch-all routes to `comp.update()` → `pane.write_bytes()`. Guard against empty bytes via `!bytes.is_empty()`.
- **No unwraps anywhere in this change**.

### 2. `crates/term-wm-core/src/runner.rs`
- Handle in `dispatch_action`:
  ```rust
  TermWmAction::SendCommandPaletteKeyToWindow(target) => {
      if let Some(combo) = app.wm().keybindings().first_combo(TermWmAction::OpenCommandPalette) {
          let bytes = KeyEvent::new(combo.code, combo.mods, KeyKind::Press).to_pty_bytes(false);
          if !bytes.is_empty() {
              queue.push_back((target, TermWmAction::KeyToBytes(bytes)));
          }
      }
  }
  ```
