# Plan: SUPER Key Forwards Through Palette via Data-Driven Keybinding

## Objective
When the command palette is open, pressing SUPER (the OpenCommandPalette keybinding) forwards the key bytes to the focused window instead of closing the palette. This is implemented as a palette-layer keybinding, making it entirely data-driven.

## How It Works
- `OpenCommandPalette` has combo `Ctrl+A` in the Global layer → opens palette when closed
- `SendSuperKeyToWindow` gets the same combo `Ctrl+A` in the CommandPalette layer → forwards key bytes when palette is open
- The runner pre-barrier no longer closes the palette; instead it lets the event fall through to the palette barrier, where the CommandPalette-layer keybinding dispatches `SendSuperKeyToWindow`

## Files to Modify

### 1. `crates/term-wm-core/src/keybindings.rs`
- Add `SendSuperKeyToWindow: [ (KeyCode::Char('a'), KeyModifiers { control: true, shift: false, alt: false }) ]` to the default keybindings macro (same combo as OpenCommandPalette)

### 2. `crates/term-wm-core/src/runner.rs`
- **Pre-barrier (line 467-484)**: Change the close-palette path — when palette is visible, skip the early return so the event falls through to the palette barrier:
  ```rust
  if app.wm().command_palette_visible() {
      // Don't close — fall through to palette barrier
      // where CommandPalette-layer keybinding handles it
  } else {
      app.open_command_palette();
      update_selection_snapshot(app);
      return flush_state_changes(...);
  }
  ```
- **Palette barrier (after line 548)**: After `handle_command_palette_event` returns `None` (event Ignored by palette), check for CommandPalette-layer keybindings:
  ```rust
  } else if let Event::Key(key) = &evt {
      if let Some(action) = app.wm().keybindings().action_for_key_in_layer(key, ActionLayer::CommandPalette) {
          let focused = app.wm().focused_window();
          let mut actions = std::collections::VecDeque::new();
          actions.push_back((focused, action));
          drain_action_queue(app, &mut actions);
      }
  }
  ```
- Add `use crate::actions::ActionLayer;` import if not present
