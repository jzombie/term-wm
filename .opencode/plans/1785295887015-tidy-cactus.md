### 2. `crates/term-wm-core/src/runner.rs`
- Handle in `dispatch_action`:
  ```rust
  TermWmAction::SendCommandPaletteKeyToWindow(target) => {
      if let Some(combo) = app.wm().keybindings().first_combo(TermWmAction::OpenCommandPalette) {
          let bytes = KeyEvent::new(combo.code, combo.mods, KeyKind::Press).to_pty_bytes(false);
          if !bytes.is_empty() {
              queue.push_back((target, TermWmAction::KeyToBytes(bytes)));
          }
      }
  }
  ```
  Note: `to_pty_bytes(false)` returns `Vec<u8>` — `!bytes.is_empty()` guard handles empty output for untypable combos.
