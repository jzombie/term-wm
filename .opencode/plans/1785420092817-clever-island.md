# Refactoring: Gap-Free Binary Tiling with Viewport Maximize

## Architectural Changes

### 1. Maximization = Viewport Overlay (NOT Tree Mutation)
Add `maximized_window: Option<WindowKey>` to `WindowManager`. On maximize:
- Set `maximized_window = Some(key)` — tree is NOT mutated
- On unmaximize: set `maximized_window = None` — zero spatial drift
- During render: if `maximized_window` is set, allocate 100% of `managed_area` to that window

### 2. Remove `Void` from `LayoutNode` Enum
The `Void` variant is eliminated. The type system guarantees gap-free trees:
```rust
pub enum LayoutNode<Id> {
    Leaf(Id),
    Split { id: NodeId, direction: Direction, children: Vec<LayoutNode<Id>>, weights: Vec<u16>, resizable: bool },
}
```

### 3. Minimization = Structural Prune + TreePath
Capture the window's topological path from root before pruning:
- `remove_and_collapse(key)` — consume-and-return tree collapse
- `TreePath = Vec<PathStep>` where each step records child index AND split direction
- On restore: re-insert at path, converting target Leaf into Split when needed

### 4. Remove `void_id` from `Window` struct  
Replace with `tree_path: Option<TreePath>`.

### 5. `maximized_window` Single Source of Truth
- Only one window can be maximized at a time
- `toggle_maximize` clears previous maximized window's `is_maximized` flag
- `close_window` clears `maximized_window` if the closed window was maximized

### 1g. Add `remove_and_collapse(self, key: Id) -> Option<Self>`
Recursively prunes the target `Leaf` without destroying sibling windows:
```rust
/// Removes `key` from the tree and collapses parent splits.
/// Recurses into child `Split` nodes so sibling windows in the same
/// subtree are preserved. Returns `None` if the tree is now empty.
pub fn remove_and_collapse(self, key: Id) -> Option<Self> {
    match self {
        Self::Leaf(k) if k == key => None,
        Self::Leaf(k) => Some(Self::Leaf(k)),
        Self::Split { id, direction, children, weights, resizable } => {
            let mut new_children = Vec::with_capacity(children.len());
            let mut new_weights = Vec::with_capacity(weights.len());
            let mut removed = false;

            for (child, weight) in children.into_iter().zip(weights.into_iter()) {
                if !removed && child.contains_key(&key) {
                    if let Some(collapsed) = child.remove_and_collapse(key) {
                        new_children.push(collapsed);
                        new_weights.push(weight);
                    }
                    removed = true;
                } else {
                    new_children.push(child);
                    new_weights.push(weight);
                }
            }

            match new_children.len() {
                0 => None,
                1 => Some(new_children.remove(0)),
                _ => Some(Self::Split { id, direction, children: new_children, weights: new_weights, resizable }),
            }
        }
    }
}
```

### 1h. Add `find_path` to `LayoutNode` (capture topological path before removal)
```rust
/// Records path steps from root to the leaf matching `key`.
/// Returns `Some(path)` if found, `None` otherwise.
pub fn find_path(&self, key: &Id, path: &mut TreePath) -> bool {
    match self {
        Self::Leaf(k) => k == key,
        Self::Split { direction, children, .. } => {
            for (i, child) in children.iter().enumerate() {
                if child.find_path(key, path) {
                    path.push(PathStep { child_index: i, direction: *direction });
                    return true;
                }
            }
            false
        }
    }
}
```

### 1i. Add `insert_at_path` + `insert_at_path_recursive` to `LayoutNode`
Non-destructive root re-insertion saves and restores the old root if it isn't a single leaf:

```rust
/// Re-insert `key` into the tree at the given topological path.
/// Returns true if insertion succeeded.
pub fn insert_at_path(&mut self, key: Id, path: &[PathStep]) -> bool {
    if path.is_empty() {
        // Root re-insertion: only split if root is a single Leaf
        let old_root = std::mem::replace(self, Self::Leaf(key));
        match old_root {
            Self::Leaf(existing) if existing == key => {
                *self = Self::Leaf(key);
                true
            }
            Self::Leaf(existing) => {
                *self = Self::Split {
                    id: NodeId::next(),
                    direction: Direction::Horizontal,
                    children: vec![Self::Leaf(existing), Self::Leaf(key)],
                    weights: vec![1, 1],
                    resizable: true,
                };
                true
            }
            _ => {
                // Root is a Split — restore it and recurse
                *self = old_root;
                self.insert_at_path_recursive(key, path)
            }
        }
    } else {
        self.insert_at_path_recursive(key, path)
    }
}

/// Recursive path traversal: follows `child_index` steps, converting
/// the target `Leaf` into a `Split` using `step.direction`.
/// Clamps `child_index` to valid range for collapsed trees.
fn insert_at_path_recursive(&mut self, key: Id, path: &[PathStep]) -> bool {
    match self {
        Self::Leaf(existing_key) => {
            if *existing_key == key {
                return true;
            }
            let dir = path.first().map(|s| s.direction).unwrap_or(Direction::Horizontal);
            let old_leaf = Self::Leaf(*existing_key);
            *self = Self::Split {
                id: NodeId::next(),
                direction: dir,
                children: vec![old_leaf, Self::Leaf(key)],
                weights: vec![1, 1],
                resizable: true,
            };
            true
        }
        Self::Split { ref mut direction, ref mut children, ref mut weights, .. } => {
            if let Some((head, tail)) = path.split_first() {
                let target_idx = head.child_index.min(children.len().saturating_sub(1));
                children[target_idx].insert_at_path_recursive(key, tail)
            } else {
                // Path exhausted on a Split: append as new child
                children.push(Self::Leaf(key));
                weights.push(1);
                *direction = Direction::Horizontal;
                true
            }
        }
    }
}
```

```rust
pub(super) fn reattach_to_tiling_layout(&mut self, key: WindowKey) {
    if self.layout_contains(key) { return; }
    let path = self.window(key).and_then(|w| w.tree_path());
    
    let Some(ref mut layout) = self.managed_layout else {
        self.managed_layout = Some(TilingLayout::new(LayoutNode::leaf(key)));
        return;
    };

    if layout.is_monocle() {
        layout.append_monocle_leaf(key);
    } else {
        let inserted = path.as_ref()
            .map(|p| layout.insert_at_path(key, p))
            .unwrap_or(false);

        if !inserted {
            layout.insert_window_balanced(key, self.managed_area);
        }
    }
    
    if let Some(w) = self.windows.get_mut(key) {
        w.clear_tree_path();
    }
}
```

## Phase 6: WindowManager Chrome (`window/window_manager/chrome.rs`)

### 6a. Rewrite `toggle_maximize`
Single source of truth — clears previous maximized window's flag, restores floating geometry on unmaximize:
```rust
pub fn toggle_maximize(&mut self, key: WindowKey) {
    if let Some(prev) = self.maximized_window.take() {
        if let Some(w) = self.windows.get_mut(prev) {
            w.set_maximized(false);
            // Restore floating rect if this was a floating window
            if w.is_floating() {
                if let Some(prev_rect) = w.take_prev_floating_rect() {
                    w.set_floating_rect(Some(prev_rect));
                }
            }
        }
        if prev == key {
            return; // Unmaximized the target window
        }
    }

    // Maximize the new window
    if let Some(w) = self.windows.get_mut(key) {
        if w.is_floating() {
            w.set_prev_floating_rect(w.floating_rect());
        }
        w.set_maximized(true);
    }
    self.maximized_window = Some(key);
}
```
