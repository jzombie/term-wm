# Plan: Visibility-Filtered Geometry

## Problem
The previous approach mutated the layout tree on minimize (removing windows, replacing leaves with Voids) then tried to restore using fragile path-memory. This caused:
- Windows getting lost when tree collapsed then restored
- Layout drift on maximize/unmaximize  
- Dead Void nodes left in the tree

## Solution
Three changes working together:

### A. `detach_from_tiling_layout` — branch on state
- **Iconic (minimized)**: NO-OP — window stays in tree, geometry pass skips it
- **Unmapped/None (closed/destroyed)**: Remove from tree as before

### B. Geometry engine — visibility-aware region allocation
Add `calculate_regions` to `LayoutNode` that accepts a `visible_keys: &HashSet<Id>` set. Subtrees with no visible leaves get zero-size rects; visible siblings absorb the freed space.

### C. `register_managed_layout` — use two key sets  
- **Topology keys**: ALL non-floating, non-unmapped windows (including Iconic) — used only to keep the `TilingLayout::sync` consistent
- **Visibility keys**: Only Mapped, non-floating windows — passed to `calculate_regions`

## Step 1: `calculate_regions_recursive` in layout engine

**File:** `crates/term-wm-layout-engine/src/tiling.rs`

Add to `LayoutNode<Id>`:

```rust
/// Compute regions, allocating 0-area to hidden (not in visible_keys)
/// leaves and distributing their space to visible siblings.
pub fn calculate_regions(
    &self,
    area: LayoutRect,
    visible_keys: &HashSet<Id>,
) -> Vec<(Id, LayoutRect)> {
    let mut regions = Vec::new();
    self.calculate_regions_recursive(area, visible_keys, &mut regions);
    regions
}

fn calculate_regions_recursive(
    &self,
    area: LayoutRect,
    visible_keys: &HashSet<Id>,
    out: &mut Vec<(Id, LayoutRect)>,
) {
    match self {
        LayoutNode::Leaf(id) => {
            if visible_keys.contains(id) {
                out.push((*id, area));
            }
            // Hidden leaves: no region pushed
        }
        LayoutNode::Split { direction, children, weights, resizable } => {
            // Count visible children
            let visible_indices: Vec<usize> = children
                .iter()
                .enumerate()
                .filter(|(_, c)| c.has_visible_leaf(visible_keys))
                .map(|(i, _)| i)
                .collect();

            if visible_indices.is_empty() {
                return; // No regions from this subtree
            }

            if visible_indices.len() == 1 {
                // Only one visible child — give it the full area
                children[visible_indices[0]]
                    .calculate_regions_recursive(area, visible_keys, out);
                return;
            }

            // Multiple visible children: split area among them using weights
            let orientation = Orientation::from(*direction);
            let total_dim = match direction {
                Direction::Horizontal => area.width,
                Direction::Vertical => area.height,
            };
            let visible_weights: Vec<u16> = visible_indices.iter().map(|&i| weights[i]).collect();
            let n_visible = visible_weights.len();

            let (rects, _gaps) = split::split_rects_with_gaps(
                area,
                orientation,
                &visible_weights,
                n_visible,
                split::gap_size(orientation, total_dim, n_visible, *resizable),
            );

            for (&idx, rect) in visible_indices.iter().zip(rects) {
                children[idx].calculate_regions_recursive(rect, visible_keys, out);
            }
        }
    }
}

/// Returns true if any leaf in this subtree is in visible_keys.
fn has_visible_leaf(&self, visible_keys: &HashSet<Id>) -> bool {
    match self {
        LayoutNode::Leaf(id) => visible_keys.contains(id),
        LayoutNode::Split { children, .. } => {
            children.iter().any(|c| c.has_visible_leaf(visible_keys))
        }
    }
}
```

pub(super) fn detach_from_tiling_layout(&mut self, key: WindowKey) {
    let state = self.window_state(key);
    if state == Some(WindowState::Unmapped) || state.is_none() {
        // Window closed/destroyed: prune from tree permanently
        if let Some(ref mut layout) = self.managed_layout {
            if layout.remove_window(key) {
                self.managed_layout = None;
            }
        }
    }
    // Minimized (Iconic): leave in tree — visibility filtering handles it
}

## Step 5: Update `register_managed_layout`

**File:** `crates/term-wm-core/src/window/window_manager/layout.rs`

Replace the existing loop that iterates `layout.regions()` (lines ~416-437) with:

```rust
if let Some(layout) = self.managed_layout.as_mut() {
    // 1. Structural Sync: ALL managed, non-destroyed windows
    let topology_keys: Vec<WindowKey> = self
        .windows
        .iter()
        .filter(|(_, w)| !w.is_floating() && w.state() != WindowState::Unmapped)
        .map(|(k, _)| *k)
        .collect();
    layout.sync(&topology_keys);

    // 2. Geometry Calculation: Only visible (Mapped) windows
    let visible_keys: std::collections::HashSet<WindowKey> = self
        .windows
        .iter()
        .filter(|(_, w)| w.state() == WindowState::Mapped && !w.is_floating())
        .map(|(k, _)| *k)
        .collect();

    let regions = layout.calculate_regions(self.managed_area, &visible_keys);
    let handles = layout.handles(self.managed_area);
    for (key, rect) in &regions {
        if self.window(*key).is_none() { continue; }
        self.regions.set(*key, *rect);
        active_keys.push(*key);
    }

    // 3. Viewport Override: maximized window fills screen
    if let Some(max_key) = self.maximized_window {
        if self.window(max_key).is_some_and(|w| w.state() == WindowState::Mapped) {
            if !active_keys.contains(&max_key) {
                active_keys.push(max_key);
            }
            self.regions.set(max_key, self.managed_area);
            // Cull background window regions (they render behind)
            for &key in &active_keys {
                if key != max_key {
                    self.regions.remove(key);
                }
            }
        }
    }
}
```
