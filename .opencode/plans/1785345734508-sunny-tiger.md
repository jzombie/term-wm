# Fix: Restore minimized window in float mode doesn't bring it to top

## Bug

When a window is minimized while in tiled mode, then the layout is switched to
float mode (via `toggle_tiling`), restoring the minimized window makes it
tiled (no `floating_rect`) even though we're in float mode. This means:

1. The tiled window renders **behind** all floating windows (bifurcated draw
   order puts tiled first, floating on top).
2. `bring_to_front_key()` is a no-op for tiled windows.
3. A new `TilingLayout` is created, putting the WM in an inconsistent
   tiled+floating mixed state.

## Root Cause

In `transition_window()` at `mod.rs:511` (`Iconic → Mapped`), the handler
calls `reattach_to_tiling_layout()` unconditionally. If `managed_layout` is
`None` (float mode), `reattach_to_tiling_layout` creates a brand new
`TilingLayout` with just the restored window — it doesn't give the window a
`floating_rect`.

Compare with the `Unmapped → Mapped` handler at line 534, which correctly
checks for float mode / other floating windows and assigns a floating rect
via `default_cascading_rect()`.

## Fix

In the `(Iconic, Mapped)` branch of `transition_window()` in
`mod.rs:511`, add the same float-mode check that the `(Unmapped, Mapped)`
branch performs:

```rust
(WindowState::Iconic, WindowState::Mapped) => {
    if !self.z_order.contains(&key) {
        self.z_order.push(key);
    }
    if !self.managed_draw_order.contains(&key) {
        self.managed_draw_order.push(key);
    }

    // If we're in float mode or all other windows are floating,
    // assign a floating rect instead of reattaching to tiling.
    let has_other_floating = self
        .windows
        .values()
        .any(|w| w.state() == WindowState::Mapped && w.is_floating());
    let floating_mode = self.managed_layout.is_none();

    if !self.is_window_floating(key) && (has_other_floating || floating_mode) {
        let index = self.windows.len().saturating_sub(1);
        let fallback = self.default_cascading_rect(index);
        self.set_floating_rect(
            key,
            Some(crate::window::FloatRectSpec::Absolute(fallback)),
        );
        self.bring_to_front_key(key);
    } else {
        self.reattach_to_tiling_layout(key);
    }

    self.focus_add(key);
}
```
