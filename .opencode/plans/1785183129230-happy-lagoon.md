## 2. `wm_menu_items()` Returns `Vec<MenuDisplayItem>` Directly

**`crates/term-wm-core/src/window/window_manager/mod.rs`**

`wm_menu_items()` builds the list sequentially with `MenuDisplayItem::Separator` inline — no parallel index arrays:

```rust
pub fn wm_menu_items(&self, debug_log_visible: bool, system_panel_visible: bool)
    -> Vec<MenuDisplayItem<TermWmAction>>
{
    let mut items = Vec::new();

    items.push(MenuDisplayItem::Item(MenuItem { label: "Resume".. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: "New Window".. }));
    items.push(MenuDisplayItem::Separator);

    items.push(MenuDisplayItem::Item(MenuItem { label: mouse_label.. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: clipboard_label.. }));
    // ... etc
    items.push(MenuDisplayItem::Separator);

    // Help / Exit UI group
    items.push(MenuDisplayItem::Item(MenuItem { label: "Help".. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: "Exit UI".. }));
    items.push(MenuDisplayItem::Separator);

    // Display mode group
    items.push(MenuDisplayItem::Item(MenuItem { label: monocle_label.. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: tiling_label.. }));
    items.push(MenuDisplayItem::Separator);

    // Dynamic items (window management, switch-to)
    for btn in self.window_management_buttons() { items.push(MenuDisplayItem::Item(..)); }
    for (key, title) in self.window_titles() { items.push(MenuDisplayItem::Item(..)); }

    items
}
```

Group order:
```
Resume
New Window
─────────────────────
Mouse: Enable/Disable Capture
Clipboard: Enable/Disable
Window: Enable/Disable Selection
System: Enable/Disable Debug Log
System: Enable/Disable Panel
─────────────────────
Help
Exit UI
─────────────────────
View: Enable/Disable/Set Monocle Mode
View: Enable/Disable Tiling
─────────────────────
Close/Maximize/Minimize Window (dynamic)
Switch to: title (dynamic)
```

## 5. Palette Pipeline

**`crates/term-wm-ui-components/src/command_palette.rs`**

```rust
pub enum PaletteDisplayNode {
    Item(PaletteItem),
    Separator,
}
```

`CommandPaletteComponent` stores `display_nodes: Vec<PaletteDisplayNode>`.

`rebuild_data_cache()`:
- Build from registry + the `MenuDisplayItem` positions (separators not in registry)
- Produce `Vec<PaletteDisplayNode>` with separators at correct positions

`rerank_with_registry()`:
- Type-safe: extract only `Item` variants, feed `PaletteItem` values to fuzzy scorer
- Result: `Vec<PaletteItem>` — zero separators in search results
- Separators are removed at compile-typed boundaries, not via string matching

`render()`:
- Convert `Vec<PaletteDisplayNode>` → `Vec<MenuDisplayItem>` for inner MenuComponent
- When query is empty: includes separators
- When query is non-empty: items only (separators already stripped by `rerank_with_registry`)

## 4. Action-Oriented Labels (Strict Taxonomy)

Labels follow `Namespace: Verb Object` format as prescribed:

| Current | New |
|---------|-----|
| `Mouse Capture: On/Off` | `Mouse: Enable Capture` / `Mouse: Disable Capture` |
| `Clipboard Mode: On/Off` | `Clipboard: Enable` / `Clipboard: Disable` |
| `Window Selection: On/Off` | `Window: Enable Selection` / `Window: Disable Selection` |
| `Toggle Debug Log` | `System: Enable Debug Log` / `System: Disable Debug Log` |
| `Toggle System Panel` | `System: Enable Panel` / `System: Disable Panel` |
| `Monocle Mode: On/Off/Auto` | `View: Enable Monocle Mode` / `View: Disable Monocle Mode` / `View: Set Monocle Mode Auto` |
| `Toggle Float Mode` / `Toggle Tile Mode` | `View: Enable Tiling` / `View: Disable Tiling` |
| `Resume` | `Resume` (unchanged) |
| `New Window` | `New Window` (unchanged) |
| `Help` | `Help` (unchanged) |
| `Exit UI` | `Exit UI` (unchanged) |

For monocle (3-state):
- `MonocleMode::Auto` → `View: Enable Monocle Mode` (clicking will enable/on)
- `MonocleMode::On` → `View: Disable Monocle Mode` (clicking will disable/off)
- `MonocleMode::Off` → `View: Set Monocle Mode Auto` (clicking will set auto)

`MonocleMode::label()` returns `"Enable Monocle Mode"` / `"Disable Monocle Mode"` / `"Set Monocle Mode Auto"`.

## 6. Separator Behavior During Search

- When query is empty: `PaletteDisplayNode::Separator` variants are present, rendered as `─` lines
- When user types a query: `rerank_with_registry()` pattern-matches, strips `Separator` variants, feeds only `PaletteItem` values to fuzzy scorer
- Result: separators are type-safely excluded from search results (no empty-string hacking)
