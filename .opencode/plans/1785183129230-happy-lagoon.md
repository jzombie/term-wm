# Bug Fix Plan

Root cause: `Overlay::set_menu_items` trait signature accepts `Vec<MenuItem<Msg>>`, erasing the `MenuDisplayItem` sum type at the trait boundary. Every `set_menu_items` call coerces separators into items, losing them permanently.

Secondary root cause: `wm_menu_items()` takes external visibility params, but `focus.rs` hardcodes `false, false`. Fix by moving window/overlay keys into `WindowManager` via `TypeId` registries so state is resolved internally.

## Changes

### 1. Propagate sum type through `Overlay` trait

**`crates/term-wm-core/src/components.rs:283`**
`fn set_menu_items(&mut self, _items: Vec<MenuItem<Msg>>) {}`
→ `fn set_menu_items(&mut self, _items: Vec<MenuDisplayItem<Msg>>) {}`

**`crates/term-wm-core/src/macros.rs:241`**
Update delegate macro signature to match.

### 2. Update overlay impls

**`crates/term-wm-sys-ui-components/src/wm_command_palette.rs`**
`set_menu_items` currently wraps `Vec<MenuItem>` in `MenuDisplayItem::Item(...)`. Accept `Vec<MenuDisplayItem>` and pass directly to `set_items()`.

### 3. `TypeId` registries for system windows AND overlays

**`crates/term-wm-core/src/window/window_manager/mod.rs`**

Replace all hardcoded overlay/window key fields with two `HashMap<TypeId, ...>` maps:

```rust
use std::any::TypeId;
use std::collections::HashMap;

pub system_windows: HashMap<TypeId, WindowKey>,
pub system_overlays: HashMap<TypeId, OverlayKey>,
```

Define marker types for all system windows and overlays:

```rust
pub mod system_tags {
    pub struct DebugLog;
    pub struct SystemPanel;
    pub struct CommandPalette;
    pub struct HelpOverlay;
    pub struct ExitConfirm;
}
```

Add generic accessors:

```rust
pub fn register_system_window<T: 'static>(&mut self, key: WindowKey) {
    self.system_windows.insert(TypeId::of::<T>(), key);
}
pub fn get_system_window<T: 'static>(&self) -> Option<WindowKey> {
    self.system_windows.get(&TypeId::of::<T>()).copied()
}
pub fn register_overlay<T: 'static>(&mut self, key: OverlayKey) {
    self.system_overlays.insert(TypeId::of::<T>(), key);
}
pub fn get_overlay<T: 'static>(&self) -> Option<OverlayKey> {
    self.system_overlays.get(&TypeId::of::<T>()).copied()
}
```

**Delete** the hardcoded fields: `help_key`, `exit_confirm_key`, `command_palette_key`, `debug_key`, `system_panel_key`.

Remove visibility params from `wm_menu_items()` signature. Compute internally:

```rust
use crate::window::window_manager::system_tags;
use crate::window::WindowState;
let debug_visible = self.get_system_window::<system_tags::DebugLog>()
    .is_some_and(|k| self.window_state(k) == Some(WindowState::Mapped));
let panel_visible = self.get_system_window::<system_tags::SystemPanel>()
    .is_some_and(|k| self.window_state(k) == Some(WindowState::Mapped));
```

### 4. Fix `focus.rs` — use overlay registry, preserve separators

**`crates/term-wm-core/src/window/window_manager/focus.rs`**

Replace the palette key lookup and item-rebuild block:

```rust
let Some(palette_key) = self.get_overlay::<system_tags::CommandPalette>() else {
    return;
};
let items = self.wm_menu_items();
let supported = &self.supported_menu_actions;
let filtered: Vec<MenuDisplayItem<_>> = items
    .into_iter()
    .filter(|entry| match entry {
        MenuDisplayItem::Item(item) => {
            supported.contains(&item.action)
                || matches!(item.action, FocusWindow(_) | MaximizeWindow(_) | MinimizeWindow(_) | CloseWindow(_))
        }
        MenuDisplayItem::Separator => true,
    })
    .collect();
if let Some(overlay) = self.overlays.get_mut(palette_key) {
    overlay.set_menu_items(filtered);
}
```

### 5. Update `open_*_overlay` methods in `WindowManager`

**`crates/term-wm-core/src/window/window_manager/mod.rs`**

- `open_command_palette_overlay`: replace `self.command_palette_key = Some(...)` with `self.register_overlay::<system_tags::CommandPalette>(key)`
- `open_help_overlay`: replace `self.help_key = Some(...)` with `self.register_overlay::<system_tags::HelpOverlay>(key)`
- `open_exit_confirm_overlay`: replace `self.exit_confirm_key = Some(...)` with `self.register_overlay::<system_tags::ExitConfirm>(key)`

Update all callers that read the old hardcoded fields (`self.help_key`, `self.command_palette_key`, `self.exit_confirm_key`) to use `self.get_overlay::<system_tags::...>()`.

### 6. Update `term_wm_app.rs`

- After creating debug window / system panel, register:
  ```rust
  self.wm.register_system_window::<system_tags::DebugLog>(debug_key);
  self.wm.register_system_window::<system_tags::SystemPanel>(sys_key);
  ```
- In `open_command_palette()`: remove visibility params — just call `self.wm.wm_menu_items()`.
- In `open_help_overlay()`: no visibility changes needed (help overlay doesn't use wm_menu_items).
