# Plan: Command Palette Reorganization (v3)

## Goal
Relabel command palette options action-oriented. Add visual separators using correct sum types. Fix state synchronization.

## 1. Sum Type for Menu Display Items

**`crates/term-wm-ui-components/src/menu.rs`**

Replace `MenuComponent`'s `Vec<MenuItem<TermWmAction>>` with `Vec<MenuDisplayItem<TermWmAction>>`:

```rust
pub enum MenuDisplayItem<R> {
    Item(MenuItem<R>),
    Separator,
}
```

Changes:
- `set_items(Vec<MenuItem>)` — wraps each in `Item(...)` (backward compat)
- `set_display_items(Vec<MenuDisplayItem>)` — for items with separators
- `render_items()` — pattern match: `Item(mi)` renders normally, `Separator` draws `─` across full width using `disabled_style`
- `update()` for `MenuUp`/`MenuDown` — skip `Separator` by continuing in same direction
- `selected_action()` — returns `None` for `Separator`

## 2. Sum Type for Palette Pipeline

**`crates/term-wm-ui-components/src/command_palette.rs`**

```rust
pub enum PaletteDisplayNode {
    Item(PaletteItem),
    Separator,
}
```

`CommandPaletteComponent` stores:
- `all_display_nodes: Vec<PaletteDisplayNode>` (pre-filtered, includes separators)
- `separator_positions: Vec<usize>` (indices into all_display_nodes)

`rebuild_data_cache()`: Build `all_display_nodes` from registry items, injecting `Separator` at stored positions. Mark which indices are separators.

`rerank_with_registry()`:
- Type-safe: filter `all_display_nodes` keeping only `Item` variants
- Feed only `PaletteItem` values into fuzzy scorer
- Result: `Vec<PaletteItem>` with zero separators (they are removed at compile-typed boundaries, not via string matching)

`render()`:
- Convert `PaletteDisplayNode` list → `MenuDisplayItem` list for inner MenuComponent
- When query is empty: include separators
- When query is non-empty: items only (separators already filtered by `rerank_with_registry`)

## 4. Action-Oriented Labels (Strict Taxonomy)

Labels follow `Namespace: Verb Object` format as prescribed:

| Current | New |
|---------|-----|
| `Mouse Capture: On/Off` | `Mouse: Enable Capture` / `Mouse: Disable Capture` |
| `Clipboard Mode: On/Off` | `Clipboard: Enable` / `Clipboard: Disable` |
| `Window Selection: On/Off` | `Window: Enable Selection` / `Window: Disable Selection` |
| `Toggle Debug Log` | `System: Enable Debug Log` / `System: Disable Debug Log` |
| `Toggle System Panel` | `System: Enable Panel` / `System: Disable Panel` |
| `Monocle Mode: On/Off/Auto` | `View: Enable Monocle Mode` / `View: Disable Monocle Mode` / `View: Set Monocle Mode Auto` |
| `Toggle Float Mode` / `Toggle Tile Mode` | `View: Enable Tiling` / `View: Disable Tiling` |
| `Resume` | `Resume` (unchanged) |
| `New Window` | `New Window` (unchanged) |
| `Help` | `Help` (unchanged) |
| `Exit UI` | `Exit UI` (unchanged) |

For monocle (3-state):
- `MonocleMode::Auto` → `View: Enable Monocle Mode` (clicking will enable/on)
- `MonocleMode::On` → `View: Disable Monocle Mode` (clicking will disable/off)
- `MonocleMode::Off` → `View: Set Monocle Mode Auto` (clicking will set auto)

`MonocleMode::label()` returns `"Enable Monocle Mode"` / `"Disable Monocle Mode"` / `"Set Monocle Mode Auto"`.

## 6. Separator Behavior During Search

- When query is empty: `PaletteDisplayNode::Separator` variants are present, rendered as `─` lines
- When user types a query: `rerank_with_registry()` pattern-matches, strips `Separator` variants, feeds only `PaletteItem` values to fuzzy scorer
- Result: separators are type-safely excluded from search results (no empty-string hacking)
