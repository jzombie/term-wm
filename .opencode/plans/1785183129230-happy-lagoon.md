```rust
pub fn wm_menu_items(&self, debug_log_visible: bool, system_panel_visible: bool)
    -> Vec<MenuDisplayItem<TermWmAction>>
{
    let mut items = Vec::new();

    items.push(MenuDisplayItem::Item(MenuItem { label: "Resume".. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: "New Window".. }));
    items.push(MenuDisplayItem::Separator);

    items.push(MenuDisplayItem::Item(MenuItem { label: mouse_label.. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: clipboard_label.. }));
    // ... etc
    items.push(MenuDisplayItem::Separator);

    // Help / Exit UI group
    items.push(MenuDisplayItem::Item(MenuItem { label: "Help".. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: "Exit UI".. }));
    items.push(MenuDisplayItem::Separator);

    // Display mode group
    items.push(MenuDisplayItem::Item(MenuItem { label: monocle_label.. }));
    items.push(MenuDisplayItem::Item(MenuItem { label: tiling_label.. }));
    items.push(MenuDisplayItem::Separator);

    // Dynamic items (window management, switch-to)
    for btn in self.window_management_buttons() { items.push(MenuDisplayItem::Item(..)); }
    for (key, title) in self.window_titles() { items.push(MenuDisplayItem::Item(..)); }

    items
}
```

## 4. Active Node Sum Type + WmCommandPalette + Deterministic Cache Rebuild

**`crates/term-wm-ui-components/src/command_palette.rs`**

Add `ActivePaletteNode` enum — carries separators alongside registry IDs:

```rust
pub enum ActivePaletteNode {
    Node(CommandNodeId),
    Separator,
}
```

Replace `active_ids: Vec<CommandNodeId>` with `active_nodes: Vec<ActivePaletteNode>`.

**`crates/term-wm-sys-ui-components/src/wm_command_palette.rs`** — on `set_items()`:

Add `component_id: ComponentId` field to struct (initialized in `new()`).

At start of `set_items()`, purge previous nodes:
```rust
self.registry.drop_owner(self.component_id);
```

When registering each node, enforce ownership:
```rust
let mut active_nodes = Vec::new();
for display_item in items {
    match display_item {
        MenuDisplayItem::Item(mi) => {
            let mut node = /* convert mi → CommandNode */;
            node.owner_id = Some(self.component_id);
            let id = self.registry.register(node);
            active_nodes.push(ActivePaletteNode::Node(id));
        }
        MenuDisplayItem::Separator => {
            active_nodes.push(ActivePaletteNode::Separator);
        }
    }
}
palette.active_nodes = active_nodes;
palette.mark_data_dirty();
```

**`CommandPaletteComponent::rebuild_data_cache()`**:
Iterate `self.active_nodes`. For each:
- `Node(id)` → fetch from registry; if context_mask matches, push `PaletteDisplayNode::Item(...)`
- `Separator` → apply collapse rules (see below) before pushing

`PaletteDisplayNode` enum:
```rust
pub enum PaletteDisplayNode {
    Item(PaletteItem),
    Separator,
}
```

**Separator collapse rules** — prevent corrputed topology when context culling removes items:
1. **No leading separators**: skip `Separator` if output cache is empty
2. **No consecutive separators**: skip `Separator` if last output element is also `Separator`
3. **No trailing separator**: after iteration, if last element is `Separator`, `pop()` it

These rules guarantee that the rendered list never starts, ends, or doubles-up on separators regardless of which items are culled by `context_mask`.

`rerank_with_registry()`:
- Extract only `Item` variants, feed `PaletteItem` values to fuzzy scorer
- Result: `Vec<PaletteItem>` — zero separators in search results
- Separators are removed at compile-typed boundaries, not via string matching
- **After building `display_nodes`**: synchronously hydrate the inner `MenuComponent` by converting `PaletteDisplayNode` → `MenuDisplayItem` and calling `menu.set_display_items(converted)` directly (not deferred to `render()`)

`render()`:
- **Removed**: MenuComponent hydration is now done in `rerank_with_registry()` / `rebuild_data_cache()`
- Only renders the search bar and delegates to `ScrollViewComponent`
- Still calls `set_selected()` on MenuComponent (selection index), but item list is already set

## 5. Action-Oriented Labels (Strict Taxonomy)

Labels follow `Namespace: Verb Object` Title Case format:

| Current | New |
|---------|-----|
| `Mouse Capture: On/Off` | `Mouse: Enable Capture` / `Mouse: Disable Capture` |
| `Clipboard Mode: On/Off` | `Clipboard: Enable` / `Clipboard: Disable` |
| `Window Selection: On/Off` | `Window: Enable Selection` / `Window: Disable Selection` |
| `Toggle Debug Log` | `System: Enable Debug Log` / `System: Disable Debug Log` |
| `Toggle System Panel` | `System: Enable Panel` / `System: Disable Panel` |
| `Monocle Mode: On/Off/Auto` | `View: Enable Monocle Mode` / `View: Disable Monocle Mode` / `View: Set Monocle Mode Auto` |
| `Toggle Float Mode` / `Toggle Tile Mode` | `View: Enable Tiling` / `View: Disable Tiling` |
| `Resume` | `Resume` (unchanged) |
| `New Window` | `New Window` (unchanged) |
| `Help` | `Help` (unchanged) |
| `Exit UI` | `Exit UI` (unchanged) |

Monocle 3-state mapping:
- `MonocleMode::Auto` → `View: Enable Monocle Mode` (click → On)
- `MonocleMode::On` → `View: Disable Monocle Mode` (click → Off)
- `MonocleMode::Off` → `View: Set Monocle Mode Auto` (click → Auto)

`MonocleMode::label()` returns `"Enable Monocle Mode"` / `"Disable Monocle Mode"` / `"Set Monocle Mode Auto"`.

## Bug Fix Plan (4 targeted changes)

Three root causes identified:

1. **Dialog height clips separators** — `compute_content_dimensions()` counts `filtered_items` (no separators) → `display_nodes` (with separators)
2. **Debug label stale** — `debug_key.is_some()` checks existence, not window state → `WindowState::Mapped`
3. **Registry/separator annihilation** — prior fix injected `drop_owner` + `component_id`, destroying all registered nodes and thus all separators

### Change 1: Fix dialog height

**File:** `crates/term-wm-sys-ui-components/src/wm_command_palette.rs`
**Line:** 150

Change `self.palette.filtered_items.len()` to `self.palette.display_nodes.len()` in `compute_content_dimensions()`.

### Change 2: Fix debug/system label staleness

**File:** `src/term_wm_app.rs`
**Lines:** 469-470

Replace `self.debug_key.is_some()` / `self.system_panel_key.is_some()` with `WindowState::Mapped` checks:

```rust
let debug_visible = self.debug_key
    .is_some_and(|k| self.wm.window_state(k) == Some(WindowState::Mapped));
let panel_visible = self.system_panel_key
    .is_some_and(|k| self.wm.window_state(k) == Some(WindowState::Mapped));
```

### Change 3: Restore `set_items()` — remove broken `drop_owner` & `component_id`

**File:** `crates/term-wm-sys-ui-components/src/wm_command_palette.rs`

Revert `set_items()` back to the working pattern — `CommandRegistry::new()`, `owner_id: None`, no `drop_owner`. Remove the `component_id` field, the `AtomicU64` static, and all related imports.

The broken injection was:

Restore:

**File:** `crates/term-wm-ui-components/src/command_palette.rs`

`rerank_with_registry()` has two adjacent `// Build display_nodes for rendering` blocks (lines ~439-468 and ~470-501). The first is dead code (was a duplicate from `rerank()` that never ran). Delete the first block.
