# Plan: Command Palette Reorganization

## Goal
Relabel command palette options to be action-oriented (what clicking *does*, not current state) and add visual section separators.

---

## Files to Modify

### 1. `crates/term-wm-core/src/components.rs`
- Add `is_separator: bool` field to `MenuItem<R>` (default `false`)
- Add a helper `MenuItem::separator()` constructor

### 2. `crates/term-wm-ui-components/src/menu.rs`
- `render_items()`: when `item.is_separator`, draw a row of `─` characters across the full width instead of the normal `> icon label` format
- `handle_key_event()` / `update()`: skip separator items during Up/Down navigation
- `handle_events()`: return `EventResult::Consumed` for mouse clicks on separator

### 3. `crates/term-wm-core/src/window/window_manager/mod.rs`
- Add `debug_log_visible: bool` and `system_panel_visible: bool` fields to `WindowManager` struct (initialized `false`)
- Update `wm_menu_items()` with new labeling convention:

| Current | New |
|---------|-----|
| Resume | Resume |
| New Window | New Window |
| Mouse Capture: On/Off | mouse: Disable / mouse: Enable |
| Clipboard Mode: On/Off | clipboard: Disable / clipboard: Enable |
| Window Selection: On/Off | window selection: Disable / window selection: Enable |
| Toggle Debug Log | system debug log: Disable / system debug log: Enable |
| Toggle System Panel | system panel: Disable / system panel: Enable |
| Help | Help |
| Exit UI | Exit UI |
| Monocle Mode: On/Off/Auto | monocle mode: Disable / monocle mode: Enable / monocle mode: Auto |
| Toggle Float/Tile Mode | tiling: Enable / tiling: Disable |

- Insert separator items between groups:
  1. `Separator` → Resume, New Window → `Separator`
  2. mouse, clipboard, window selection, system debug log, system panel → `Separator`
  3. Help, Exit UI → `Separator`
  4. monocle mode, tiling → `Separator`
  5. Close/Maximize/Minimize window, Switch-to items (no trailing separator)

### 4. `src/term_wm_app.rs`
- After calling `toggle_debug_window()`, set `self.wm.debug_log_visible` to reflect new state
- After calling `toggle_system_panel()`, set `self.wm.system_panel_visible` to reflect new state

### 5. Test files
- All 38 `MenuItem { ... }` construction sites: add `is_separator: false`
- Update menu.rs tests for separator navigation skip behavior
- Update any existing tests that check palette item labels

## Details

### Label computation logic in `wm_menu_items()`:

```rust
// mouse
let mouse_label = if self.mouse_capture_enabled {
    "mouse: Disable"
} else {
    "mouse: Enable"
};

// debug log
let debug_label = if self.debug_log_visible {
    "system debug log: Disable"
} else {
    "system debug log: Enable"
};

// monocle (3-state)
let monocle_label = match self.monocle_mode {
    MonocleMode::Auto => "monocle mode: Enable",
    MonocleMode::On   => "monocle mode: Disable",
    MonocleMode::Off  => "monocle mode: Auto",
};
```

### Separator rendering in `menu.rs`

In `render_items()`, when `item.is_separator`:
- Fill the entire row with `─` characters
- Use the `disabled_style` (dimmed)
- No marker, no icon, no label text

### Navigation skipping

In `MenuComponent::update()` for `MenuUp`/`MenuDown`:
- After moving selection, if the new index is a separator, continue moving in the same direction
- Boundary: never skip past the last/first non-separator item (wrap-around skips separators)
