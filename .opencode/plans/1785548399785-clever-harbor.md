## Required Draft Corrections (2)

### Correction 1: Developer code sample (For Developers section)

**Draft's (wrong) sample:**
```rust
use term_wm_core::config::WmConfig;
use term_wm_core::app::TermWmApp;
let config = WmConfig::minimal();
let app = TermWmApp::embedded(config);
```

**Why wrong (verified):**
- `TermWmApp` is in the top-level `term-wm` crate (`src/term_wm_app.rs`), re-exported from `term_wm::prelude` (`src/prelude.rs:3`) — NOT `term_wm_core::app` (no such module).
- `WmConfig` lives in `term_wm_core::wm_config`; `term_wm_core::config` holds `AppBuilder`/`ConfigError` (config.rs:35).
- `TermWmApp::embedded(app_ctx: AppContext)` takes an `AppContext` and hardwires `WmConfig::minimal()` internally (term_wm_app.rs:419, embedded_custom at :160).

**Corrected sample:**
```rust
use term_wm::prelude::{AppContext, TermWmApp};

// Embedded mode boots with the minimal preset (no chrome, no command menu).
let app = TermWmApp::embedded(AppContext::new("myapp", "1.0"));
```

Optionally add: for full control over config, use `AppBuilder` (from `term_wm_core::config`) and hand the built `WindowManager` to `TermWmApp::from_wm`.

### Correction 2: Muxio IPC transport phrase

**Draft says:** "...over Unix sockets". **Actual (verified):** `interprocess::local_socket` `GenericNamespaced` — Linux abstract namespace, macOS `/tmp`, Windows named pipes (`crates/term-session-muxio-service-definitions/src/channel.rs:54-59`).

**Corrected phrasing:** "...over an OS-native IPC transport (Linux abstract sockets, macOS `/tmp`, Windows named pipes)".
