## Detailed Changes

### README.md

1. **Badge line (line 4):** Delete the entire badge line and the 14 link definitions listed in Issue 5.

   ```
   alt="term-wm v0.8.12-alpha on macOS"  →  alt="term-wm running on macOS"
   ```

3. **"No-Conflict" Philosophy section (lines 34–52):** Retitle to drop the `Esc` framing (e.g., "The "No-Conflict" Philosophy (`Ctrl+A` Super Key)"). Replace the section body and delete the behavior table. New content:
   - The default super key is `Ctrl+A` (configurable via `KeyBindings`), bound to `TermWmAction::OpenCommandPalette`.
   - Press `Ctrl+A` to open the Command Palette overlay; pressing it again (or while palette is open) sends the key to the focused window (`SendSuperKeyToFocusedWindow`).
   - While the palette is open: `Tab` / `Shift+Tab` cycle window focus, `Enter` activates the selected item.
   - **Direct mode is automatic** — driven by `DirectInputTracker`, it engages when a child application requests the **alternate screen buffer**, **mouse tracking**, or **custom scroll margins** (e.g., `vim`, `less`). In direct mode all keys pass through unfiltered; `Ctrl+A` still opens the palette.
   - Keep the "Retro-Modern" motivation text intact; only the implementation details are wrong.

4. **Operation Modes (lines 62–65):**
   - `WmConfig::embedded()` → `WmConfig::minimal()`, noting it is the minimal preset (no chrome, no floating windows, no command menu).
   - Add: embedded initialization of the full application is handled via `TermWmApp::embedded()` (and `embedded_custom()` for a custom `AppContext`).

5. **Consistency sweep:** grep the modified README for `Esc`, `[D]`, `embedded()`, `v0.8.12` to confirm no stale references remain.
