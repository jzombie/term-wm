# Plan: Fix Bouncy Scrollbar

## Issue 1 — Bottom row loss on shrink

### Root Cause
vt100 `grid.set_size()` truncates bottom rows. Prior attempts injected both `SU` and `CUU`, but `SU` already decrements `cursor.row` by `delta` — `CUU` was a double decrement causing shell ZLE desync and prompt duplication.

### Fix: SU-only pre-scroll in `Pty::resize()` on shrink

**File:** `crates/term-wm-pty-engine/src/pty.rs` — inject `\x1b[{delta}S` (SU only) before `set_size()` when shrinking and no custom DECSTBM margins active. `SU` scrolls content up, pushes top `delta` rows to scrollback, adds blank rows at bottom, and decrements `cursor.row` by `delta` automatically. `set_size()` truncates the blank rows, preserving bottom content. No `CUU`, no `SD`, no `CUD`. No patching vt100.

```rust
if new_rows < old_rows && !self.tracker.has_custom_margins() {
    let delta = old_rows - new_rows;
    let seq = format!("\x1b[{delta}S");
    guard.process(seq.as_bytes());
}
guard.screen_mut().set_size(new_rows, size.cols);
```

**Expand:** `set_size()` runs directly — `SIGWINCH` delegates positioning to the shell.

**No vt100 patch, no Cargo.toml change, no vendor directory.**

| File | Change |
|------|--------|
| `crates/term-wm-pty-engine/src/pty.rs` | SU-only pre-scroll on shrink, guarded by `has_custom_margins()` |

## Issue 2 — Bouncy Scrollbar (Layout Thrashing)

### Root Cause
`ScrollViewComponent::render()` starts every frame assuming `needs_vertical = false`, forcing pass 1 at width W and pass 2 at W-1 — dual child renders per frame. For reflowing children this creates oscillation.

### Fix: Seed pass-1 from persistent state; passive bounds for OFF-transition; monotonic attempt counter

**File:** `crates/term-wm-core/src/component_context.rs` — Add `last_needs_vertical: bool` and `last_needs_horizontal: bool` to `ScrollBounds`

**File:** `crates/term-wm-ui-components/src/scroll_view.rs` — Two changes:

**Change 1 — `compute_layout` accepts explicit scrollbar state:
```rust
pub(crate) fn compute_layout(&self, area: LayoutRect, needs_vertical: bool, needs_horizontal: bool) -> LayoutRect {
    let mut view_w = area.width;
    let mut view_h = area.height;
    if needs_vertical && view_w > 0 { view_w = view_w.saturating_sub(1); }
    if needs_horizontal && view_h > 0 { view_h = view_h.saturating_sub(1); }
    LayoutRect { x: area.x, y: area.y, width: view_w, height: view_h }
}
```

**Change 2 — Render loop seeds from persistent state; monotonic attempt (no reset):**
```rust
// Before loop:
let mut needs_vertical = {
    let state = self.scroll_state.borrow();
    state.last_needs_vertical
};
let mut needs_horizontal = {
    let state = self.scroll_state.borrow();
    state.last_needs_horizontal
};

// Inside loop, after child render:
if needs_vertical {
    // OFF-transition: only when content at W-1 fits strictly
    if content_h <= inner_area.height as usize {
        needs_vertical = false;
        attempt += 1;
        if attempt < MAX_ATTEMPTS { continue; }
    }
} else {
    if inner_area.height > 0 && content_h > inner_area.height as usize {
        needs_vertical = true;
        attempt += 1;
        if attempt < MAX_ATTEMPTS { continue; }
    }
}

// After loop, before scrollbar paint:
{
    let mut state = self.scroll_state.borrow_mut();
    state.last_needs_vertical = needs_vertical;
    state.last_needs_horizontal = needs_horizontal;
}
```

Also update `on_mouse`'s `compute_layout(sa)` call to pass `last_needs_vertical/horizontal`.

**Monotonic attempt counter** (no `attempt = 0` reset): prevents infinite loop on oscillating content. MAX_ATTEMPTS (3) bounds the retry budget.

**No speculative probes, no scratch buffers, no SIGWINCH flooding.**

fn shrink_grid_preserves_bottom_rows() {
    let mut parser = vt100::Parser::new(30, 80, 200);
    for i in 0..30 {
        parser.process(format!("line {i}\r\n").as_bytes());

#[test]
fn shrink_then_expand_no_duplication() {
    let mut term = TerminalComponent::from_pane(Box::new(TestPane::new(200)));
    let area30 = LayoutRect { x: 0, y: 0, width: 80, height: 30 };
    let area24 = LayoutRect { x: 0, y: 0, width: 80, height: 24 };
    let (handle, _shared) = make_handle();
    let ctx30 = ComponentContext::new(true).with_viewport(
        ScrollViewport { offset_x:0, offset_y:0, width:80, height:30 }, Some(handle.clone()));
    let ctx24 = ComponentContext::new(true).with_viewport(
        ScrollViewport { offset_x:0, offset_y:0, width:80, height:24 }, Some(handle));

    let mut p = term.pane.borrow_mut();
    for i in 0..30 { p.write_bytes(format!("line {i}\r\n").as_bytes()).ok(); }
    p.write_bytes(b"MARKER").ok(); drop(p);

    let mut render = |area: LayoutRect, ctx: &ComponentContext| {
        let rect = layout_rect_to_clipped_rect(area);
        let mut buf = Buffer::empty(rect);
        let mut bk = RatatuiBackend::new_simple(buf, rect);
        let mut reg = HitboxRegistry::new(area);
        term.render(&mut bk, area, ctx, &mut reg);
    };
    render(area30, &ctx30);
    render(area24, &ctx24);
    render(area30, &ctx30);

    let count = term.pane_mut().shared_parser().lock().unwrap()
        .screen().contents().matches("MARKER").count();
    assert!(count < 2);
}
```

#[test]
fn scrollbar_off_transition_when_content_fits() {
    let mut sv = ScrollViewComponent::new(term_wm_core::window::test_component::ActionRecorder::default());
    let area = LayoutRect { x: 0, y: 0, width: 80, height: 10 };

    // Seed state: scrollbar ON, content fits within W-1
    sv.scroll_state.borrow_mut().last_needs_vertical = true;
    sv.scroll_state.borrow_mut().content_width = 80;
    sv.scroll_state.borrow_mut().content_height = 9;  // <= 10

    // Simulate a render pass by calling compute_layout then updating state
    // as the render loop would
    let needs_v = sv.scroll_state.borrow().last_needs_vertical;
    let inner = sv.compute_layout(area, needs_v, false);
    // inner area is 79x10 (gutter reserved for vertical scrollbar)
    assert_eq!(inner.width, 79);
    assert_eq!(inner.height, 10);

    // The render loop would check: content_h (9) <= inner_area.height (10) -> true -> flip to false
    // Manually apply the same logic the loop uses:
    if needs_v && sv.scroll_state.borrow().content_height <= inner_area.height as usize {
        sv.scroll_state.borrow_mut().last_needs_vertical = false;
    }

    assert!(!sv.scroll_state.borrow().last_needs_vertical,
        "scrollbar must transition OFF when content fits at W-1");
}
```
