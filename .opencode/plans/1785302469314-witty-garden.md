# Plan: Fix Bouncy Scrollbar

## Issue 1 — Bottom row loss on shrink (accepted limitation)

### Root Cause
vt100 `grid.set_size()` calls `self.rows.resize(new_rows, ...)` which truncates bottom N rows of the viewport without pushing them into scrollback.

### Decision: No fix possible without patching vt100

Three approaches were evaluated:
| Approach | Result |
|----------|--------|
| Pure `set_size()` | Data loss on shrink (vt100 truncates bottom rows) |
| SU injection via `guard.process()` | Shell ZLE desync → prompt duplication |
| Memory-level grid patch in vt100 | Works cleanly but requires `[patch.crates-io]` |

Patcing vt100 is rejected. SU injection causes shell desync. **Approach A (pure `set_size()`) is the only valid path.** The bottom-row loss on shrink is a known limitation of vt100 0.16.2.

**Pty::resize():** remains pure `set_size()` + `master.resize()` — no sequence injection.

### Files Changed (Issue 1)

None.

## Issue 2 — Bouncy Scrollbar (Layout Thrashing)

### Root Cause
`ScrollViewComponent::render()` starts every frame assuming `needs_vertical = false`, forcing pass 1 at width W and pass 2 at W-1 — dual child renders per frame. For reflowing children this creates oscillation.

### Fix: Seed pass-1 from persistent state; passive bounds for OFF-transition; monotonic attempt counter

**File:** `crates/term-wm-core/src/component_context.rs` — Add `last_needs_vertical: bool` and `last_needs_horizontal: bool` to `ScrollBounds`

**File:** `crates/term-wm-ui-components/src/scroll_view.rs` — Two changes:

**Change 1 — `compute_layout` accepts explicit scrollbar state:
```rust
pub(crate) fn compute_layout(&self, area: LayoutRect, needs_vertical: bool, needs_horizontal: bool) -> LayoutRect {
    let mut view_w = area.width;
    let mut view_h = area.height;
    if needs_vertical && view_w > 0 { view_w = view_w.saturating_sub(1); }
    if needs_horizontal && view_h > 0 { view_h = view_h.saturating_sub(1); }
    LayoutRect { x: area.x, y: area.y, width: view_w, height: view_h }
}
```

**Change 2 — Render loop seeds from persistent state; monotonic attempt (no reset):**
```rust
// Before loop:
let mut needs_vertical = {
    let state = self.scroll_state.borrow();
    state.last_needs_vertical
};
let mut needs_horizontal = {
    let state = self.scroll_state.borrow();
    state.last_needs_horizontal
};

// Inside loop, after child render:
if needs_vertical {
    // OFF-transition: only when content at W-1 fits strictly
    if content_h <= inner_area.height as usize {
        needs_vertical = false;
        attempt += 1;
        if attempt < MAX_ATTEMPTS { continue; }
    }
} else {
    if inner_area.height > 0 && content_h > inner_area.height as usize {
        needs_vertical = true;
        attempt += 1;
        if attempt < MAX_ATTEMPTS { continue; }
    }
}

// After loop, before scrollbar paint:
{
    let mut state = self.scroll_state.borrow_mut();
    state.last_needs_vertical = needs_vertical;
    state.last_needs_horizontal = needs_horizontal;
}
```

Also update `on_mouse`'s `compute_layout(sa)` call to pass `last_needs_vertical/horizontal`.

**Monotonic attempt counter** (no `attempt = 0` reset): prevents infinite loop on oscillating content. MAX_ATTEMPTS (3) bounds the retry budget.

**No speculative probes, no scratch buffers, no SIGWINCH flooding.**

| File | Change |

| `crates/term-wm-ui-components/src/scroll_view.rs` | Seed pass-1 from persistent state; passive OFF-transition; `compute_layout` signature change |

#### Test 1 — `vt100_set_size_truncates_bottom_rows` (documents current behavior)

Add to `crates/term-wm-pty-engine/src/pty.rs` test module — verifies the known limitation of vt100 0.16.2:

```rust
#[test]
fn vt100_set_size_truncates_bottom_rows() {
    // Non-zero scrollback capacity (200) proves the limitation:
    // vt100 truncates viewport rows instead of pushing them into scrollback.
    let mut parser = vt100::Parser::new(30, 80, 200);

    for i in 0..30 {
        parser.process(format!("line {i}\r\n").as_bytes());
    }
    parser.process(b"BOTTOMLINE");

    // Shrink viewport from 30 to 24
    parser.screen_mut().set_size(24, 80);

    // vt100 truncates from end — bottom content is LOST
    let visible = parser.screen().contents();
    assert!(!visible.contains("BOTTOMLINE"),
        "vt100 0.16.2 drops bottom rows on shrink (known limitation)");
    assert_eq!(parser.screen().size(), (24, 80),
        "viewport is 24 rows after shrink");
}
```

#### Test 2 — `shrink_then_expand_no_duplication`

Add to `crates/term-wm-ui-components/src/terminal.rs` test module:

```rust
#[test]
fn shrink_then_expand_no_duplication() {
    let mut term = TerminalComponent::from_pane(Box::new(TestPane::new(200)));
    let area30 = LayoutRect { x: 0, y: 0, width: 80, height: 30 };
    let area24 = LayoutRect { x: 0, y: 0, width: 80, height: 24 };
    let (handle, _shared) = make_handle();
    let ctx30 = crate::components::ComponentContext::new(true).with_viewport(
        term_wm_core::component_context::ScrollViewport {
            offset_x: 0, offset_y: 0, width: 80, height: 30
        }, Some(handle.clone()));
    let ctx24 = crate::components::ComponentContext::new(true).with_viewport(
        term_wm_core::component_context::ScrollViewport {
            offset_x: 0, offset_y: 0, width: 80, height: 24
        }, Some(handle.clone()));

    let mut pane = term.pane.borrow_mut();
    for i in 0..30 { pane.write_bytes(format!("line {i}\r\n").as_bytes()).ok(); }
    pane.write_bytes(b"DUPLICHECK").ok();
    drop(pane);

    let mut render_fn = |area: LayoutRect, ctx: &crate::components::ComponentContext| {
        let rect = crate::helpers::layout_rect_to_clipped_rect(area);
        let mut buffer = ratatui::buffer::Buffer::empty(rect);
        let mut backend = term_wm_console::RatatuiBackend::new_simple(buffer, rect);
        let mut registry = term_wm_core::hitbox_registry::HitboxRegistry::new(area);
        term.render(&mut backend, area, ctx, &mut registry);
    };
    render_fn(area30, &ctx30);
    render_fn(area24, &ctx24);
    render_fn(area30, &ctx30);

    let pane = term.pane.borrow();
    let parser = pane.shared_parser().lock().unwrap();
    let count = parser.screen().contents().matches("DUPLICHECK").count();
    // With pure set_size (no SU injection): marker may be lost (count=0)
    // but must NOT be duplicated (count >= 2)
    assert!(count < 2,
        "marker must not be duplicated (got {count} occurrences, expected 0 or 1)");
}
```

```rust
#[test]
fn scrollbar_persistent_state_tracks_overflow() {
    let sv = ScrollViewComponent::new(SimpleComponent::new(80, 11));
    let area = LayoutRect { x: 0, y: 0, width: 80, height: 10 };

    // Initially false
    assert!(!sv.scroll_state.borrow().last_needs_vertical);

    // compute_layout with needs_vertical=false gives full width 80
    let inner = sv.compute_layout(area, false, false);
    assert_eq!(inner.width, 80);

    // compute_layout with needs_vertical=true reserves gutter -> width 79
    let inner = sv.compute_layout(area, true, false);
    assert_eq!(inner.width, 79);
}
```
