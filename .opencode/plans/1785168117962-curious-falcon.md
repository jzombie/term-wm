# Plan: Make command palette icons searchable

## Goal

When typing in the command palette search, fuzzy match against the menu item's icon text in addition to the display name. This lets users find a command by typing its icon character (e.g., `*` for "Toggle System Panel").

## Changes

### 1. `crates/term-wm-core/src/command_menu/matcher.rs` — Expand tuple to include icon

The `FuzzyMatch::score` method takes `&[(String, String, bool)]` — currently `(name, description, disabled)`. The description and icon are unused in scoring.

Extend to a 4-tuple `(name, icon_text, description, disabled)` and build the haystack from `name` concatenated with `icon_text` so both are searchable.

```rust
pub fn score(&mut self, query: &str, items: &[(String, String, String, bool)]) -> Vec<usize> {
    if query.is_empty() {
        return (0..items.len()).collect();
    }
    self.matcher = Matcher::new(NucleoConfig::DEFAULT.match_paths());
    let pattern = Pattern::new(query, CaseMatching::Ignore, Normalization::Smart, AtomKind::Fuzzy);
    let mut scored: Vec<(u32, usize)> = items
        .iter()
        .enumerate()
        .filter_map(|(i, (name, icon_text, _desc, _disabled))| {
            self.char_buf.clear();
            // Build haystack from display name + icon for broader matching
            let haystack = if icon_text.is_empty() {
                Utf32Str::new(name, &mut self.char_buf)
            } else {
                let combined = format!("{} {}", icon_text, name);
                Utf32Str::new(&combined, &mut self.char_buf)
            };
            let score = pattern.score(haystack, &mut self.matcher);
            score.map(|s| (s, i))
        })
        .collect();
    scored.sort_by_key(|&(score, _)| std::cmp::Reverse(score));
    scored.into_iter().map(|(_, i)| i).collect()
}
```

### 2. `crates/term-wm-ui-components/src/command_palette.rs` — Include icon in display_items tuple

In `rebuild_data_cache`, add the node's icon text to the tuple (flatten `Option<&str>` to `String`):

```rust
self.display_items = self
    .active_ids
    .iter()
    .filter_map(|id| {
        let node = registry.get(*id)?;
        let display_name = node.name.format(self.current_context_mask);
        let desc = node.description.clone().unwrap_or_default();
        let icon_text = node.icon.unwrap_or("").to_string();
        Some((display_name, icon_text, desc, node.disabled))
    })
    .collect();
```

Update the destructuring in `rerank` (line 124) and `rerank_with_registry` (line 208) to match the 4-tuple:
- Line 124: `let (display_name, description, is_disabled)` → `let (display_name, _icon_text, description, is_disabled)`
- Line 208: `let (ref display_name, ref desc, _disabled)` → `let (ref display_name, _ref _icon_text, ref desc, _disabled)`

### 3. Update the `display_items` field type (`command_palette.rs` line 44)

Change `Vec<(String, String, bool)>` to `Vec<(String, String, String, bool)>`.
