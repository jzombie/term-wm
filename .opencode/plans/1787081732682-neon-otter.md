# Plan: Title-case all `TermWmAction` Display strings

## Goal

Make the `TermWmAction` `Display` impl use uniform Chicago title-casing so every
action name matches the title-case labels already used by the Command Palette and
the approved documentation. Minor words (`to`, `and`, `of`, `in`, `or`, `a`, `an`,
`the`) stay lowercase unless at the start/end of the string; `SUPER` stays uppercase
(it is the key name). This also fixes the workspace-action mismatch flagged earlier
(`New workspace` → `New Workspace`, `Detach viewer` → `Detach Viewer`,
`Switch to workspace: {name}` → `Switch to Workspace: {name}`).

The `Display` strings are user-visible: `wm_bottom_panel.rs:232` renders them in the
shortcut-hint bar (`format!(" {action}")`).

### 3. New style guide: `docs/UI-STYLE.md`

Create a user-facing UI string style guide so the title-case convention is codified
and reusable (this is the convention the `actions.rs` change implements). Structure:

```markdown
# UI Style Guide — User-Facing Strings

Scope: user-facing text in term-wm — action names, Command Palette labels, menu
labels, notifications, help text, terminology. Code conventions (naming, files)
live in AGENTS.md; this file covers *strings users see*.

## Title-Casing Rule

All user-facing action/command names use Chicago title-case:
- Capitalize the first and last word and every major word (nouns, verbs, adjectives, adverbs).
- Keep minor words lowercase unless first or last: `a`, `an`, `and`, `at`, `by`,
  `for`, `in`, `of`, `on`, `or`, `the`, `to`.
- Examples: `New Workspace`, `Switch to Workspace: <name>`, `Detach Viewer`,
  `Scroll to Top`, `Menu Up`, `Toggle Mouse Capture`, `Begin Tap-to-Swap`.

## Exceptions

- Key names and acronyms stay uppercase: `SUPER` (the Super Key), `UI`, `OSC 52`,
  `SGR`, `SSH`, `IPC`.
- Established feature names are treated as proper nouns and keep their canonical
  spelling: `Command Palette`, `Debug Log`, `System Panel`, `Direct Input Mode`,
  `Monocle`, `Terminal`, `Workspace`, `Viewer`, `Gateway`.
- Message/notification bodies and description text use sentence case (only the
  first word capitalized) — title-case applies to *names/labels*, not prose.

## Canonical Action Names

`TermWmAction::Display` (`crates/term-wm-core/src/actions.rs`) is the canonical
machine-rendered form of every action name. It MUST match the Command Palette
labels; the palette is the source of truth for user-visible naming. If a label
changes, update both the palette entry and the `Display` string together.

## Stable Terminology

- **workspace** — a named channel namespace; maps to the daemon channel `<workspace>/main`.
- **channel** — a daemon-hosted session endpoint (`<workspace>/main`).
- **gateway / gateway daemon** — the background session daemon; endpoint `term-wm/<env>/<user>/gateway`.
- **viewer** — a connected client of a channel (the local TUI or a term-session client).
- **detach** — disconnect a viewer from a session without terminating its processes.

## Environment Variables & Flags

- Environment variables are always uppercase `TERM_WM_*` (`TERM_WM_ENV`,
  `TERM_WM_GATEWAY`, …).
- CLI flags are lowercase kebab-case (`--no-session-persistence`, `--list-channels`).
```
