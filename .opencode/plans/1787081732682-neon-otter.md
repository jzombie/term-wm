# Plan: Title-case all `TermWmAction` Display strings

## Goal

Make the `TermWmAction` `Display` impl use uniform Chicago title-casing so every
action name matches the title-case labels already used by the Command Palette and
the approved documentation. Minor words (`to`, `and`, `of`, `in`, `or`, `a`, `an`,
`the`) stay lowercase unless at the start/end of the string; `SUPER` stays uppercase
(it is the key name). This also fixes the workspace-action mismatch flagged earlier
(`New workspace` → `New Workspace`, `Detach viewer` → `Detach Viewer`,
`Switch to workspace: {name}` → `Switch to Workspace: {name}`).

The `Display` strings are user-visible: `wm_bottom_panel.rs:232` renders them in the
shortcut-hint bar (`format!(" {action}")`).
