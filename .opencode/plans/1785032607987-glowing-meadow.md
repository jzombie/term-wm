# Plan: Encapsulate Window struct fields behind getters/setters

## Goal
Make all `Window` struct fields private and provide getter/setter methods, matching the existing pattern of `is_maximized`/`set_maximized`.

## Files to modify
1. `crates/term-wm-core/src/window/entry.rs` — Make fields private, add getters/setters
2. `crates/term-wm-core/src/window/window_manager/mod.rs` — Update direct field accesses
3. `crates/term-wm-core/src/window/window_manager/layout.rs` — Update direct field accesses
4. `crates/term-wm-core/src/window/window_manager/chrome.rs` — Update direct field accesses
5. `crates/term-wm-core/src/window/window_manager/focus.rs` — Update direct field accesses (already uses methods for is_maximized)

## Step 1: Add getters/setters to `Window` in `entry.rs`

For each field, add a getter and (where mutable access is needed) a setter, then remove `pub`:

| Field | Getter | Setter | Notes |
|-------|--------|--------|-------|
| `title: Option<String>` | `pub fn title(&self) -> &Option<String>` | `pub fn set_title(&mut self, title: Option<String>)` | |
| `title_set_order: Option<usize>` | `pub fn title_set_order(&self) -> Option<usize>` | `pub fn set_title_set_order(&mut self, order: Option<usize>)` | Return copy for Copy types |
| `state: WindowState` | `pub fn state(&self) -> WindowState` | `pub fn set_state(&mut self, state: WindowState)` | |
| `floating_rect: Option<FloatRectSpec>` | `pub fn floating_rect(&self) -> Option<&FloatRectSpec>` | `pub fn set_floating_rect(&mut self, rect: Option<FloatRectSpec>)` | Return ref for non-Copy type; add `floating_rect_mut()` if needed |
| `prev_floating_rect: Option<FloatRectSpec>` | `pub fn prev_floating_rect(&self) -> Option<&FloatRectSpec>` | `pub fn set_prev_floating_rect(&mut self, rect: Option<FloatRectSpec>)` + `pub fn take_prev_floating_rect(&mut self) -> Option<FloatRectSpec>` | |
| `creation_order: usize` | `pub fn creation_order(&self) -> usize` | *(none — set only in constructor)* | |
| `direct_mode: bool` | `pub fn direct_mode(&self) -> bool` | `pub fn set_direct_mode(&mut self, value: bool)` | |
| `void_id: Option<usize>` | `pub fn void_id(&self) -> Option<usize>` | `pub fn set_void_id(&mut self, id: Option<usize>)` | |
| `component_key: ComponentKey` | `pub fn component_key(&self) -> ComponentKey` | *(none — set only in constructor)* | Return copy since `ComponentKey: Copy` |
| `close_policy: ClosePolicy` | `pub fn close_policy(&self) -> ClosePolicy` | `pub fn set_close_policy(&mut self, policy: ClosePolicy)` | |
| `content_hitbox_id: HitboxId` | `pub fn content_hitbox_id(&self) -> HitboxId` | *(none — set only in constructor)* | |
| `active_keyboard_focus: Option<HitboxId>` | `pub fn active_keyboard_focus(&self) -> Option<HitboxId>` | `pub fn set_active_keyboard_focus(&mut self, id: Option<HitboxId>)` | |
