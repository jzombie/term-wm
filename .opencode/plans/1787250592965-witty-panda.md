# Plan: Refresh Command Palette on State Changes

## Problem

The Command Palette snapshots `all_users_by_ws`, `cached_workspaces`, and WM state at open time. User connect/disconnect and workspace changes while the palette is open leave it stale.

## Approach

### Step 1: Add `refresh_palette_items()` to `WindowManager` and refactor `focus.rs`

**File:** `crates/term-wm-core/src/window/window_manager/mod.rs`

Add `refresh_palette_items()` — rebuilds palette items from current WM state and applies to the overlay. Same borrow-split pattern as `focus_window_key()`.

**File:** `crates/term-wm-core/src/window/window_manager/focus.rs`

Refactor `focus_window_key()` to delegate to `self.refresh_palette_items()` instead of inlining 35 lines of duplicate palette rebuild/filter logic.

### Step 2: Add `on_user_registry_changed()` to `WindowManagerHost`

**File:** `crates/term-wm-core/src/runner.rs`

Add default no-op method to trait. Call `app.on_user_registry_changed()` after all user connect/disconnect/cache-refreshed blocks (~line 494), using a `user_changed` flag to batch the three event drains.

### Step 3: Implement on `TermWmApp<C>` with feature gates + visibility check

**File:** `src/term_wm_app.rs`

```rust
fn on_user_registry_changed(&mut self) {
    if !self.wm.command_menu_visible() { return; }
    #[cfg(feature = "session-persistence")]
    {
        self.refresh_workspace_cache();
        self.wm.cached_workspaces = self.cached_workspaces.clone();
        self.wm.current_workspace = self.current_workspace.clone();
        self.wm.all_users_by_ws = self.all_users_by_ws.clone();
    }
    self.wm.refresh_palette_items();
}
```

### Step 4: Implement on `TermWmAppMain` (delegates to inner)

**File:** `src/main.rs`

```rust
fn on_user_registry_changed(&mut self) {
    self.inner.on_user_registry_changed();
}
```

### Step 5: Feature-gate workspace cache sync in `handle_custom_action`

**File:** `src/main.rs`

Wrap the workspace cache refresh + palette refresh in `SwitchWorkspace` and `NewWorkspace` handlers with `#[cfg(feature = "session-persistence")]`.
