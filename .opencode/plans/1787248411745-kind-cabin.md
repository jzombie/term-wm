# Plan: Enhanced SSH Connection Discrimination & User Info Display

## Goal
1. Distinguish same user connected from different devices (via SSH source port, terminal size, uptime)
2. Show active terminal size and connection uptime in the command palette

## Display Format
Compact single-line format:
```
    └ alice@host-a (192.168.1.50:54321) 80x24 5m
    └ bob@laptop 200x60 42s
    └ charlie@server (10.0.0.1:22) 120x40 1d 3h
```
- SSH address shows `ip:port` (port distinguishes same-IP connections)
- Terminal size and uptime appended compactly
- Local (non-SSH) connections omit the `(ip:port)` group
