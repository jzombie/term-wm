# Fix: Exclude Section Headers from Search Results

## Root Cause

Section headers (`disabled + starts_with('─')`) are included as matchable items in `filtered_items` during active search. The fuzzy matcher scores them alongside regular commands, causing headers to appear at arbitrary positions — often below their child items.

## Fix

### `command_palette.rs` — Filter headers/disabled from search pipeline with correct index mapping

Use a `search_map` that pairs each `cache_idx` with its search tuple, so `fmatch.score()` indices map directly back to `display_cache` entries.

Apply the same pattern to both `rerank()` and `rerank_with_registry()`.

#### In `rerank()`:

Replace the `searchable` builder and `filtered_items` assignment with:

```rust
let is_searching = !self.query.is_empty();

self.filtered_items = if is_searching {
    let mut search_map: Vec<(usize, (String, String, String, bool))> = Vec::new();
    for &cache_idx in &item_indices {
        if let Some(DisplayCacheEntry::Item {
            display_name,
            description,
            searchable_text,
            disabled,
            ..
        }) = self.display_cache.get(cache_idx)
        {
            if !*disabled {
                search_map.push((
                    cache_idx,
                    (
                        display_name.clone(),
                        description.clone(),
                        searchable_text.clone(),
                        *disabled,
                    ),
                ));
            }
        }
    }

    let searchable: Vec<_> = search_map.iter().map(|(_, item)| item.clone()).collect();
    let matches = fmatch.score(&self.query, &searchable);
    matches
        .iter()
        .filter_map(|&matched_idx| {
            let (cache_idx, _) = search_map.get(matched_idx)?;
            resolve_item(*cache_idx)
        })
        .collect()
} else {
    item_indices
        .iter()
        .filter_map(|&i| resolve_item(i))
        .collect()
};
```

#### Selection clamping — preserve current position, only fix invalid state:

```rust
if self.filtered_items.is_empty() {
    self.selected = 0;
} else {
    self.selected = self.selected.min(self.filtered_items.len() - 1);
    // Only move cursor if current selection is disabled
    if self.skip_disabled_items && self.filtered_items[self.selected].disabled {
        if let Some(valid_idx) = self.filtered_items.iter().position(|item| !item.disabled) {
            self.selected = valid_idx;
        } else {
            self.selected = 0;
        }
    }
}
```

#### Apply identical `search_map` pattern to `rerank_with_registry()`.
