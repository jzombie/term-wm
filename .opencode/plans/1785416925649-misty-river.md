# Plan: Fix bottom panel key binding highlighting lost on truncation

## Problem
In `crates/term-wm-sys-ui-components/src/wm_bottom_panel.rs`, lines 187-200, when the first keybinding hint entry is wider than the available space, the entire entry is truncated as a plain string via `truncate_to_width` and rendered with the normal panel `style` — losing the green-highlighted key combo styling (`combo_style`). The combo portion of the text should retain its highlighting even when truncated.

## Root Cause
The forced truncation path (line 187: `cursor_x == bounds.x && entry_width > available_w`) treats the entry as a monolithic string and applies a single uniform style, discarding the per-segment combo vs description styling that the non-truncated path uses (lines 212-223).

## Fix
Replace the monolithic truncation (lines 186-200) with a two-segment approach:

1. **Combo portion**: Truncate `combo_str` to fit within `available_w`, render with `combo_style`.
2. **Description portion**: If any space remains after the combo, truncate `" {action}"` to fit and render with `style`.

This preserves the highlighting on the key combo even when the overall entry is truncated.

**Important**: Use `unicode_width::UnicodeWidthStr::width()` for terminal column calculations, not `.chars().count()`, to correctly handle multi-width Unicode glyphs.

### Add dependency
Add `unicode-width` to `crates/term-wm-sys-ui-components/Cargo.toml`:
```toml
unicode-width = { workspace = true }
```

### Add import
Add to imports in `wm_bottom_panel.rs`:
```rust
use unicode_width::UnicodeWidthStr;
```

### Replace the truncation block
**Remove** (lines 186-200):
```rust
                let available_w = max_hint_x.saturating_sub(cursor_x);
                if cursor_x == bounds.x && entry_width > available_w {
                    let text = truncate_to_width(&entry, available_w as usize);
                    safe_set_string(buffer, bounds, cursor_x, area.y as u16, &text, style);
                    self.hint_rects.push((
                        LayoutRect {
                            x: i32::from(cursor_x),
                            y: area.y,
                            width: available_w,
                            height: 1,
                        },
                        action.clone(),
                    ));
                    break;
                }
```

**Replace with**:
```rust
                let available_w = max_hint_x.saturating_sub(cursor_x);
                if cursor_x == bounds.x && entry_width > available_w {
                    let truncated_combo = truncate_to_width(&combo_str, available_w as usize);
                    let combo_cols = UnicodeWidthStr::width(truncated_combo.as_str()) as u16;
                    safe_set_string(buffer, bounds, cursor_x, area.y as u16, &truncated_combo, combo_style);

                    let desc_available = available_w.saturating_sub(combo_cols);
                    if desc_available > 0 {
                        let desc = format!(" {action}");
                        let truncated_desc = truncate_to_width(&desc, desc_available as usize);
                        let desc_cursor = cursor_x.saturating_add(combo_cols);
                        safe_set_string(buffer, bounds, desc_cursor, area.y as u16, &truncated_desc, style);
                    }

                    self.hint_rects.push((
                        LayoutRect {
                            x: i32::from(cursor_x),
                            y: area.y,
                            width: available_w,
                            height: 1,
                        },
                        action.clone(),
                    ));
                    break;
                }
```
