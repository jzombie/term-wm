# Plan: Progressive degradation for bottom panel key binding hints

## Problem
The bottom panel currently has two issues when space is tight:
1. **Combo truncation**: When the first entry doesn't fit, the combo string (e.g., `Ctrl+Shift+N`) is truncated, making the hint unreadable.
2. **No space management**: The panel doesn't reclaim space from decorative elements (info section) before sacrificing functional content.

## Design: 4-Level Progressive Degradation

```
[Level 0: Full]    Ctrl+N New Window  Alt+Tab Switch    term-wm 0.1.0 · macos · mbp
[Level 1: No Info] Ctrl+N New Window  Alt+Tab Switch    ▲
[Level 2: Compact] Ctrl+N New  Alt+Tab Switch  F1 Help  └ ~40 cols reclaimed
[Level 3: Combo]   Ctrl+N  Alt+Tab  F1  Ctrl+W          └ combos atomic, desc truncated
                                                          └ combos only, low-prio dropped
```

- **Level 0 → 1**: Reclaim info section (~40 cols) when first combo doesn't fit
- **Level 1 → 2**: Descriptions truncated to fit, combos always fully visible
- **Level 2 → 3**: In worst case, drop descriptions entirely (combo-only mode)

## Implementation

### File: `crates/term-wm-sys-ui-components/src/wm_bottom_panel.rs`

#### 1. Unify hint rendering loop (replace lines ~175-247)

**Before**: Two code paths — one for first-entry truncation (loses highlighting), one for normal entries.

**After**: Single unified loop where:
- Combo is **atomic** (never truncated)
- Description fills remaining space (truncated if needed, omitted if no room)
- Separator "|" between entries (omitted if no room)

```rust
            let mut cursor_x = bounds.x;
            self.hint_rects.clear();
            for (action, combos) in &self.keybinding_hints {
                if cursor_x >= max_hint_x {
                    break;
                }

                let combo_str = combos.join("/");
                let combo_cols = UnicodeWidthStr::width(combo_str.as_str()) as u16;
                let min_entry_w = combo_cols + 1;

                // Combo atomic: skip entry if combo itself doesn't fit
                if cursor_x.saturating_add(min_entry_w) > max_hint_x {
                    break;
                }

                let entry_start = cursor_x;

                // Render combo highlighted
                safe_set_string(
                    buffer, bounds, cursor_x, area.y as u16, &combo_str, combo_style,
                );
                cursor_x = cursor_x.saturating_add(combo_cols);

                // Render description if room
                let remaining = max_hint_x.saturating_sub(cursor_x);
                if remaining > 0 {
                    let desc = format!(" {action}");
                    let desc_cols = UnicodeWidthStr::width(desc.as_str()) as u16;
                    let display_desc = if desc_cols <= remaining {
                        desc
                    } else {
                        truncate_to_width(&desc, remaining as usize)
                    };
                    safe_set_string(
                        buffer, bounds, cursor_x, area.y as u16, &display_desc, style,
                    );
                    cursor_x = cursor_x.saturating_add(
                        UnicodeWidthStr::width(display_desc.as_str()) as u16
                    );
                }

                // Separator
                if cursor_x.saturating_add(1) <= max_hint_x {
                    safe_set_string(buffer, bounds, cursor_x, area.y as u16, "|", Style::default());
                    cursor_x = cursor_x.saturating_add(1);
                }

                self.hint_rects.push((
                    LayoutRect {
                        x: i32::from(entry_start),
                        y: area.y,
                        width: cursor_x.saturating_sub(entry_start),
                        height: 1,
                    },
                    action.clone(),
                ));
            }
```

#### 2. Level 1: Suppress info section when hints need space

```rust
        // Level 0→1 degradation: if first combo doesn't fit with info, suppress info section
        let actual_info_width = if show_info && info_width > 0 {

                let first_combo_str = combos.join("/");
                let first_combo_w = UnicodeWidthStr::width(first_combo_str.as_str()) as u16;
                let first_entry_min_w = first_combo_w.saturating_add(1);
                let hint_area_w = bounds
                    .width
                    .saturating_sub(right_margin);

            bounds.x.saturating_add(bounds.width).saturating_sub(right_margin)
        } else {
            bounds.x.saturating_add(bounds.width)
        };
```
