## Findings by Risk

### HIGH — `CloseSession` handler does not wake polling loop

**Location:** `session_server.rs:168`

`guard.session = None` is set without calling `guard.notify.notify_one()`. The polling loop parks on `notify.notified().await` and never wakes when session is removed, causing:
- `session_child_exit` integration test fails (no final stream marker sent)
- `session_osc52_via_osc52extractor` likely fails due to timing (output buffered but never flushed)

**Fix needed:** Add `clear_session()` method on `ServerState` that calls `notify.notify_one()` after clearing the session. Update polling loop to send final stream markers when `session == None`.

### MEDIUM — `RemotePane::new()` public API + test gate

**Location:** `remote_pane.rs:26`

`RemotePane::new()` currently takes `Arc<RpcIpcClient>` and wraps it in `Some()` internally. The test constructs the struct directly via field access (bypassing `new`) and is gated `#[cfg(unix)]`.

**Fix:** Change the public API of `new()` to accept `Option<Arc<RpcIpcClient>>`. Production callers pass `Some(client)`; the test passes `None`. This makes the test fully cross-platform — no platform gates needed.

### MEDIUM — `prev_parser` resize test

**Location:** `lib.rs` test module

`test_prev_parser_resize_sync_matches_fresh_parser` validates that `set_size + RIS + process` on a reused parser matches a fresh allocation. This test is cross-platform and passes.

### LOW — Unused `Duration` import removed

`std::time::Duration` was unused in `session_server.rs` after removing the interval timer. Clean.

### 2. Add `clear_session()` to `ServerState`

Encapsulate session teardown in `ServerState` so `notify.notify_one()` is always
fired when the session is removed — regardless of which code path does it.

```rust
impl ServerState {
    /// Terminate and clear the active session, waking the polling task
    /// to flush final stream markers to subscribers.
    fn clear_session(&mut self) {
        if let Some(session) = self.session.as_mut() {
            let _ = session.pty.kill_child();
        }
        self.session = None;
        self.notify.notify_one();
    }
}
```

### 2. Update CloseSession handler

Replace the inline `kill_child + session = None` with `clear_session()`:

```rust
// In CloseSession handler (session_server.rs):
let mut guard = state.lock().await;
guard.clear_session();
CloseSession::encode_response(())
    .map_err(|e| Box::new(e) as Box<dyn std::error::Error + Send + Sync>)
```

### 3. Update polling loop session-None path

When the polling loop wakes to find `session == None`, it must send final
stream markers to all subscribers before breaking:

```rust
let Some(session) = guard.session.as_mut() else {
    for sub in &guard.subscribers {
        sub.respond.respond(Vec::new(), true);
    }
    guard.subscribers.clear();
    let _ = exit_tx.send(0);
    break;
};
```
