# Fix: Monocle Mode Border Visibility from Floating State

## Bug

When entering monocle mode from "all floating" mode, window borders still show. Doesn't happen when entering from tiled.

## Root Cause

`window_mode()` in `layout.rs:216-226` checks `is_floating()` **before** `is_monocle()`. `WindowManager`'s `is_monocle()` (global layout mode) and `Window`'s `is_floating()` (local window state) are orthogonal states that can both be true. The `if/else if` chain is the sole arbiter of which `WindowMode` wins. Currently `Floating` beats `Monocle`, so the `ModeChromeConfig.monocle` rules (already correctly set to `show_borders: false` in `entry.rs`) are never reached for floating windows.

Existing test at line 1107-1114 explicitly asserts the old precedence.

## Fix

### 1. Formalize precedence hierarchy as domain contract (layout.rs:~206)

Update the doc comment on `window_mode()` to explicitly declare the operational hierarchy:

```
Maximized > Monocle > Floating > Tiled
```

- **Maximized**: Local window override — user explicitly maximized this window.
- **Monocle**: Global layout constraint — workspace-wide mode that fills screen with focused window.
- **Floating**: Local window override — user dragged window out of layout. Subordinate to Monocle because global layout mode overrides per-window chrome when active.
- **Tiled**: Default fallback.

### 2. Fix precedence in `window_mode()` (layout.rs:~216)

Swap `is_monocle()` before `is_floating()`:

```rust
pub fn window_mode(&self, w: &Window) -> WindowMode {
    if w.is_maximized() {
        WindowMode::Maximized
    } else if self.is_monocle() {
        WindowMode::Monocle
    } else if w.is_floating() {
        WindowMode::Floating
    } else {
        WindowMode::Tiled
    }
}
```

### 3. Rewrite `test_window_mode_priority_hierarchy` (layout.rs:~1093)

Delete `evaluate_mode()` shadow helper. Test against `WindowManager::window_mode(&window)` directly using `make_wm()` from sibling test module. Use `wm.monocle_mode = MonocleMode::On` to activate global monocle.

Test all 4 permutations against the real production API:

| Maximized | Monocle | Floating | Expected `window_mode()` |
|-----------|---------|----------|--------------------------|
| false     | false   | false    | `Tiled`                  |
| false     | true    | false    | `Monocle`                |
| false     | true    | true     | `Monocle` (precedence fix) |
| true      | true    | true     | `Maximized`              |
