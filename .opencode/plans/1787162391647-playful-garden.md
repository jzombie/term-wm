# Plan: Detect Cargo context in `default_environment()`

## Problem
`default_environment()` uses only `cfg!(debug_assertions)` to decide between Dev and Prod. Running `cargo run --release` disables `debug_assertions`, causing it to evaluate to `Environment::Prod` and hit the production gateway during local testing.

## Fix
**File:** `crates/term-wm-config/src/env.rs` (lines 55-61)

Replace the current implementation:

```rust
pub fn default_environment() -> Environment {
    if cfg!(debug_assertions) {
        Environment::Dev
    } else {
        Environment::Prod
    }
}
```

With:

```rust
pub fn default_environment() -> Environment {
    if std::env::var_os("CARGO_MANIFEST_DIR").is_some() || cfg!(debug_assertions) {
        Environment::Dev
    } else {
        Environment::Prod
    }
}
```

## Behavior After Change

| Scenario | `CARGO_MANIFEST_DIR` | `debug_assertions` | Result |
|---|---|---|---|
| `cargo run` | present | true | Dev |
| `cargo run --release` | present | false | Dev |
| Installed binary | absent | false | Prod |
| `TERM_WM_ENV=prod cargo run --release` | present | false | Prod (explicit override wins) |
