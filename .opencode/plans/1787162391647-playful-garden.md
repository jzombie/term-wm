# Plan: Socket-Aware Session Inception Protection

## Problem
The current inception guard uses a coarse global boolean (`TERM_SESSION_ACTIVE=1`) on every spawned PTY child. This causes false positives: running `cargo run` inside a prod gateway session blocks the dev build from launching, even though it targets a completely separate gateway socket (`term-wm/dev/<user>/gateway`). Actual inception hazards only occur when the inner process targets the **same** gateway daemon.

## Files to Modify

### 1. `crates/term-wm-config/src/env.rs`
- **Add** `SESSION_GATEWAY_ENV_VAR` constant: `"TERM_SESSION_GATEWAY"`
- **Keep** `SESSION_ACTIVE_ENV_VAR` for backward compatibility (deprecated, still set by server)

### 2. `crates/term-session-muxio-service-definitions/src/channel.rs`
- **Re-export** `SESSION_GATEWAY_ENV_VAR` alongside existing `SESSION_ACTIVE_ENV_VAR`

### 3. `crates/term-session-muxio-service-definitions/src/lib.rs`
- **Add** `SESSION_GATEWAY_ENV_VAR` to the re-export list

### 4. `crates/term-session-server/src/session.rs` (line 68)
- **Inject** the active gateway socket path into spawned PTY children:
  ```rust
  let active_gateway = term_session_muxio_service_definitions::gateway_channel_name().to_string();
  builder.env(term_wm_config::env::SESSION_GATEWAY_ENV_VAR, &active_gateway);
  // Keep legacy boolean for backward compat with older clients
  builder.env(term_wm_config::env::SESSION_ACTIVE_ENV_VAR, "1");
  ```

### 5. `crates/term-session-client/src/lib.rs`
- **Refactor** `should_block_nesting` to accept gateway path strings:
  ```rust
  fn should_block_nesting(
      active_gateway: Option<&str>,
      target_socket: &str,
      allow_nested: bool,
  ) -> bool {
      if allow_nested {
          return false;
      }
      match active_gateway {
          Some(active) => active == target_socket,
          None => false,
      }
  }
  ```
- **Update** `run_session` guard (lines 305-320):
  ```rust
  let host_gateway = std::env::var(term_session_muxio_service_definitions::SESSION_GATEWAY_ENV_VAR).ok();
  if should_block_nesting(host_gateway.as_deref(), socket_path, allow_nested) {
      return Err(io::Error::other(NESTED_SESSION_FATAL));
  }
  ```

### 6. Tests to Update

- **`crates/term-session-client/src/lib.rs`** — update `should_block_nesting_truth_table` test (lines 1005-1020) for new signature (3 params: active_gateway, target_socket, allow_nested)
- **`crates/term-session-server/src/session.rs`** — update `spawn_marks_children_as_in_session` test (lines 309-317) to also verify `TERM_SESSION_GATEWAY` is set
- **`crates/term-session/tests/daemon_tests.rs`** — update `attach_inside_nested_env_aborts_without_allow_nested` (line 1035) to set `TERM_SESSION_GATEWAY` to the same gateway (instead of `TERM_SESSION_ACTIVE=1`), and update `attach_inside_nested_env_proceeds_with_allow_nested` (line 1068) similarly

## Behavior After Change

| Parent Gateway | Inner Target | `--allow-nested` | Result |
|---|---|---|---|
| None (shell) | `term-wm/dev/alice/gateway` | no | **Proceeds** |
| `term-wm/prod/alice/gateway` | `term-wm/dev/alice/gateway` | no | **Proceeds** (different gateways) |
| `term-wm/prod/alice/gateway` | `term-wm/prod/alice/gateway` | no | **Aborts** (same gateway) |
| `term-wm/prod/alice/gateway` | `term-wm/prod/alice/gateway` | yes | **Proceeds** (explicit bypass) |
