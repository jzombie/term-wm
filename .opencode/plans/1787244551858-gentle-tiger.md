# Fix: Flaky OSC52 Integration Tests Under `--all-features`

## Problem

Two integration tests in `tests/integration_session.rs` flake under `cargo test --workspace --all-features` due to subscription timing races under heavy CPU load.

## File to Modify

`tests/integration_session.rs` (single file, two surgical edits)

---

## Fix 1: `session_osc52_in_output` (line 318)

**Race:** `Spawn` is called before `open_channel(SUBSCRIBE_OUTPUT_METHOD_ID)`. Under load, `osc52_alive` writes its OSC52 payload to the PTY and the server broadcasts it to zero subscribers before the subscription RPC completes. The payload is lost; the subscriber only sees trailing teardown bytes.

**Fix:** Swap the order — open the output subscription *before* spawning, so the subscriber is already registered when output arrives.

**Current code (lines 316-349):**
```rust
async fn session_osc52_in_output() {
    let mock = get_mock_bin();
    let (client, _conn_id, guard) = spawn_session(&test_channel("test/osc52_output")).await;
    Spawn::call(&*client, SpawnRequest { ... }).await.unwrap();  // spawn first
    let (_, mut reader) = client.open_channel(SUBSCRIBE_OUTPUT_METHOD_ID, 0).await.unwrap();  // subscribe second
    let output = wait_for_output(&mut reader, EXPECTED_OSC52_PAYLOAD, Duration::from_secs(3)).await;
    ...
}
```

**New code:**
```rust
async fn session_osc52_in_output() {
    let mock = get_mock_bin();
    let (client, _conn_id, guard) = spawn_session(&test_channel("test/osc52_output")).await;
    // Subscribe FIRST so the listener is registered before output arrives.
    let (_, mut reader) = client.open_channel(SUBSCRIBE_OUTPUT_METHOD_ID, 0).await.unwrap();
    Spawn::call(&*client, SpawnRequest {
        cmd: Some(vec![mock, "osc52_alive".into()]),
        cols: TEST_COLS,
        rows: TEST_ROWS,
        cwd: None,
    }).await.unwrap();
    let output = wait_for_output(&mut reader, EXPECTED_OSC52_PAYLOAD, Duration::from_secs(3)).await;
    let payload = find_osc52_payload(&output);
    assert_eq!(payload, Some(common::mock::EXPECTED_OSC52_PAYLOAD), ...);
    guard.shutdown().await;
}
```

**Why this is safe:** The subscribe handler (`session_server.rs:1215-1267`) works with or without a live session — it clones the (empty) `output_cache`, pushes the subscriber, and notifies the polling task. When `Spawn` later creates the session, the polling task immediately starts broadcasting output to the already-registered subscriber.

## Fix 2: `session_osc52_late_subscribe_gets_retained_output` (line 419)

**Race:** A fixed `tokio::time::sleep(Duration::from_millis(1200))` waits for the `osc52` process to exit and the server to tear down the session. Under load, this isn't enough — the subscriber attaches while the session is still live, misses the broadcast, and gets no retained cache.

**Fix:** Replace the fixed sleep with a `ListChannels` polling loop that checks `session.exited == true` before subscribing.

**Current code (lines 417-454):**
```rust
async fn session_osc52_late_subscribe_gets_retained_output() {
    ...
    Spawn::call(&*client, SpawnRequest { cmd: Some(vec![mock, "osc52".into()]), ... }).await.unwrap();
    tokio::time::sleep(Duration::from_millis(1200)).await;  // fixed sleep — flaky
    let (_, mut reader) = client.open_channel(SUBSCRIBE_OUTPUT_METHOD_ID, 0).await.unwrap();
    ...
}
```

**New code:**
```rust
async fn session_osc52_late_subscribe_gets_retained_output() {
    let mock = get_mock_bin();
    let channel = test_channel("test/osc52_retained");
    let (client, _conn_id, guard) = spawn_session(&channel).await;
    Spawn::call(&*client, SpawnRequest {
        cmd: Some(vec![mock, "osc52".into()]),
        cols: TEST_COLS,
        rows: TEST_ROWS,
        cwd: None,
    }).await.unwrap();

    // Poll until the server marks the session as exited, instead of
    // relying on a fixed sleep that can race under heavy CPU load.
    let channel_name = channel.to_string();
    let start = std::time::Instant::now();
    while start.elapsed() < Duration::from_secs(5) {
        if let Ok(resp) = list_channels(&client).await {
            if let Some(ch) = resp.channels.iter().find(|c| c.name == channel_name) {
                if ch.session.as_ref().is_some_and(|s| s.exited) {
                    break;
                }
            }
        }
        tokio::time::sleep(Duration::from_millis(50)).await;
    }

    let (_, mut reader) = client.open_channel(SUBSCRIBE_OUTPUT_METHOD_ID, 0).await.unwrap();
    let output = wait_for_output(&mut reader, EXPECTED_OSC52_PAYLOAD, Duration::from_secs(3)).await;
    let payload = find_osc52_payload(&output);
    assert_eq!(payload, Some(common::mock::EXPECTED_OSC52_PAYLOAD), ...);
    guard.shutdown().await;
}
```

**Key detail:** The `channel` variable is captured as a `ChannelName` before the loop. The `channel_name` string is derived from it for the `ListChannels` lookup. The `list_channels()` helper is already imported from `common::session`.
