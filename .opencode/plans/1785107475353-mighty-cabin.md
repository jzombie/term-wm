# Plan: Panel click support when command palette is open

## Goal

When the command palette is open and the user clicks **outside the palette bounds**, the click should:
1. Dismiss the palette
2. Route to panels, overlays, window chrome, or activate the window under the cursor — in priority order, in a single unified method.

Panels are pure UI chrome (they switch windows/tabs and never forward clicks to terminal processes), so routing clicks to them is safe from PTY event leakage.

## The Root Cause

Panel sub-elements (window title tabs, hamburger button, tiling indicator) NEVER register hitboxes into the `HitboxRegistry`. They do hit-testing internally in `on_mouse_press()` by comparing click coordinates against stored rects (`self.list.window_hits`, `self.menu_rect`, etc.). See `wm_top_panel.rs` where `render()` takes `_registry` (unused).

In normal mode, `register_panel_hitboxes()` registers the panel's outer hitbox with `ComponentOwner::Layer(layer_id)` and the `top_claimed` area. But in monocle cramped mode, `top_claimed` is empty (panels render as overlays), so this registration is skipped.

Without ANY panel hitbox in the registry, `handle_outside_click`'s `hit_test_all` can never find a panel at the click coordinates — only the full-screen Window hitbox is found.

## Architecture

### Change 1: Register panel outer hitbox in `render_overlays()`
After the panel overlay renders in monocle mode, manually register its outer hitbox with `ComponentOwner::Layer(layer_id)` and the overlay `top_area`. This gives `handle_outside_click` a panel hitbox to find.

### Change 2: `handle_outside_click` (via `hit_test_all`)
Iterates all hitboxes at position, dispatches Layer/Overlay events, focuses Chrome/Window directly.

### 4. Unify dispatch — Extract `dispatch_action`

Both `drain_action_queue` and the keybinding barrier's match block handle identical actions (`ToggleTiling`, `FocusWindow`, `ToggleMouseCapture`, `ToggleClipboardMode`, `ToggleWindowSelection`, `SendNotification`, `Callback`) with duplicate code. Extract a single `dispatch_action` function and have both paths call it.

File: `crates/term-wm-core/src/runner.rs`

```rust
/// Single authoritative action dispatcher. Both the component action queue
/// and the overlay keybinding barrier route through this function.
fn dispatch_action<C, L, O, A>(
    app: &mut A,
    key: WindowKey,
    action: TermWmAction,
    queue: &mut VecDeque<(WindowKey, TermWmAction)>,
) where
    C: Component<TermWmAction>,
    L: WmComponent,
    O: Overlay<TermWmAction>,
    A: WindowManagerHost<C, L, O>,
{
    match action {
        TermWmAction::Quit | TermWmAction::ExitUi => app.open_exit_confirm(),
        TermWmAction::Help | TermWmAction::OpenHelp => app.open_help_overlay(),
        TermWmAction::CloseHelp => {}
        TermWmAction::CloseWindow(k) => app.wm().close_window(k),
        TermWmAction::NewWindow => drop(app.wm_new_window()),
        TermWmAction::MinimizeWindow(k) => app.wm().minimize_window(k),
        TermWmAction::MaximizeWindow(k) => app.wm().toggle_maximize(k),
        TermWmAction::ToggleMonocle => app.wm().toggle_monocle(),
        TermWmAction::ToggleTiling => app.wm().toggle_tiling(),
        TermWmAction::ToggleMouseCapture => app.wm().toggle_mouse_capture(),
        TermWmAction::ToggleClipboardMode => app.wm().toggle_clipboard_enabled(),
        TermWmAction::ToggleWindowSelection => app.wm().toggle_window_selection(),
        TermWmAction::ToggleDebugWindow => app.toggle_debug_window(),
        TermWmAction::ToggleSystemPanel => app.toggle_system_panel(),
        TermWmAction::FocusWindow(k) => {
            if app.wm().window_state(k) == Some(crate::window::WindowState::Iconic) {
                app.wm().transition_window(k, crate::window::WindowState::Mapped);
            }
            app.wm().focus_window_key(k);
        }
        TermWmAction::FocusNext => app.wm().advance_focus(true),
        TermWmAction::FocusPrev => app.wm().advance_focus(false),
        TermWmAction::OpenCommandPalette => {
            if app.wm().command_menu_visible() {
                app.wm().close_command_palette();
            } else {
                app.open_command_palette();
            }
        }
        TermWmAction::SendNotification(msg) => app.wm().push_notification(msg, Duration::from_secs(3)),
        TermWmAction::Callback(f) => f(),
        TermWmAction::RequestKeyboardFocus(id) => app.wm().set_keyboard_focus(key, id),
        TermWmAction::PasteClipboard => {
            if let Some(text) = app.wm().clipboard_mut().and_then(|cb| cb.get().ok()) {
                queue.push_back((key, TermWmAction::ClipboardPaste(text)));
            }
        }
        action => {
            let ctx = app.wm().component_context_for(true, key);
            if let Some(comp) = app.wm().component_for_key_mut(key) {
                comp.update(action, &ctx, queue);
            }
        }
    }
}

fn drain_action_queue<C, L, O, A>(app: &mut A, queue: &mut VecDeque<(WindowKey, TermWmAction)>)
where
    C: Component<TermWmAction>,
    L: WmComponent,
    O: Overlay<TermWmAction>,
    A: WindowManagerHost<C, L, O>,
{
    while let Some((key, action)) = queue.pop_front() {
        dispatch_action(app, key, action, queue);
    }
}
```
