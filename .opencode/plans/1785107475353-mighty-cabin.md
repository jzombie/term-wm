Every new function, trait method, and logic branch added in this feature must have a unit test.

## Implementation notes

- Use `TestOverlay` (already defined in `mod.rs` tests) for overlay-bound tests.
- Use `TestComponent` for window-related tests.
- For dispatch_action tests, create a `FakeApp` (pattern used elsewhere in runner.rs) that records actions.
- For spatial barrier tests, use the existing `run_event_loop` test infrastructure.
