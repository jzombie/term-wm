# Plan: Generic outside-click dismissal for overlays

## Goal

When any dismissable overlay is open and the user clicks **outside the overlay bounds**, the click should:
1. Dismiss the overlay
2. Route to panels, window chrome, or activate the window underneath

The exit confirm overlay remains a full modal blocker (it returns `None` from `render_area()`).

## Architecture

Replace per-overlay visibility checks and close methods in `runner.rs` with a unified generic mechanism:

1. **`active_overlay: Option<OverlayKey>`** on `WindowManager` — tracks the currently active dismissable overlay
2. **`close_overlay(key)`** — generic overlay removal that also clears `active_overlay` if matching
3. **`handle_overlay_event(key, event)`** — generic dispatch to any overlay's `Component::handle_events`
4. **Runner** — single block: get active overlay, check bounds via `render_area()`, dismiss + `handle_outside_click` if outside, route to `handle_events` if inside

Exit confirm stays separate (uses its own `handle_confirm_event` dispatch path and returns `None` from `render_area()`).

## Changes Required

### 1. Add `active_overlay` to `WindowManager`

File: `crates/term-wm-core/src/window/window_manager/mod.rs`

```rust
active_overlay: Option<OverlayKey>,
```

Initialize to `None` in `with_config()`. Update `open_help_overlay` and `open_command_palette_overlay` to set it. Update `close_help_overlay` and `close_command_palette` to clear it. (Or use a generic `close_overlay` that handles both.)

### 2. Add `overlay_render_area(key)` and `overlay_event_handler(key, event)`

File: `crates/term-wm-core/src/window/window_manager/overlays.rs`

```rust
pub fn overlay_render_area(&self, key: OverlayKey) -> Option<LayoutRect> {
    self.overlays.get(key).and_then(|o| o.render_area())
}
```

For event handling, the existing per-overlay methods have different return types. Keep them but add a generic `handle_overlay_event` that wraps them. Or simpler: the runner just calls `handle_events` on the overlay via `overlays.get_mut(key)` directly.

### 3. Update `handle_outside_click` — Parameterize overlay exclusion

Add `ignored_overlay: Option<OverlayKey>` parameter. Replace `self.command_palette_key` in the Overlay match guard with `ignored_overlay`.

### 4. `runner.rs` — Unified overlay barrier

Replace the help overlay and command palette barriers with a single generic block:

```rust
if let Some(active_key) = app.wm().active_overlay {
    // Spatial hit-test for outside-click dismissal (overlays with render_area)
    if let Event::Mouse(mouse_evt) = &evt
        && matches!(mouse_evt.kind, MouseEventKind::Press(_))
        && let Some(bounds) = app.wm().overlay_render_area(active_key)
        && !bounds.contains(mouse_evt.column, mouse_evt.row)
    {
        app.wm().close_overlay(active_key);
        let mut actions = std::collections::VecDeque::new();
        if !app.wm().handle_outside_click(
            mouse_evt.column, mouse_evt.row, &evt, &mut actions, Some(active_key),
        ) {
            app.wm().handle_mouse_focus_click(mouse_evt.column, mouse_evt.row);
        }
        drain_action_queue(app, &mut actions);
        update_selection_snapshot(app);
        return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
    }
    // Handle inside-click or keyboard event via the overlay's Component::handle_events
    let _ = app.wm().handle_overlay_event(active_key, &evt);
    update_selection_snapshot(app);
    return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
}
```

The exit confirm barrier stays BEFORE this block (it uses its own `handle_confirm_event` path and never reaches the generic block because it returns `None` from `render_area()`).

### 5. `WmHelpOverlayComponent` — Implement `render_area()`

File: `crates/term-wm-sys-ui-components/src/wm_help_overlay.rs`

If it doesn't have an `area: Cell<LayoutRect>` field, add one, set it in `render()`, and implement:

```rust
fn render_area(&self) -> Option<LayoutRect> {
    Some(self.area.get())
}
```

### 6. `close_overlay(key)` — Make it generic

The existing method only removes from the SlotMap. Update it to also clear `active_overlay`:

```rust
pub fn close_overlay(&mut self, key: OverlayKey) {
    self.overlays.remove(key);
    if Some(key) == self.active_overlay {
        self.active_overlay = None;
    }
    self.input_mode = crate::actions::WmInputMode::Passthrough;
}
```
