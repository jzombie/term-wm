# Plan: Panel click support when command palette is open

## Goal

When the command palette is open and the user clicks **outside the palette bounds**, the click should:
1. Dismiss the palette
2. Activate the window under the cursor (body or header) — **already implemented**
3. OR route to a panel (taskbar, status bar) if the click lands on one — **new**

Panels are pure UI chrome (they switch windows/tabs and never forward clicks to terminal processes), so routing clicks to them is safe from PTY event leakage.

## Architecture

After the palette is closed on outside-click:
1. `handle_mouse_focus_click(col, row)` handles window activation (already works)
2. `panel_hit_test(col, row, event)` checks if the click falls within `top_claimed` or `bottom_claimed` via `rect_contains`, and if so dispatches to the panel component via `get_semantic_component_mut` + `handle_events`. Any action returned by the panel (e.g. `FocusWindow` from clicking a window tab) is dispatched in the runner.

This avoids PTY leakage because panels are pure UI chrome that never forward clicks to terminal processes. No use of `dispatch_mouse` or the hitbox registry — instead, direct bounding-box checks against the claimed panel regions.

## Changes

### 1. `WindowManager` — Add `panel_hit_test()` method returning `Option<TermWmAction>`

File: `crates/term-wm-core/src/window/window_manager/mod.rs`

```rust
/// Dispatch a mouse click to the panel component if the click falls within
/// a panel region. Panels are pure UI chrome — they never forward clicks to
/// terminal processes, so dispatching here is safe from PTY event leakage.
///
/// Returns `Some(action)` if the panel produced an action (e.g. FocusWindow
/// from clicking a window title tab), or `None` if the click missed all panels
/// or the panel ignored it.
pub fn panel_hit_test(&mut self, col: u16, row: u16, event: &Event) -> Option<TermWmAction> {
    // Check top panel
    if !self.top_claimed.is_empty()
        && crate::layout::rect_contains(self.top_claimed, col, row)
    {
        if let Some(panel) = self.get_semantic_component_mut(ComponentTag::TopPanel) {
            let ctx = self.component_context(true).with_screen_area(self.top_claimed);
            if let EventResult::Action(action) = panel.handle_events(event, &ctx) {
                return Some(action);
            }
        }
    }

    // Check bottom panel
    if !self.bottom_claimed.is_empty()
        && crate::layout::rect_contains(self.bottom_claimed, col, row)
    {
        if let Some(panel) = self.get_semantic_component_mut(ComponentTag::BottomPanel) {
            let ctx = self.component_context(true).with_screen_area(self.bottom_claimed);
            if let EventResult::Action(action) = panel.handle_events(event, &ctx) {
                return Some(action);
            }
        }
    }

    None
}
```

### 2. `runner.rs` — Capture and dispatch panel action

File: `crates/term-wm-core/src/runner.rs`, spatial fast-path block (lines 444-460)

```rust
if !palette_bounds.contains(mouse_evt.column, mouse_evt.row) {
    // 1. Dismiss palette
    app.wm().close_command_palette();

    // 2. Try window activation first (no-op if click is outside all windows)
    app.wm().handle_mouse_focus_click(mouse_evt.column, mouse_evt.row);

    // 3. Route to panels if click landed on a panel region
    if let Some(action) = app.wm().panel_hit_test(mouse_evt.column, mouse_evt.row, &evt) {
        match action {
            TermWmAction::ToggleDebugWindow => app.toggle_debug_window(),
            // Delegate other panel actions (e.g. FocusWindow from tab click)
            // to the WM action handler.
            other => app.handle_wm_action(other),
        }
    }

    update_selection_snapshot(app);
    return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
}
```
