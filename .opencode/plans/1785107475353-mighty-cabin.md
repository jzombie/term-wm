# Plan: Minimal outside-click for help overlay (FIXED)

## Goal

When the help overlay is open and the user clicks **outside the dialog bounds**, the click should dismiss it and activate the window/panel underneath — same behavior as the command palette. No generic barrier refactoring; just add a spatial check before the existing `handle_help_event` call, and parameterize the stale hitbox exclusion.

## Architecture

Keep the existing per-overlay event handlers intact. Add a bounds check before each one. Parameterize `handle_outside_click` so it knows which stale overlay hitbox to ignore during the routing phase.

## Changes Required

### 1. Add `help_overlay_bounds()` on `WindowManager`

File: `crates/term-wm-core/src/window/window_manager/overlays.rs`

```rust
pub fn help_overlay_bounds(&self) -> Option<LayoutRect> {
    self.help_key
        .and_then(|key| self.overlays.get(key))
        .and_then(|o| o.render_area())
}
```

### 2. Parameterize `handle_outside_click`

File: `crates/term-wm-core/src/window/window_manager/mod.rs`

Change the signature to accept `ignored_overlay`:

```rust
pub fn handle_outside_click(
    &mut self,
    col: u16,
    row: u16,
    event: &Event,
    actions: &mut VecDeque<(WindowKey, TermWmAction)>,
    ignored_overlay: Option<OverlayKey>,
) -> bool
```

Inside this method, replace `self.command_palette_key` in the hit-test match guard with `ignored_overlay`.

### 3. `runner.rs` — Add spatial check before `handle_help_event`

Add the outside-click block. Capture the overlay key *before* closing it so we can pass it to `handle_outside_click`:

```rust
if app.wm().help_overlay_visible() {
    // Spatial check for outside-click dismissal
    if let Event::Mouse(mouse_evt) = &evt
        && matches!(mouse_evt.kind, MouseEventKind::Press(_))
        && let Some(bounds) = app.wm().help_overlay_bounds()
        && !bounds.contains(mouse_evt.column, mouse_evt.row)
    {
        // 1. Capture the key before destroying the overlay state
        let stale_key = app.wm().help_key();

        app.wm().close_help_overlay();
        let mut actions = std::collections::VecDeque::new();

        // 2. Pass the stale_key to bypass the ghost hitbox
        if !app.wm().handle_outside_click(
            mouse_evt.column, mouse_evt.row, &evt, &mut actions, stale_key,
        ) {
            app.wm().handle_mouse_focus_click(mouse_evt.column, mouse_evt.row);
        }
        drain_action_queue(app, &mut actions);
        update_selection_snapshot(app);
        return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
    }
    // Inside-click → existing handler (unchanged)
    let _ = app.wm().handle_help_event(&evt);
    update_selection_snapshot(app);
    return flush_state_changes(app, driver, ControlFlow::Continue, false, None);
}
```

### 4. `runner.rs` — Update existing `handle_outside_click` calls

Update the existing command palette outside-click dismissal to pass its key:
