# Plan: Fix maximize-while-tiled tabbing issue

## Bug
When a tiled window is maximized, other windows become inaccessible:
- Maximized window covers full managed area (floating renders on top of tiled)
- Mouse clicks always hit the maximized window (full-area region)
- Focus cycling changes focus logically but the maximized window stays on top

## Approach: Layer both (Void for tiled, prev_floating_rect for floating)

**Floating origin:** `prev_floating_rect` saves/restores the floating rect.
**Tiled origin:** Replace `Leaf(key)` with `Void(id)` in-place — preserves exact tree topology, split weights, and spatial position. On restore, swap Void back to Leaf.

No new `was_tiled_before_maximize` flag. Void being present in the tree implicitly means "was tiled." `prev_floating_rect` being `Some` means "was floating."

### 3. Rewrite `toggle_maximize` (chrome.rs)

```rust
pub fn toggle_maximize(&mut self, key: WindowKey) {
    let is_maxed = self.window(key).is_some_and(|w| w.is_maximized);

    if is_maxed {
        // UNMAXIMIZE
        let prev_float = self.take_prev_floating_rect(key);
        if let Some(prev_spec) = prev_float {
            // Was floating: restore previous floating rect
            self.set_floating_rect(key, Some(prev_spec));
        } else {
            // Was tiled: restore Void → Leaf in layout tree
            self.clear_floating_rect(key);
            if let Some(ref mut layout) = self.managed_layout {
                layout.restore_void_to_leaf(key);
            }
        }
        if let Some(w) = self.windows.get_mut(key) {
            w.is_maximized = false;
            w.borders_enabled = true;
            w.void_id = None;
        }
        self.bring_floating_to_front_key(key);
        return;
    }

    // MAXIMIZE
    let full = FloatRectSpec::Absolute(...managed_area...);
    if let Some(current) = self.floating_rect(key) {
        // Was floating: save floating rect
        self.set_prev_floating_rect(key, Some(current));
    } else {
        // Was tiled: replace Leaf with Void in-place
        if let Some(ref mut layout) = self.managed_layout {
            let void_id = layout.preserve_leaf_as_void(key);
            if let Some(w) = self.windows.get_mut(key) {
                w.void_id = void_id;
            }
        }
        self.set_prev_floating_rect(key, None);
    }
    self.set_floating_rect(key, Some(full));
    if let Some(w) = self.windows.get_mut(key) {
        w.is_maximized = true;
        w.borders_enabled = false;
    }
    self.bring_floating_to_front_key(key);
}
```

### 5. Update `detach_from_tiling_layout` — handle void placeholder teardown
**File:** `crates/term-wm-core/src/window/window_manager/layout.rs:765-774`

If the window has `void_id` set (was maximized while tiled), remove the Void node from the tree instead of searching for `Leaf(key)` (which doesn't exist — it was replaced by the Void). Add `remove_void_by_id(void_id)` to `TilingLayout`/`LayoutNode`:

```rust
pub(super) fn detach_from_tiling_layout(&mut self, key: WindowKey) {
    if let Some(ref mut layout) = self.managed_layout {
        // If window has an active void placeholder (was maximized while tiled)
        if let Some(void_id) = self.window(key).and_then(|w| w.void_id) {
            layout.remove_void_by_id(void_id);
            if let Some(w) = self.windows.get_mut(key) {
                w.void_id = None;
            }
        } else {
            let _ = layout.root_mut().remove_leaf(key);
            layout.root_mut().cleanup_after_removal();
            layout.root_mut().clear_leaf(key);
        }
    }
}
```

Add `remove_void_by_id(&mut self, void_id: usize) -> bool` to `LayoutNode` — finds the Void node by ID and removes it from its parent split, then calls `cleanup_after_removal` to collapse empty parents.

# Plan: Fix New Window Creation While Window Is Maximized

## Bug Analysis

When a tiled window `A` is maximized and a new window `B` is opened, `B` is
invisible or `A` disappears. Two interconnected bugs:

### Bug 1: Premature Focus Pointer Mutation in `transition_window`

`open_window(B)` calls `transition_window(B, Mapped)` → `focus_add(B)` →
`self.focus.set_current(B)`. Later when `focus_window_key(B)` runs — which
checks `prev_focus != key` to decide whether to unmaximize the old window —
`prev_focus` is already `B` (the new focus), so the comparison `B != B` is
false and `toggle_maximize(A)` is never called. `A` stays maximized and
renders a full-screen overlay covering `B`.

### Bug 2: Tiling Mode Destruction in `try_spawn_floating_default`

`try_spawn_floating_default(B)` checks
`existing.iter().all(|k| self.is_window_floating(*k))`. Since maximized `A`
has a `floating_rect`, `is_window_floating(A)` returns `true`, so the
function concludes the workspace is in Floating Mode and runs
`self.managed_layout = None;`, destroying the tiling tree (including `A`'s
`Void` placeholder). `B` is spawned as floating. When `A` is later
unmaximized, `managed_layout` is `None` and `A` has no tiling placement.

## Fixes

### 1. Update `focus_add` (mod.rs)

Append the key to `focus.order()` but only set `focus.current()` if the
current focus is an invalid key (e.g. initial startup). Defer focus changes
to `focus_window_key` so the previous focus is preserved for auto-unmaximize.

```rust
fn focus_add(&mut self, key: WindowKey) {
    if !self.focus.order().contains(&key) {
        let mut order = self.focus.order().to_vec();
        order.push(key);
        self.focus.set_order(order);
    }
    if !self.windows.contains_key(*self.focus.current()) {
        self.focus.set_current(key);
    }
}
```

### 2. Update `try_spawn_floating_default` (drag.rs)

Return `false` early if `self.managed_layout.is_some()` (in Tiling Mode —
new windows must be tiled). Remove `self.managed_layout = None;` and the
redundant internal `self.focus_window_key(key)` call.

```rust
pub fn try_spawn_floating_default(&mut self, key: WindowKey) -> bool {
    if self.managed_layout.is_some() {
        return false;
    }
    let existing: Vec<_> = self.mapped_windows()
        .into_iter().filter(|k| *k != key).collect();
    if existing.is_empty() || !existing.iter().all(|k| self.is_window_floating(*k)) {
        return false;
    }
    let rect = self.default_cascading_rect(existing.len());
    self.set_floating_rect(key, Some(FloatRectSpec::Absolute(FloatRect { ... })));
    self.bifurcate_draw_order();
    true
}
```
