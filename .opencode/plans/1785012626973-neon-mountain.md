# Fix: Direct Mode Scrollbar Space & Auto-Sync with Alt Screen

Transition-based polling (like `take_pending_title`): only fires when alt screen state changes, never overwrites manual toggle, never floods notifications.

## Code Changes

### 1. Component trait
**`crates/term-wm-core/src/components.rs`** (after `take_pending_title`):
```rust
/// Returns Some(bool) exactly once when the pane's alternate screen state changes.
/// None means no change since last poll.
fn take_alternate_screen_transition(&mut self) -> Option<bool> {
    None
}
```

### 2. Delegate macro
**`crates/term-wm-core/src/macros.rs`** (after `take_pending_title`):
```rust
fn take_alternate_screen_transition(&mut self) -> Option<bool> {
    match self { $(Self::$variant(c) => c.take_alternate_screen_transition(),)* }
}
```

### 3. TerminalComponent — transition tracking
**`crates/term-wm-ui-components/src/terminal.rs`**

**Struct**: remove `last_was_direct_or_alt`, add `reported_alt_screen: bool` initialized to `false`.

Override in `impl Component`:
```rust
fn take_alternate_screen_transition(&mut self) -> Option<bool> {
    let current = self.pane.get_mut().alternate_screen();
    if current != self.reported_alt_screen {
        self.reported_alt_screen = current;
        Some(current)
    } else {
        None
    }
}
```

**`render_screen`** — current-state check (no transition history needed):
```rust
if let Some(handle) = ctx.scroll_handle() {
    if ctx.direct_mode() || pane.alternate_screen() {
        handle.set_content_size(clipped.width as usize, clipped.height as usize);
        pane.set_scrollback(0);
    } else {
        let used = pane.max_scrollback();
        handle.set_content_size(clipped.width as usize, used + clipped.height as usize);
        let current_sb = pane.scrollback();
        let view_offset = ctx.viewport().offset_y;
        if current_sb == 0 {
            if view_offset < self.last_max_scrollback.get().saturating_sub(1) {
                let target_sb = used.saturating_sub(view_offset);
                pane.set_scrollback(target_sb);
            } else {
                handle.scroll_vertical_to(usize::MAX);
            }
        } else if current_sb != self.last_scrollback.get() {
            let new_offset = used.saturating_sub(current_sb);
            handle.scroll_vertical_to(new_offset);
        } else {
            let target_sb = used.saturating_sub(view_offset);
            if target_sb != current_sb {
                pane.set_scrollback(target_sb);
            }
        }
        self.last_max_scrollback.set(used);
    }
}
```

### 4. WindowManager — transition method
**`crates/term-wm-core/src/window/window_manager/mod.rs`** (after `window_pane_title`):
```rust
pub fn take_alternate_screen_transition(&mut self, key: WindowKey) -> Option<bool> {
    self.component_for_key_mut(key)
        .and_then(|c| c.take_alternate_screen_transition())
}
```

**`set_direct_mode`** — push_notification inside the guard:
```rust
pub fn set_direct_mode(&mut self, key: WindowKey, value: bool) {
    let title = self.window_title(key);
    if let Some(w) = self.windows.get_mut(key) {
        if w.direct_mode != value {
            w.direct_mode = value;
            if value {
                if let Some(c) = self.components.get_mut(w.component_key) {
                    c.clear_selection();
                }
            }
            self.mark_layout_dirty();
            let status = if value { "enabled" } else { "disabled" };
            self.push_notification(format!("Direct mode {} for {}", status, title));
        }
    }
}
```
