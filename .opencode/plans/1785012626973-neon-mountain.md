# Fix: Direct Mode Wastes Scrollbar Space

## Problem
When direct mode or alternate screen is active, `ScrollViewComponent` reserves 1 column for scrollbars (stale content_height) but doesn't draw them (`if !ctx.direct_mode()` guard). Wastes terminal width.

## Root Cause
Two interacting issues:

1. **Stale content_height**: `TerminalComponent::render_screen` only calls `handle.set_content_size(...)` when `!pane.alternate_screen()`. In alt screen/direct mode, `ScrollBounds.content_height` stays at the last primary-screen value (e.g. 2000). ScrollViewComponent sees 2000 > 24 and reserves a column.

2. **Viewport offset corruption on mode exit**: When exiting direct mode/alt screen, `ScrollViewComponent`'s `view_offset` is 0 (because during direct mode, content_height == viewport_height, so max offset = 0). `render_screen` sees `view_offset == 0` and interprets it as "user scrolled to top", calling `pane.set_scrollback(used)` — pinning the viewport to the top of history.

## Fix

### 1. `crates/term-wm-ui-components/src/terminal.rs` — Add `last_was_direct_or_alt: Cell<bool>`

**Struct:** Add field `last_was_direct_or_alt: Cell<bool>` initialized to `false`.

**`render_screen`**: Replace the current scroll sync block with:

| Mode | Action |
|------|--------|
| Alt screen OR direct mode | `set_content_size(viewport_w, viewport_h)`, `set_scrollback(0)`, set `last_was_direct_or_alt = true` |
| Normal mode, just exited from direct/alt | `set_content_size(viewport_w, used_sb + viewport_h)`, `set_scrollback(0)`, `scroll_vertical_to(usize::MAX)`, set `last_was_direct_or_alt = false` |
| Normal mode, was already normal | Existing sync logic unchanged |

The `else` branch (normal mode) wraps in `if self.last_was_direct_or_alt.get()` to handle the transition, else uses the original scroll-sync code.

### 2. `crates/term-wm-ui-components/src/scroll_view.rs`

Remove the `if !ctx.direct_mode()` guard (line 489) wrapping scrollbar rendering. ScrollViewComponent draws scrollbars when content_height > viewport_height. Since TerminalComponent now reports correct sizes, scrollbars naturally appear/disappear.

### 3. `crates/term-wm-core/src/window/window_manager/mod.rs`

In `set_direct_mode`: call `self.mark_layout_dirty()` to trigger immediate re-render on toggle.
