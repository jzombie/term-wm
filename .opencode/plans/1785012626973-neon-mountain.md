# Fix: Direct Mode Scrollbar Space & Auto-Sync with Alt Screen

## Root Cause
`TerminalComponent::render_screen` only updates `handle.set_content_size()` when `!pane.alternate_screen()`. In alt screen or direct mode, `ScrollBounds.content_height` stays stale (e.g. 2000 lines). `ScrollViewComponent` reserves a scrollbar column but no scrollbar is drawn (because the old `if !ctx.direct_mode()` guard also existed — both conditions needed fixing).

## Approach
- Auto-sync `direct_mode` flag with alt screen state using transition-based polling (`take_alternate_screen_transition`, same pattern as `take_pending_title`)
- `TerminalComponent` reports correct content size based on current state + transition tracking for the exit frame
- `ScrollViewComponent` remains pure — no `ctx.direct_mode()` checks; scrollbars render purely based on `needs_vertical`/`needs_horizontal`, which are naturally false when TerminalComponent reports viewport-sized content

### 3. TerminalComponent — transition detection + scroll sync fix
**`crates/term-wm-ui-components/src/terminal.rs`**

**Struct**: remove `last_was_direct_or_alt`, add `last_mode_suppressed_scroll: bool` (init `false`).

**Override** in `impl Component`:
```rust
fn take_alternate_screen_transition(&mut self) -> Option<bool> {
    let current = self.pane.get_mut().alternate_screen();
    if current != self.reported_alt_screen {
        self.reported_alt_screen = current;
        Some(current)
    } else {
        None
    }
}
```
Add `reported_alt_screen: bool` field (init `false`).

**`render_screen`** — scroll sync with transition guard:
```rust
let suppress_scroll = ctx.direct_mode() || pane.alternate_screen();

if suppress_scroll {
    handle.set_content_size(clipped.width as usize, clipped.height as usize);
    pane.set_scrollback(0);
    self.last_mode_suppressed_scroll = true;
} else {
    let used = pane.max_scrollback();
    handle.set_content_size(clipped.width as usize, used + clipped.height as usize);

    if self.last_mode_suppressed_scroll {
        // JUST exited direct mode or alt screen.
        // viewport offset is 0 (clamped during suppressed mode).
        // Reset to bottom rather than interpreting offset 0 as "scroll to top".
        self.last_mode_suppressed_scroll = false;
        pane.set_scrollback(0);
        handle.scroll_vertical_to(usize::MAX);
    } else {
        let current_sb = pane.scrollback();
        let view_offset = ctx.viewport().offset_y;
        if current_sb == 0 {
            if view_offset < self.last_max_scrollback.get().saturating_sub(1) {
                let target_sb = used.saturating_sub(view_offset);
                pane.set_scrollback(target_sb);
            } else {
                handle.scroll_vertical_to(usize::MAX);
            }
        } else if current_sb != self.last_scrollback.get() {
            let new_offset = used.saturating_sub(current_sb);
            handle.scroll_vertical_to(new_offset);
        } else {
            let target_sb = used.saturating_sub(view_offset);
            if target_sb != current_sb {
                pane.set_scrollback(target_sb);
            }
        }
    }
    self.last_max_scrollback.set(used);
}
```

### 4. WindowManager — transition method + fixed set_direct_mode
**`crates/term-wm-core/src/window/window_manager/mod.rs`** (after `window_pane_title`):
```rust
pub fn take_alternate_screen_transition(&mut self, key: WindowKey) -> Option<bool> {
    self.component_for_key_mut(key)
        .and_then(|c| c.take_alternate_screen_transition())
}
```

**`set_direct_mode`** — notification inside guard:
```rust
pub fn set_direct_mode(&mut self, key: WindowKey, value: bool) {
    let title = self.window_title(key);
    if let Some(w) = self.windows.get_mut(key) {
        if w.direct_mode != value {
            w.direct_mode = value;
            if value {
                if let Some(c) = self.components.get_mut(w.component_key) {
                    c.clear_selection();
                }
            }
            self.mark_layout_dirty();
            let status = if value { "enabled" } else { "disabled" };
            self.push_notification(format!("Direct mode {} for {}", status, title));
        }
    }
}
```

### 5. Auto-sync in render_app
**`src/lib.rs`** (in title loop):
```rust
for &key in &windows {
    if let Some(title) = wm.window_pane_title(key) {
        wm.set_window_title(key, title);
    }
    if let Some(is_alt) = wm.take_alternate_screen_transition(key) {
        wm.set_direct_mode(key, is_alt);
    }
}
```

### 6. ScrollViewComponent — NO changes
No `ctx.direct_mode()` guard. Scrollbars render purely based on `needs_vertical`/`needs_horizontal`. TerminalComponent naturally suppresses both during direct mode by reporting viewport-sized content.
