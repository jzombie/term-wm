# Fix: Command Palette Direct Mode State Label

## Approach
Invocation-bound capture: `wm_menu_items()` is called once when the palette opens (`term_wm_app.rs:289-304`). The MenuItem label evaluates state at that exact moment — no JIT refresh, no mutator hooks.

## Change

### `crates/term-wm-core/src/window/window_manager/mod.rs`

In `wm_menu_items()`, replace the `ToggleDirectMode` MenuItem:

```rust
];
let focused = self.focused_window();
let has_active = self.windows.contains_key(focused);
items.push(MenuItem {
    label: {
        let on = has_active && self.direct_mode(focused);
        format!("Direct Mode: {}", if on { "On" } else { "Off" }).into()
    },
    icon: Some("D"),
    action: TermWmAction::ToggleDirectMode,
    disabled: !has_active,
});
```

This moves the MenuItem from the `vec![]` macro to a `push()` call so `focused` and `has_active` can be computed once and reused for both `label` and `disabled`.

No other files need changes — no helper, no JIT refresh, no mutator hooks.
