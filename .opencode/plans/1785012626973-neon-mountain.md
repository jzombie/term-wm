# Fix: Command Palette State Synchronization (Clean Slate)

## Changes

### 1. `wm_menu_items()` — show state, disable when no active window

In `window_manager/mod.rs`, the `ToggleDirectMode` MenuItem:

```rust
MenuItem {
    label: {
        let focused = self.focused_window();
        let has_active = self.windows.contains_key(focused);
        let on = has_active && self.direct_mode(focused);
        format!("Direct Mode: {}", if on { "On" } else { "Off" }).into()
    },
    icon: Some("D"),
    action: TermWmAction::ToggleDirectMode,
    disabled: !self.windows.contains_key(self.focused_window()),
},
```

### 2. `refresh_command_palette()` helper — no visibility guard

Add to `window_manager/mod.rs`:

```rust
fn refresh_command_palette(&mut self) {
    let items = self.wm_menu_items();
    let supported = &self.supported_menu_actions;
    let filtered: Vec<_> = items.into_iter()
        .filter(|item| supported.contains(&item.action)
            || matches!(item.action, TermWmAction::FocusWindow(_)))
        .collect();
    if let Some(palette_key) = self.command_palette_key
        && let Some(overlay) = self.overlays.get_mut(palette_key)
    {
        overlay.set_menu_items(filtered);
    }
}
```

Note: no `if !self.command_menu_visible() { return; }` — the cache is always refreshed.

### 3. JIT refresh in render loop

In `src/lib.rs`, before draw dispatch:

```rust
if wm.command_menu_visible() {
    wm.refresh_command_palette();
}
```

### 4. Delete all mutator hooks

No calls to `refresh_command_palette()` from `set_direct_mode` or `focus.rs`.
