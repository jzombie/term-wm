# Plan: Snap preview as outline instead of fill (#259)

## Summary
The drag snap "ghost preview" currently renders a dashed border **plus** a solid
interior shade fill. Per issue #259, render it as an outline only — the dashed
border already exists, so the change is to stop painting the interior fill.

## Files to change

### 1. `crates/term-wm-console/src/draw_plan_renderer.rs`
- In `render_ghost_preview` (line 1809), delete the `// Interior shade fill — LICM-hoisted BCE row-slice iterator` block (lines 1872–1886). This is the only fill painting; the corner/dash-edge drawing above it stays unchanged.
- `theme` is still used for the border `fg_color`, and `clip` is still used — no signature change.
