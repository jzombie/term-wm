# Plan: Feature-Gate Project Tasks as Default Feature (Corrected — Decoupled)

## Context
Project Tasks pulls `shell-words` + `serde_json` always. Need `project-tasks` gated but default-on, additive only (no API mutation), and `--no-default-features` must actually hide it.

## Decision
Keep `ProjectTaskConfig` type, `pub mod project_tasks`, `WindowManager::project_tasks` field, and `wm_menu_items(project_tasks: &[ProjectTaskConfig])` **unconditional**. Gate only heavy dep usage inside `project_tasks.rs` and the menu loop. Make `project-tasks` default in both crates, with orthogonal `pty`/`session-persistence`/`project-tasks` features.

## Changes

### 1. `crates/term-wm-core/Cargo.toml`
```toml
[dependencies]
serde_json = { workspace = true, optional = true }
shell-words = { workspace = true, optional = true }

[features]
default = ["pty", "project-tasks"]
pty = ["portable-pty"]
session-persistence = ["term-wm-config/session-persistence"]
project-tasks = ["dep:shell-words", "dep:serde_json"]
```

### 2. `Cargo.toml` (root)
```toml
[dependencies]
term-wm-core = { workspace = true, default-features = false }

[features]
default = ["session-persistence", "project-tasks", "pty"]
pty = ["term-wm-core/pty"]
project-tasks = ["term-wm-core/project-tasks"]
session-persistence = [
    "dep:term-session",
    "dep:tokio",
    "dep:muxio-rpc-service-caller",
    "dep:muxio-rpc-service-endpoint",
    "term-wm-config/session-persistence",
    "term-wm-core/session-persistence",
]
```

### 3. `crates/term-wm-core/src/project_tasks.rs`
Keep `pub mod` unconditional. Gate bodies:
```rust
pub fn argv(&self) -> Option<Vec<String>> {
    #[cfg(feature = "project-tasks")] { /* shell_words::split */ }
    #[cfg(not(feature = "project-tasks"))] { None }
}
pub fn load_tasks_for_cwd(cwd: &Path) -> Option<ProjectTasks> {
    #[cfg(feature = "project-tasks")] { /* walk + serde_json */ }
    #[cfg(not(feature = "project-tasks"))] { let _ = cwd; None }
}
fn parse_tasks_file(path: &Path) -> Option<Vec<ProjectTaskConfig>> {
    #[cfg(feature = "project-tasks")] { /* fs + serde_json */ }
    #[cfg(not(feature = "project-tasks"))] { let _ = path; None }
}
#[cfg(feature = "project-tasks")]
use shell_words::split; // or fully-qualified inside cfg block
```
Gate tests:
```rust
#[cfg(all(test, feature = "project-tasks"))]
mod tests { ... }
```

### 4. `crates/term-wm-core/src/window/window_manager/command_palette.rs`
Keep signature unconditional, gate loop only + silence unused:
```rust
#[cfg(feature = "project-tasks")]
{
    let mut any_tasks_added = false;
    for task in project_tasks.iter().filter(|t| t.argv().is_some()) {
        items.push(MenuDisplayItem::Item(MenuItem { label: task.label.clone().into(), icon: Some("▶"), action: RunProjectTask(task.label.clone()), disabled: false }));
        any_tasks_added = true;
    }
    if any_tasks_added { items.push(Separator); }
}
#[cfg(not(feature = "project-tasks"))]
{ let _ = project_tasks; }
```
