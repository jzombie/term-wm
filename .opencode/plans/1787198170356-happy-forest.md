# Plan: Show All Connected Users Grouped by Workspace in Command Palette (Corrected)

## Context
Palette currently shows only flat `Connected Users (N)` for `current_workspace` via `UserRegistry` (`crates/term-wm-core/src/user_registry.rs:20`) and `refresh_user_cache()` (`src/term_wm_app.rs:337`) which queries `ListUsers(session/{current})`. User wants all workspaces with workspace annotation.

- `ListChannels` (`methods.rs:336`, `server.rs:1280`) already returns all `ChannelInfo{ name, clients: Vec<ClientInfo> }` where `ClientInfo` superset of `UserInfo`; workspace = `ChannelName::parse_workspace(&ch.name)`.
- `wm_menu_items(workspaces: &[String], ...)` (`command_palette.rs:106`) builds `MenuDisplayItem::Item(MenuItem{label: Cow<'static,str>, icon: Option<&'static str>, action: TermWmAction, disabled: bool})`. Palette filtered in `TermWmApp::open_command_palette` (`term_wm_app.rs:802`) against `supported_menu_actions` — informational rows must use `action: CloseMenu` with `disabled:true`.
- Current wrapper `App::open_command_palette` (`src/main.rs:679`) does two sync refreshes; adding a second `list_channels()` would double blocking IPC (OS thread + Tokio runtime) on UI thread.

## Decision
Single IPC pass: unify workspace + global user collection in one `list_channels()` call, direct-assign to `WindowManager`, no duplicate `TermWmApp` map/clone.

## Changes

### 1. `crates/term-wm-core/src/window/window_manager/mod.rs`
- Add gated field:
  ```rust
  #[cfg(feature = "session-persistence")]
  pub all_workspaces_users: std::collections::BTreeMap<String, Vec<crate::user_registry::UserEntry>>,
  ```
- Init in `with_config()` as `BTreeMap::new()` (gated). Keep `user_registry: UserRegistry` for live `OnUserConnected` toasts.

### 2. `src/term_wm_app.rs` — unify `refresh_workspace_cache()`
Delete `refresh_all_users_cache()`. Replace body of `refresh_workspace_cache()` with single-pass extraction:
```rust
#[cfg(feature = "session-persistence")]
pub fn refresh_workspace_cache(&mut self) {
    if !term_wm_config::runtime::session_persistence_enabled() { return; }
    match term_session::list_channels() {
        Ok(resp) => {
            let mut workspaces = std::collections::HashSet::new();
            let mut users_by_ws: std::collections::BTreeMap<String, Vec<term_wm_core::user_registry::UserEntry>> = std::collections::BTreeMap::new();
            for ch in resp.channels {
                let ws = term_session::ChannelName::parse_workspace(&ch.name).to_string();
                workspaces.insert(ws.clone());
                for c in ch.clients {
                    users_by_ws.entry(ws.clone()).or_default().push(term_wm_core::user_registry::UserEntry {
                        conn_id: c.conn_id, user: c.user, hostname: c.hostname, ssh_ip: c.ssh_ip,
                    });
                }
            }
            for v in users_by_ws.values_mut() { v.sort_by(|a,b| a.user.cmp(&b.user).then_with(|| a.hostname.cmp(&b.hostname))); }
            self.cached_workspaces = workspaces.into_iter().collect();
            self.cached_workspaces.sort();
            self.wm.all_workspaces_users = users_by_ws;
        }
        Err(e) => tracing::debug!("Failed to refresh workspace/user cache: {e}"),
    }
}
```
No `all_users_by_workspace` field on `TermWmApp`; no clone. Direct assign to `wm`.

Keep `refresh_user_cache()` for fallback if needed but palette no longer requires it.

### 3. `crates/term-wm-core/src/window/window_manager/command_palette.rs` — correct rendering
In `wm_menu_items`, after workspace group (which already ends with `Separator`), replace next block with:
```rust
#[cfg(feature = "session-persistence")]
if term_wm_config::runtime::session_persistence_enabled() && !self.all_workspaces_users.is_empty() {
    let total: usize = self.all_workspaces_users.values().map(|v| v.len()).sum();
    items.push(MenuDisplayItem::Item(MenuItem {
        label: format!("Connected Users ({total})").into(),
        icon: Some("●"),
        action: crate::actions::TermWmAction::CloseMenu,
        disabled: true,
    }));
    for (ws, users) in &self.all_workspaces_users {
        items.push(MenuDisplayItem::Item(MenuItem {
            label: format!("  {ws} ({})", users.len()).into(),
            icon: None,
            action: crate::actions::TermWmAction::CloseMenu,
            disabled: true,
        }));
        for u in users {
            let label = if let Some(ip)=&u.ssh_ip { format!("    {}@{} ({})",u.user,u.hostname,ip)} else { format!("    {}@{}",u.user,u.hostname) };
            items.push(MenuDisplayItem::Item(MenuItem {
                label: label.into(), icon: None,
                action: crate::actions::TermWmAction::CloseMenu, disabled: true,
            }));
        }
    }
    items.push(MenuDisplayItem::Separator);
} else if !self.user_registry.is_empty() { // fallback flat
    // existing flat Connected Users rendering (kept for non-persistence or empty global map)
}
```
- Gated with `#[cfg(feature = "session-persistence")]`.
- Uses `CloseMenu` to survive `supported_menu_actions` filter.
- Uses correct `MenuDisplayItem::Item(MenuItem{label: Cow, icon, action, disabled})`.
- No leading `Separator` — avoids double separator after workspace section's trailing `Separator`.

### 4. `src/main.rs`
`App::open_command_palette`:
```rust
fn open_command_palette(&mut self) {
    #[cfg(feature = "session-persistence")]
    self.inner.refresh_workspace_cache(); // now refreshes workspaces + all users in one IPC
    self.inner.open_command_palette();
}
```
Remove separate `refresh_user_cache()` call. Single blocking IPC on UI thread.

### 5. No new RPC
Reuse `list_channels()`; `ListUsers` kept for live incremental toasts but not for global palette snapshot.
