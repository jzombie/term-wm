# Fix: OSC 8 hyperlinks (Zed source-control links) not clickable inside term-wm

## Root cause (confirmed by investigation)

term-wm drops OSC 8 in three stacked places — so programs like Zed's source-control
integration, `git`, `gh`, and editors that emit `\x1b]8;;file:///abs/path:line:col\x1b\\`
produce plain, unclickable text in the host terminal (Zed disables its regex fallback
in alternate-screen mode, so nothing picks up the slack):

1. **Parser** — `term-wm-vt100`'s `osc_dispatch` (fork `perform.rs:200`) routes `8;…`
   to `unhandled_osc` and discards it. Cells carry no hyperlink metadata. (`OSC 7` cwd
   is discarded the same way.)
2. **Renderer** — `TerminalComponent::render_screen` (`crates/term-wm-ui-components/src/terminal.rs:529`)
   copies only `cell.contents()` + colors/styles into a ratatui `Buffer`.
3. **Output** — `ConsoleRenderTarget::draw` (`crates/term-wm-console/src/console_render_target.rs:185`)
   emits via ratatui `Terminal::draw` → `CrosstermBackend`, which only writes cursor
   moves / SGR / text — never OSC 8.

The fix is a full passthrough pipeline: parse OSC 8 in the fork → carry per-cell
hyperlinks through the render pipeline → emit well-formed OSC 8 (strict termination
hygiene, diff-aware) in a custom output backend. Plus OSC 7 cwd forwarding gated to
the focused pane, and parser-boundary URI canonicalization.

## Design decisions (addresses review SEV-1/SEV-2)

1. **Diff-aware hyperlink emission (SEV-1: link-only changes).** ratatui's
   `Buffer::diff_iter` only compares symbol/style (`ratatui-core 0.1.2` terminal/buffers.rs:104),
   so a hyperlink change on a visually-identical cell never reaches `Backend::draw`.
   We therefore run an explicit **correction pass**: after `f()` builds the frame,
   `ConsoleRenderTarget` computes `{i : cur_hyperlinks[i] != prev_hyperlinks[i]}`, and for
   each such cell (excluding ones the visual diff will redraw) the backend re-emits the
   cell inside the new link context (`open → MoveTo → Print(symbol) → close`) so the
   host's link state is updated/removed. No mutation of ratatui's `Cell` and no fight
   with its diff engine.
2. **No mid-span fragmentation (SEV-1).** The emitter tracks the open URI. On a
   coordinate jump it does NOT close purely because of the jump: it consults the
   current-frame hyperlink map for every skipped cell `x1+1..x2`; if all of them carry
   the same open URI, it keeps the sequence open across the `MoveTo` (those cells retain
   their link from prior frames). It only closes on a genuine URI change, an end-of-link
   boundary, or end-of-draw. A contiguous multi-cell link can never be split into
   fragments.
3. **Strict OSC 8 state invalidation.** Every open sequence is closed (`\x1b]8;;\x1b\\`)
   before any cursor jump that crosses a link boundary, before a pane/window/chrome
   transition, and at end of draw. Links can never bleed across window borders.
4. **OSC 7 gated to keyboard focus, re-synced on focus gain (SEV-2).** Each
   `TerminalComponent` tracks `last_forwarded_cwd`. On every frame where `ctx.focused()`
   is true, if current cwd ≠ `last_forwarded_cwd`, queue `\x1b]7;<uri>\x1b\\` and update
   `last_forwarded_cwd`. So a cwd mutated while unfocused is forwarded the moment the
   pane gains focus (no CWD race, no desync).
5. **Canonicalize URIs at the parser boundary.** The fork resolves schemeless/relative
   OSC 8 URIs to canonical `file:///abs/...` using the pane's cwd before storing, so
   term-wm never emits malformed `\x1b]8;;src/main.rs:42\x1b\\`.
6. **Linkifier as fallback only.** term-wm's `linkify` pass applies only to cells whose
   OSC 8 slot is `None`; program-emitted OSC 8 is authoritative. Never regex on raw ANSI.
7. **`Cell` stays 32 bytes (SEV-2).** No free 16 bits exist in the fork's 32-byte `Cell`
   (`contents[22] + len:u8 + attrs{fg,bg,mode}=9`). Use a packed `hyperlink: u8` **index**
   (0 = none) into a `Screen`-side `Vec<Arc<str>>` URI table, and shrink `CONTENT_BYTES`
   22→21. Per the `append` guard (`len >= CONTENT_BYTES - 4`), the max content length
   stays 20 bytes for a 4-byte base char + combining marks — the same as today, so the
   shrink is capacity-preserving (maintainer validates against existing tests).
   Layout: `contents[21] + len:u8 + hyperlink:u8 + attrs(9)` = exactly 32 bytes, align 1
   ⇒ the existing `size_of::<Cell>() == 32` assertion passes unmodified.

## Pipeline at a glance

```
PTY bytes ──▶ term-wm-vt100 (parses OSC 8/7, canonicalizes, stores packed per-cell id + cwd)
                │
Screen ──▶ TerminalComponent::render_screen ──▶ RatatuiBackend.hyperlinks[] (parallel to buffer.content)
                │
composite_window / blit ──▶ main frame hyperlinks[]
                │
ConsoleRenderTarget::draw ──▶ FrameLinks{cur, prev, corrections, osc7} (Rc<RefCell>)
                │
HyperlinkBackend::draw(dirty cells) ──▶ emits MoveTo+SGR+Print; wraps link cells in
   \x1b]8;;uri\x1b\\…\x1b]8;;\x1b\\  +  correction pass for link-only changes
```

## Step 1 — Fork `term-wm-vt100` (repo: `/Volumes/2TB Storage Vault/term-wm-vt100`)

Enable the local override during development: copy `.cargo/config.toml.example` →
`.cargo/config.toml` (already contains `term-wm-vt100 = { path = "../term-wm-vt100" }`).
No workspace version bump is needed to iterate (`^0.16.2-patch3` accepts the next patch).
Bump to the published version when released.

Fork changes:

- **Parse OSC 8** in `src/perform.rs` `osc_dispatch`, matching the OSC 52 shape:
  `[b"8", id_params, uri]`. Empty `uri` ⇒ close active link; non-empty ⇒ open.
  Validate `id_params` (empty or `id=…`), ignore malformed.
- **Packed per-cell hyperlink id** (`src/cell.rs`): add `hyperlink: u8` (0 = none),
  shrink `CONTENT_BYTES` 22→21, keep the `size_of::<Cell>() == 32` assertion passing.
  Screen holds `uri_table: Vec<Arc<str>>` (index → canonical URI); identical URIs share
  one index (dedupe on open). Every printable path (`Cell::set`/`append`/`clear`, insert
  mode, erase, scroll) stamps the active id; **line reflow on resize** moves it with the
  cell. Close (`8;;`) sets active id back to 0.
- **New API** (mirrors `Screen::cell` incl. `scrollback_offset`):
  - `Screen::hyperlink(&self, row: u16, col: u16) -> Option<Arc<str>>`
  - `Screen::cwd(&self) -> Option<&str>` (last OSC 7 URI)
- **Parse OSC 7** (`7;file://…`) and store on the `Screen`.
- **Canonicalization** in the OSC 8 dispatcher, before storing in the table:
  - Has scheme (`file://`, `http(s)://`, …) ⇒ keep; normalize `file://localhost/` → `file:///`.
  - Bare absolute path ⇒ `file://` + path.
  - Relative path ⇒ resolve against current `cwd()`; drop if unresolvable (never emit malformed).
  - Seed cwd: `Parser::new_with_callbacks` gains an optional initial cwd (PTY spawn dir).
- **State round-trip.** `state_formatted`/`state_diff` (`src/screen.rs:236,248`) include
  OSC 8 open/close + OSC 7 so `Pty::generate_snapshot` (`pty.rs:840`) restores links.
- Tests: open/close, packed-id (0=none, dedupe), scroll+reflow+erase preservation,
  canonicalization matrix (relative, schemeless-absolute, `file://localhost/`, unknown-cwd
  drop), OSC 7 capture, `state_formatted` round-trip, `size_of::<Cell>() == 32` assert.
- Bump to next patch (e.g. `0.16.2-patch4`); publish.

## Step 2 — `term-wm-console`: carry hyperlinks through rendering

- **`RatatuiBackend`** (`crates/term-wm-console/src/lib.rs:15`) gains
  `hyperlinks: Vec<Option<Arc<str>>>` parallel to `buffer.content` (index `y*width+x`),
  reset per frame. `new`/`new_simple` initialize it (keeps existing callers working).
  Add `clear_hyperlinks(&mut self, rect)` for overlays and
  `pending_osc7: Option<Vec<u8>>` for the OSC 7 channel.
- **`composite_window`** (`draw_plan_renderer.rs:1029`): before dropping the offscreen
  `RatatuiBackend`, take `hyperlinks`; in the existing row-copy loop (1137-1146) copy
  `hyperlinks[src..] → main.hyperlinks[dst..]` alongside `content` (overwrites stale
  links from overlapping windows with `None` where the covering pane has none).
- **Secondary paths** — `blit_buffer` (`draw_plan_renderer.rs:314`) and
  `DrawPlanRenderer::render_window_composite[_to_buffer]`/`render_direct` carry
  hyperlinks too.
- **Overlays clear stale links.** `render_app` empty-state (`src/lib.rs:233`), panels,
  FAB, split handles, and notification toasts call `clear_hyperlinks` on their regions so
  transient chrome can't inherit an underlying terminal link.

## Step 3 — `TerminalComponent::render_screen` (`crates/term-wm-ui-components/src/terminal.rs:529`)

- While writing each cell, read `screen.hyperlink(row, col)` and store it at the absolute
  frame index (`cell_y * width + cell_x`) in the downcast `RatatuiBackend`
  (`helpers::downcast_ratatui`, `helpers.rs:179`). Wide-char continuation cells inherit
  the leading cell's link (fork stamps both; harmless).
- **Linkifier fallback ordering:** skip `link_overlay.is_link_cell` styling when the cell
  already has OSC 8 metadata — program OSC 8 is authoritative; `linkify` only styles
  cells whose OSC 8 slot is `None`.

## Step 4 — `term-wm-console`: diff-aware hyperlink output backend

New file `crates/term-wm-console/src/hyperlink_backend.rs`:

- **`FrameLinks`** shared store (`Rc<RefCell<…>>`):
  `{ cur: Vec<Option<Arc<str>>>, prev: Vec<Option<Arc<str>>>, corrections: Vec<(u16,u16,String)>, osc7: Option<Vec<u8>> }`.
- **`HyperlinkBackend<W: Write>`** implements ratatui `Backend` (`Error = io::Error`)
  and `Write` (delegate; keeps `execute!` in `enter`/`exit` working). Non-`draw` methods
  delegate to crossterm commands (hide/show cursor, clear, size, set/get cursor, flush).
- **`draw()`** receives `(x, y, &Cell)` for changed cells only (ratatui 0.30 contract):
  1. If `osc7` is set, write `\x1b]7;<uri>\x1b\\` first.
  2. Emit the dirty stream: replicate crossterm's MoveTo/SGR/Print loop (incl.
     `ModifierDiff`-style attribute deltas so non-link bytes are unchanged), with the
     **link state machine**:
     - track `open: Option<Arc<str>>`; before a cell, if `open != cell_uri` close, then
       (if `Some`) open `\x1b]8;;<uri>\x1b\\`;
     - on a coordinate jump, if every skipped cell `x1+1..x2` in `cur` shares `open`,
       keep the sequence open (MoveTo only) — no fragmentation; else close before moving.
     - close at URI change and at end-of-draw. A link is never open across a boundary.
  3. **Correction pass:** re-emit each `corrections` cell that wasn't already emitted by
     the dirty stream (`open/close + MoveTo + Print(symbol)`), updating/removing host link
     state on visually-identical cells.
  4. Reset SGR, close any open link, then set `prev = cur` (swap).
- All byte output for non-hyperlink cells must be byte-identical to `ratatui-crossterm`.

## Step 5 — `ConsoleRenderTarget<W>` (`crates/term-wm-console/src/console_render_target.rs`)

- `terminal: Terminal<HyperlinkBackend<W>>`; `with_writer`/`new_capturing` construct the
  new backend + a fresh `FrameLinks`. `enter`/`exit`/`repair` unchanged.
- `draw()`: build `RatatuiBackend` (fresh `hyperlinks`), run `f(&mut backend)`, then
  compute `corrections = {i : hyperlinks[i] != FrameLinks.prev[i]}` (excluding cells whose
  symbol is blank/unchanged) using the now-final frame buffer, and publish
  `FrameLinks{cur, corrections, osc7}` (clone the shared `Rc` into the closure to avoid
  borrowing `self` across `terminal.draw`). `Terminal::draw`'s internal diff then runs
  `HyperlinkBackend::draw` against the current frame's links.

## Step 6 — OSC 7 cwd forwarding, focused-pane gated (`terminal.rs`)

- Track `last_forwarded_cwd: Option<String>` per `TerminalComponent` (persists across
  focus changes). Each render, read `screen.cwd()`:
  - `ctx.focused()` && `cwd != last_forwarded_cwd` ⇒ queue `\x1b]7;<uri>\x1b\\` into
    `RatatuiBackend.pending_osc7` (drained into `FrameLinks.osc7` by Step 5) and update
    `last_forwarded_cwd`. Focus gain on a pane whose cwd changed while unfocused
    immediately syncs the host (SEV-2 fix).
  - unfocused ⇒ never forward. No multi-pane race.
- Optionally seed the initial cwd (PTY spawn dir, exposed from `Pty`) on first focus.

    `open…close`, link stays contiguous);

  - new link on a changed cell ⇒ wrapped in `\x1b]8;;file:///…\x1b\\…\x1b]8;;\x1b\\`.
- **OSC 7 focus tests (SEV-2):** cwd mutated while unfocused is NOT forwarded; on the
  first focused frame it IS forwarded exactly once; switching focus back/forth re-syncs.
