# Fix: OSC 8 hyperlinks (Zed source-control links) not clickable inside term-wm

## Root cause (confirmed by investigation)

term-wm drops OSC 8 in three stacked places — so programs like Zed's source-control
integration, `git`, `gh`, and editors that emit `\x1b]8;;file:///abs/path:line:col\x1b\\`
produce plain, unclickable text in the host terminal (Zed disables its regex fallback
in alternate-screen mode, so nothing picks up the slack):

1. **Parser** — `term-wm-vt100`'s `osc_dispatch` (fork `perform.rs:200`) routes `8;…`
   to `unhandled_osc` and discards it. Cells carry no hyperlink metadata. (`OSC 7` cwd
   is discarded the same way.)
2. **Renderer** — `TerminalComponent::render_screen` (`crates/term-wm-ui-components/src/terminal.rs:529`)
   copies only `cell.contents()` + colors/styles into a ratatui `Buffer`.
3. **Output** — `ConsoleRenderTarget::draw` (`crates/term-wm-console/src/console_render_target.rs:185`)
   emits via ratatui `Terminal::draw` → `CrosstermBackend`, which only writes cursor
   moves / SGR / text — never OSC 8.

The fix is a full passthrough pipeline: parse OSC 8 in the fork → carry per-cell
hyperlinks through the render pipeline → emit well-formed OSC 8 in a custom output
backend. Plus OSC 7 cwd forwarding gated to the focused pane, and parser-boundary URI
canonicalization (incl. RFC 3986 percent-encoding).

## Design decisions (addresses all review SEV-1/SEV-2 findings)

1. **Single unified row-major emission pass (SEV-1: out-of-order).** There is no
   "dirty stream then correction pass". `ConsoleRenderTarget::draw` computes the
   link-correction set *before* the backend emits; `HyperlinkBackend::draw` merges the
   ratatui dirty cells and the correction cells into **one `(y, x)`-sorted list** and
   emits it in a single strictly top-to-bottom, left-to-right pass. No backward cursor
   moves, no line-wrap violations, contiguous links stay contiguous.
2. **Link-only changes are emitted (SEV-1: diff bypass).** ratatui's `Buffer::diff_iter`
   only compares symbol/style (`ratatui-core 0.1.2` terminal/buffers.rs:104), so a link
   change on a visually-identical cell never reaches `Backend::draw`. The correction set
   `{i : cur_hyperlinks[i] != prev_hyperlinks[i]}` covers exactly those cells; each is
   re-emitted inside its new link context within the unified pass.
3. **No mid-span fragmentation (SEV-1).** The emitter tracks the open URI. Across a gap
   (horizontal skip or row-tail wrap), it consults `cur` for every skipped cell; if all
   share the open URI it keeps the sequence open across the `MoveTo`, else closes. A
   multi-cell link can never be split into fragments.
4. **Strict OSC 8 state invalidation.** Every open sequence closes (`\x1b]8;;\x1b\\`) on
   URI change, before a gap whose skipped cells don't share the URI, at end-of-draw —
   never left open across a pane/window/chrome boundary.
5. **Resize-safe diffing (SEV-2).** `ConsoleRenderTarget` tracks the frame dimensions;
   on width/height change it resets `prev_hyperlinks` (all-`None`, matching `cur`'s
   length) so `cur[i] != prev[i]` can never index OOB, and forces every hyperlinked cell
   into the correction set so the new layout re-emits all links. Backend link state is
   per-`draw` (fresh each call), so it self-resets.
6. **OSC 7 gated to keyboard focus, re-synced on focus gain (SEV-2).** Each
   `TerminalComponent` tracks `last_forwarded_cwd`; on every focused frame, if current
   cwd ≠ `last_forwarded_cwd` it queues `\x1b]7;<uri>\x1b\\` and updates it. A cwd mutated
   while unfocused is forwarded the moment the pane gains focus.
7. **Canonicalize + percent-encode at the parser boundary (SEV-2).** The fork resolves
   schemeless/relative OSC 8 URIs to canonical `file:///abs/...` using the pane's cwd and
   applies RFC 3986 percent-encoding to every path component (spaces, `#`, `?`, `%`,
   non-ASCII) for both OSC 8 file URIs and OSC 7 cwd. term-wm never emits malformed
   `\x1b]8;;src/main.rs:42\x1b\\` or unencoded OSC 7.
8. **Linkifier as fallback only.** term-wm's `linkify` pass applies only to cells whose
   OSC 8 slot is `None`; program-emitted OSC 8 is authoritative. Never regex on raw ANSI.
9. **`Cell` stays 32 bytes with a `u16` index (SEV-2).** Empirically verified layout:
   `contents: [u8;20]` + `len: u8` + `hyperlink: u16` + `attrs{fg,bg,mode}=9` = exactly
   32 bytes (align 2). `Attrs` is 9 bytes (fg 4 + bg 4 + mode 1) — the "8" in the review
   is off by one, but the u16 packing holds. 65,535 unique URI slots per screen; content
   capacity via the `append` guard drops to base + up to 3 combining marks (4 codepoints)
   — validated against existing tests; the maintainer may relax the guard if needed.

## Pipeline at a glance

```
PTY bytes ──▶ term-wm-vt100 (parses OSC 8/7, canonicalizes + percent-encodes, stores u16 per-cell id + cwd)
                │
Screen ──▶ TerminalComponent::render_screen ──▶ RatatuiBackend.hyperlinks[] (parallel to buffer.content)
                │
composite_window / blit ──▶ main frame hyperlinks[]
                │
ConsoleRenderTarget::draw ──▶ FrameLinks{cur, prev, corrections, osc7} (Rc<RefCell>)
                │
HyperlinkBackend::draw(dirty cells) ──▶ ONE (y,x)-sorted pass: MoveTo+SGR+Print +
   \x1b]8;;uri\x1b\\…\x1b]8;;\x1b\\  (dirty cells + link corrections merged)
```

## Step 1 — Fork `term-wm-vt100` (repo: `/Volumes/2TB Storage Vault/term-wm-vt100`)

Enable the local override during development: copy `.cargo/config.toml.example` →
`.cargo/config.toml` (already contains `term-wm-vt100 = { path = "../term-wm-vt100" }`).
No workspace version bump is needed to iterate (`^0.16.2-patch3` accepts the next patch).
Bump to the published version when released.

Fork changes:

- **Parse OSC 8** in `src/perform.rs` `osc_dispatch`, matching the OSC 52 shape:
  `[b"8", id_params, uri]`. Empty `uri` ⇒ close active link; non-empty ⇒ open.
  Validate `id_params` (empty or `id=…`), ignore malformed.
- **Packed per-cell hyperlink id** (`src/cell.rs`): `contents: [u8;20]`, `len: u8`,
  `hyperlink: u16` (0 = none), `attrs` — field order such that `size_of::<Cell>() == 32`
  passes (verified: contents, len, u16, attrs ⇒ 32 bytes, align 2). Screen holds
  `uri_table: Vec<Arc<str>>` (index → canonical URI); identical URIs share one index
  (dedupe on open). Every printable path (`Cell::set`/`append`/`clear`, insert mode,
  erase, scroll) stamps the active id; **line reflow on resize** moves it with the cell.
  Close (`8;;`) sets active id back to 0.
- **New API** (mirrors `Screen::cell` incl. `scrollback_offset`):
  - `Screen::hyperlink(&self, row: u16, col: u16) -> Option<Arc<str>>`
  - `Screen::cwd(&self) -> Option<&str>` (last OSC 7 URI, percent-encoded)
- **Parse OSC 7** (`7;file://…`) and store on the `Screen`.
- **Canonicalization + percent-encoding** in the OSC 8/7 dispatchers, before storing:
  - Has scheme (`file://`, `http(s)://`, …) ⇒ keep (normalize `file://localhost/` → `file:///`).
  - Bare absolute path ⇒ `file://` + percent-encoded path.
  - Relative path ⇒ resolve against current `cwd()`; drop if unresolvable (never emit malformed).
  - RFC 3986: percent-encode every byte outside `A-Za-z0-9-._~/` in path components
    (spaces, `#`, `?`, `%`, non-UTF-8, control chars).
  - Seed cwd: `Parser::new_with_callbacks` gains an optional initial cwd (PTY spawn dir),
    percent-encoded.
- **State round-trip.** `state_formatted`/`state_diff` (`src/screen.rs:236,248`) include
  OSC 8 open/close + OSC 7 so `Pty::generate_snapshot` (`pty.rs:840`) restores links.
- Tests: open/close; packed-id (0=none, dedupe, `size_of::<Cell>() == 32`);
  scroll/reflow/insert-mode/erase preservation; canonicalization + percent-encoding
  matrix (relative, schemeless-absolute, `file://localhost/`, unknown-cwd drop, spaces &
  non-ASCII paths); OSC 7 capture; `state_formatted` round-trip.
- Bump to next patch (e.g. `0.16.2-patch4`); publish.

## Step 2 — `term-wm-console`: carry hyperlinks through rendering

- **`RatatuiBackend`** (`crates/term-wm-console/src/lib.rs:15`) gains
  `hyperlinks: Vec<Option<Arc<str>>>` parallel to `buffer.content` (index `y*width+x`),
  reset per frame. `new`/`new_simple` initialize it (keeps existing callers working).
  Add `clear_hyperlinks(&mut self, rect)` for overlays and
  `pending_osc7: Option<Vec<u8>>` for the OSC 7 channel.
- **`composite_window`** (`draw_plan_renderer.rs:1029`): before dropping the offscreen
  `RatatuiBackend`, take `hyperlinks`; in the existing row-copy loop (1137-1146) copy
  `hyperlinks[src..] → main.hyperlinks[dst..]` alongside `content` (overwrites stale
  links from overlapping windows with `None` where the covering pane has none).
- **Secondary paths** — `blit_buffer` (`draw_plan_renderer.rs:314`) and
  `DrawPlanRenderer::render_window_composite[_to_buffer]`/`render_direct` carry
  hyperlinks too.
- **Overlays clear stale links.** `render_app` empty-state (`src/lib.rs:233`), panels,
  FAB, split handles, and notification toasts call `clear_hyperlinks` on their regions so
  transient chrome can't inherit an underlying terminal link.

## Step 3 — `TerminalComponent::render_screen` (`crates/term-wm-ui-components/src/terminal.rs:529`)

- While writing each cell, read `screen.hyperlink(row, col)` and store it at the absolute
  frame index (`cell_y * width + cell_x`) in the downcast `RatatuiBackend`
  (`helpers::downcast_ratatui`, `helpers.rs:179`). Wide-char continuation cells inherit
  the leading cell's link (fork stamps both; harmless).
- **Linkifier fallback ordering:** skip `link_overlay.is_link_cell` styling when the cell
  already has OSC 8 metadata — program OSC 8 is authoritative; `linkify` only styles
  cells whose OSC 8 slot is `None`.

## Step 4 — `term-wm-console`: unified row-major hyperlink output backend

New file `crates/term-wm-console/src/hyperlink_backend.rs`:

- **`FrameLinks`** shared store (`Rc<RefCell<…>>`):
  `{ cur: Vec<Option<Arc<str>>>, prev: Vec<Option<Arc<str>>>, corrections: Vec<(u16,u16,ratatui::Cell)>, osc7: Option<Vec<u8>> }`.
- **`HyperlinkBackend<W: Write>`** implements ratatui `Backend` (`Error = io::Error`)
  and `Write` (delegate; keeps `execute!` in `enter`/`exit` working). Non-`draw` methods
  delegate to crossterm commands (hide/show cursor, clear, size, set/get cursor, flush).
- **`draw()`** (ratatui 0.30 contract: `(x, y, &Cell)` for changed cells only):
  1. If `osc7` is set, write `\x1b]7;<uri>\x1b\\` first.
  2. **Build one emission list:** collect the dirty cells `(x, y, Cell)` from `content`,
     merge with `corrections` `(x, y, Cell)` (dirty wins on `(y,x)` collision; corrections
     carry symbol+style captured from the frame buffer), then **sort by `(y, x)`** — a
     single strictly top-to-bottom, left-to-right pass. No backward cursor moves.
  3. Emit the sorted list, replicating crossterm's MoveTo/SGR/Print loop (incl.
     `ModifierDiff`-style attribute deltas so non-link bytes are unchanged), with the
     **link state machine**:
     - track `open: Option<Arc<str>>`; before a cell, if `open != cell_uri` close, then
       (if `Some`) open `\x1b]8;;<uri>\x1b\\`;
     - on a gap (horizontal skip or row-tail wrap), look up every skipped cell in `cur`;
       if all share `open`, keep the sequence open across the `MoveTo`; else close first;
     - close on URI change and at end-of-draw. A link is never open across a boundary.
  4. Reset SGR, close any open link, then set `prev = cur` (swap).
- All byte output for non-hyperlink cells must be byte-identical to `ratatui-crossterm`.

## Step 5 — `ConsoleRenderTarget<W>` (`crates/term-wm-console/src/console_render_target.rs`)

- `terminal: Terminal<HyperlinkBackend<W>>`; `with_writer`/`new_capturing` construct the
  new backend + a fresh `FrameLinks`. Track `last_area: Rect`. `enter`/`exit`/`repair`
  unchanged.
- `draw()`:
  1. Build `RatatuiBackend` (fresh `hyperlinks`), run `f(&mut backend)`.
  2. **Resize invalidation:** if `frame_area != last_area`, reset `FrameLinks.prev` to
     all-`None` (length = `cur`'s) and force every hyperlinked cell into the correction
     set; update `last_area`.
  3. Compute `corrections`: for every `i` where `cur[i] != prev[i]` and the frame cell is
     non-blank, capture `(x, y, Cell)` (symbol+style) from the now-final frame buffer.
  4. Publish `FrameLinks{cur, corrections, osc7}` (clone the shared `Rc` into the closure
     to avoid borrowing `self` across `terminal.draw`). `Terminal::draw`'s internal diff
     then runs `HyperlinkBackend::draw`, which merges dirty + corrections and emits once.

## Step 6 — OSC 7 cwd forwarding, focused-pane gated (`terminal.rs`)

- Track `last_forwarded_cwd: Option<String>` per `TerminalComponent` (persists across
  focus changes). Each render, read `screen.cwd()`:
  - `ctx.focused()` && `cwd != last_forwarded_cwd` ⇒ queue `\x1b]7;<uri>\x1b\\` into
    `RatatuiBackend.pending_osc7` (drained into `FrameLinks.osc7` by Step 5) and update
    `last_forwarded_cwd`. Focus gain on a pane whose cwd changed while unfocused
    immediately syncs the host.
  - unfocused ⇒ never forward. No multi-pane race.
- Optionally seed the initial cwd (PTY spawn dir, exposed from `Pty`, percent-encoded) on
  first focus.
